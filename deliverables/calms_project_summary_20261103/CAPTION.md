# CALMS project summary figure

**a,** CALMS combines condition-robust spectral representations, fragmentation evidence and candidate-specific chemistry before producing a metabolite annotation with an auditable evidence record. Real-sample context is an optional extension and was not used in the GNPS benchmark. **b,** Recall@1 on the common-domain GNPS identity-disjoint development panel (10,983 queries). CALMS reaches 88.40% and improves over official fine-tuned DreaMS by 3.01 percentage points. **c,** Candidate-level ROC curves on the same query/candidate axis; CALMS achieves AUROC 0.959. GNPS is a consumed development resource, not an unopened external confirmation set.
