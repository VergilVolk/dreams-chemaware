# CALMS project summary figure

**a,** CALMS combines condition-robust MS/MS representations with fragmentation-structure consistency evidence, then optionally refines ambiguous annotations using real-sample metabolic context when that context is available. The sample-context module was not used for the GNPS benchmark. **b,** Recall@1 on the common-domain GNPS identity-disjoint development panel (10,983 queries). CALMS reaches 88.40% and improves over DreaMS by 3.01 percentage points. **c,** Candidate-level ROC curves on the same query/candidate axis; CALMS achieves AUROC 0.959. GNPS is a consumed development resource, not an unopened external confirmation set.
