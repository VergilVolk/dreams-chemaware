# CALMS architecture artwork provenance

The architecture artwork was produced with the built-in image-generation tool and refined through targeted visual edits. The final raster contains no generated text; every visible label is added deterministically by `tasks/render_calms_project_summary.py`.

## Final edit prompt

Preserve the three stacked parallel evidence branches, left LC-MS/MS input, right annotation output, restrained navy-gray palette, line-art style and orthogonal arrows. Remove every icon and internal line from the central navy-bordered CALMS panel so it becomes a completely clean typography-only space. Scale all illustrative icons inside the input, evidence and output boxes down by approximately 20–25 percent while preserving box dimensions and arrow paths. Increase whitespace. Use a solid white background, charcoal lines, pale gray fills and one muted navy accent. Include no letters, words, numbers, formulas, pseudo-text, watermarks, gradients, shadows or 3D effects.
