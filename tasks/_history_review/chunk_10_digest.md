## 块总评

本块 17 个文件（2026-09-04 至 09-05，外加早期 E1 协议）记录了 DreaMS 项目三条主线（BioAware / Noise / ChemAware）在同一两天内密集收敛的全过程，主线叙事是"高 pp 数字逐一被严格对照拆穿，真正可辩护的证据收窄到 +0.6~0.7 pp 量级"。

**BioAware 线**：09-04 科学重置撤销 R0/R1 两条临时路线，把问题拆成"样本上下文候选专家"与"身份保持单谱 embedding"两个；唯一成立结果仍是 548 查询上 full_bioaware +3.47pp(19/0)。随后 B0-M0 经 v3 审计（覆盖过门但平衡失败、dummy 实现违背边际合同）到 v4 闭环置换（数学不变量全过但四个 caliper 无一同时满足 500/300/200/SMD≤0.10 门），单谱反应邻路线以负面预检验冻结。B2 被判候选身份捷径（RT-only +2.05pp 隔离后塌缩至 +0.23pp），B3/B4 转向 identity-blind 单调抬升与"专家只当训练样本路由器"的直接微调，预检阶段还抓到 library_row 跨数据库行号别名这一数据语义级事故。

**Noise 线**（本块最重）：dynamic-direct 四臂 Phase A 中三个对照完全并列（0.9398953），dynamic 反差 0.0169pp，否定了动态权重内核；E4-PMT 把 28,509 个 N 动作硬路由后 treatment 仍输给 clean duplicate/matched random（margin 微增 0.00037 却丢 Top-1）；E4-DEB 逐候选边界三臂再次判负（hardest-margin CI 严格为负），根因五条中"以近零 preservation 梯度做标定导致 100% clipping"是新的工程级教训。复盘评委会文档是全局枢纽：证据 A-X 分级、三 evaluator 指标体系、10 条机制教训（核心是"动作有效≠动作可传递"与"普通 continuation 是真实强基线"）、16 类工程事故账本。当前最强证据仍是 E4-A multifold 平均 +0.6362pp（15/15 方向为正），传递效率仅 13-17%。

**ChemAware 线**：+0.4666pp 被判属公共 continuation（八臂中化学臂与无教师臂完全相同）；ICEBERG 分布注入与采样路由、PSD 观察字典、ChemBERTa 跨模态残差全部 DEVELOPMENT_FAIL；唯一过门的是谱内可见 mass/rule kernel（冻结空间 +0.881/+1.244pp）与两条 m/z 44.0495 诊断离子经验关联，但前者蒸不进 Transformer（Phase B 也拒）、后者覆盖率不足禁作动作源。制度性修复（单臂永不 PASS、10 GPU·时硬预算、outer 一次性密封）成为该线的遗产。

**跨线主题**：(1) 几乎每条"3-5pp"的高数字最终都被归类为 outcome-aware 容量/headroom 而非模型增益；(2) 匹配对照的数学构造（Hungarian 闭环、边际保持）与因果对照（matched-random、shifted-rule、continuation）成为裁决的唯一通货；(3) 预检/复现门（rank replay、SHA 冻结、exit code 64 隔离旧入口）系统性拦截了多起数据与工程事故；(4) 最后一份指标审计厘清 DreaMS 论文 0.85 是 NIST20 pair pooled AUROC 而非 Top-1，避免用不可得的 NIST20 文件阻塞晋级。本块是项目从"追高数字"转向"守因果"的分水岭，E4-A +0.6362pp 是截至块末唯一可写进论文主表的 A 级开发证据。
