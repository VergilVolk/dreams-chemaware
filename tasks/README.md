# 化学微调分层任务体系 — 完整定义

## 数据库
6,797,516 谱图，271,594 独特 InChIKey（GNPS+MassBank+MoNA+MSnLib）

## MCES 谱系

```
T0(MCES=0) → T1(MCES 1-2) → T2(MCES 3-5) → 负样本(MCES≥6)
  │              │               │               │
同分子          近同分异构体     类似物/同系物    结构差异大
```

## 任务定义

### T0：一致性（Consistency）
- **判定**：同一 InChIKey
- **MCES**：0（化学等价）
- **正样本**：同 IK 不同谱图（不同碰撞能/加合物/仪器）
- **负样本**：不同 IK（难：质量差≤0.05Da，易：随机）
- **化学意义**：规则命中是否跨条件稳定
- **已构造**：15,190 正 + 10,000 负

### T1：近同分异构体（Near-Isomers）
- **判定**：MCES 1-2
- **候选生成**：同 FORMULA + 不同 IK + Morgan相似度>0.2（指纹预筛）
- **正样本**：MCES 1-2（1-2 键不同：甲基化、羟基化等单步修饰）
- **负样本**：同 FORMULA + 不同 IK + MCES ≥ 5
- **化学意义**：极细微结构差异的化学区分
- **构造中**：myopic-mces + 指纹预筛

### T2：类似物/同系物（Analogs/Homologs）
- **判定**：MCES 3-5
- **候选生成**：同 Murcko 骨架 + 不同 IK + Morgan相似度>0.1（骨架匹配=缩小候选池的手段）
- **正样本**：MCES 3-5（同骨架但侧链不同）
- **负样本**：同骨架 + MCES > 5
- **化学意义**：同类骨架下侧链差异的化学区分
- **构造中**：Murcko scaffold + myopic-mces

### T3：不相关分子（Unrelated）
- **判定**：不同 InChIKey + 不同 FORMULA
- **角色**：地板基线（sanity check）—— 不是训练目标
- **注意**：**不可与 T0-T2 AUC 取平均**—— T3 太容易会拉高综合分数
- **已构造**：10,000 负样本对

## 审查规则

每批测例构造后必须检查：
1. 每条规则/每 IK 的贡献对数分布（防止少数规则/IK 垄断）
2. MCES 分布直方图 + Tanimoto 分布
3. 跨库 vs 同库配对比例
4. 正/负样本平衡度
5. 按分子大小（键数）分层的 MCES 分布（验证阈值对小分子/大分子是否都合理）
