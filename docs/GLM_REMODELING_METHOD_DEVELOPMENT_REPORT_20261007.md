# 研究开发报告：全局化学重塑分解——方法定位、模块开发与下一步（2026-10-07）

**作者：** GLM（任务 2 方法研发）  **状态：** 开发中；Stage-1 等数据上传

## 1. 文献定位：我们的净增量在哪里

| 已有工作 | 已覆盖 | 我们不能冒领 | 我们的可争增量 |
|---|---|---|---|
| Reactomics (PMD) | 质量差推断反应，无表型分解 | "PMD 边 = 反应" | 把 PMD 边放进**患者级三分解**框架 |
| MetFamily | 谱图相似族内比较 | "家族比较" | 区分家族**整体升降**与家族**内部化学替换** |
| TidyMass2 | 未注释功能模块 | "模块发现" | 把模块效应分解到**成分层**（家族/内部/残差） |
| MCN (840 万特征) | 分子社区网络组织 | "大规模组织" | 网络上的**疾病效应算子**（不是静态图） |
| DreaMS Atlas | 静态化学空间表示 | "atlas 构建" | **疾病如何重塑化学空间**（名词→动词） |
| 图信号分解理论 | 平滑/振荡分解数学 | "数学工具" | 把谱图嵌入图上的信号分解**直接绑定到测量** |

**净增量的精确表述**：第一次把非靶向代谢组学的疾病效应定义为
患者级全化学图上的结构化信号，并区分"分子家族整体丰度变化"与
"家族内部沿特定化学改造发生的重排"。这个对象——不是峰、不是注释、
不是静态图——是此前所有工作都没有直接定义和分析过的。

## 2. 已开发模块

### 2.1 转换边模块（`tasks/GLM_transformation_edges.py`，通过合同测试）

- **40+ 条生化转换 PMD**（氧化/还原/甲基化/乙酰化/糖苷化/葡萄糖醛酸化/
  硫酸化/磷酸化/谷胱甘肽结合/氨基酸结合/链延长/卤化……），每条带精确质量；
- **边构造**：精确质量差匹配（ppm ≤ 20）+ 共享碎片检查（至少一条 ≥ 10%
  强度的共同碎片）；
- **边差分**：g_{p,e} = d_{p,v} - d_{p,u}，逐患者计算；
- **方向一致性**：符号检验（one-sided binomial），输出 p 值/中位数/正比例；
- **PMD 置换零**：随机重排质量分配后重建边，校准 FDR；
- **摘要**：全部边的排序表 + 计数（有碎片支持的 / p ≤ 0.05 的）。

12 项合同测试全通过（含甲基化/葡萄糖醛酸化/硫酸化三条特定 PMD 的正测试
和一条不匹配质量差的负测试）。

## 4. 诚实边界

- 转换边是"质量差匹配 + 碎片支持"，不是"已证化学反应"；语言必须用
  "与特定化学改造一致的实体对效应差异"，禁用"反应"或"酶活性"；
- PMD 置换零是最小校准；严格的 FDR 需要完整的目标-诱饵框架（后续工作）；
- 所有 Stage-2 阈值在 Stage-1 结果出来前已冻结；出来后不得回改。
