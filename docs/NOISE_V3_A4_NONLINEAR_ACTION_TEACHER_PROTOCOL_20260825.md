# Noise-v3 A4 非线性动作教师：预注册协议

**目的：** 在不修改 DreaMS 权重的前提下，使用 A4 的 825,152 个精确峰干预结果学习“修正收益—新增错误风险—margin 变化”的非线性交互，决定哪些反事实动作有资格进入后续微调。

## 数据边界

- 输入仅来自 P3-disjoint 的 A4 训练错误与匹配正确对照；
- 同一分子式的全部查询、峰和剂量固定在同一个外层折；
- 每个查询总权重相同，避免峰多的谱图支配训练；
- 不读取 P3，不修改 DreaMS，不将 OOF 结果写成模型性能。

A4 的 1,805 个错误中有 21 个不存在任何允许删除的峰；3,193 个安全对照中有 61 个同样无动作。它们保留在 source 完整性审计中，但不强行制造动作。正式动作教师覆盖 1,784 个可干预错误和 3,132 个可干预对照；21 个零动作错误全部进入后续正例证据恢复分支。

## 模型输入

- 峰 m/z、强度、梯度、绝对梯度、剂量特异预测增益、梯度排名；
- 峰角色：confounder-only、shared、unmatched；
- 衰减剂量及角色—剂量交互；
- 候选数、峰数、near 状态、最难候选 MCES 分层。

以下字段严禁作为模型输入：`scan_kind`、baseline rank/margin、错误家族、positive/negative-deficit、`rules_favor_positive/wrong`。这些字段直接或间接依赖真实身份，会造成动作选择泄漏。它们只用于事后错误分析。

## 多任务输出

共享非线性主干同时预测：

1. 对官方错误，该动作是否能将正确候选恢复到 Top-1；
2. 对匹配正确对照，该动作是否会新增 Top-1 错误；
3. 动作导致的连续 groupwise margin 变化。

动作效用固定为：

\[
U(a|q)=P(\mathrm{correct}|a,q)-2P(\mathrm{introduce}|a,q).
\]

## 风险—覆盖率裁决

不根据当前结果临时调阈值。固定评价 5%、10%、20%、40% 四个覆盖率，每个覆盖率均报告：

- corrected、introduced、风险加权净收益；
- 历史 S1c/S2/S3A 之外的新修正；
- formula-cluster bootstrap 95% CI；
- 新增错误的峰角色、剂量、near/MCES、候选数、峰数和原始安全 margin；
- 被修正错误的四类机制分布。

只有同时满足以下条件的覆盖区间，才可产生后续微调样本：

1. benefit 与 harm 的 OOF AUPRC 均至少为对应阳性率的 2 倍；
2. 风险加权净收益的公式簇 CI 下界大于 0；
3. introduced 不超过 corrected 的一半；
4. 至少新增修正 80 个历史动作未覆盖错误。

任何门失败都不能用扩大覆盖率补偿。失败后进入正例证据恢复分支或重新设计无泄漏特征。

## 化学规则的进入条件

现有 A4 文件中的 `rules_favor_positive/wrong` 对正确对照不具有同等语义，不能用于训练。规则只有在为所有候选组重新计算“查询—候选规则证据差”，且该差异不使用真实身份后，才能加入 `core vs core+rules` 的 formula-OOF 消融。
