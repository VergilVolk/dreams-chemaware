## 1. 证据等级与状态

| 等级 | 含义 |
|---|---|
| `E0` | 数字或来源尚未绑定，禁止对外使用 |
| `E1` | 历史、探索性或受限 cohort 证据，只能生成假设或说明研究过程 |
| `E2` | 协议明确的内部开发/确认结果，可作有边界的方法学证据 |
| `E3` | 预先冻结的内部封存评价，可支持对应面板上的确认性主张 |
| `E4` | 独立外部或标准品确认；本登记范围内暂无此等级条目 |

## 3. 跨条目作图纪律

1. `FA-OLD-002`、`PT-DIAG-002` 和 `E4A-HIST-001` 共享旧 cohort，但该 cohort 已失去当前正式资格；共享旧分母不恢复其正式证据等级。
2. 只有 `A1-001` 与 `A1B-001` 适合在同一 NDCG@5 机制面板直接对照；仍须标明显式多通道与 official single-cosine 的表示不同。
3. RAW-v1、P2b、A1/A1b、Peak-token 和 E4-A 的数据、终点或训练角色不同，不得使用一个共享百分点评分轴形成算法排名或递进 waterfall。
4. P2b P3-main 与 near-core 可并列展示，但不得合并分母；正向主结果必须同时展示 near-core 负边界。
5. corrected Failure Atlas 的机制主图只有在每一类表型重新绑定 corrected manifest、checkpoint、candidate protocol、split、tie policy 和逐 query ledger 后才可定量发布。
