# LCNEC谱图坐标作业2353437审计

裁决：**无效试跑；不得作为阴性结果、覆盖率结果或论文证据。**

## 表面输出

- GNPS坐标数：2,000；
- HSST3n查询谱：262；
- 通过阈值的查询：2（0.8%）；
- LIPn：不可用；

0.8%不能解释为LCNEC化学空间只有0.8%被公共谱库覆盖，也不能解释为99.2%“暗物质”。该数字由未验证的字典抽样、分数和阈值共同产生。

## 一票否决问题

1. **没有第二平台。** 作业明确报告`LIPn not available`，因此没有任何跨平台坐标复现；P2的主要科学问题根本未被执行。
2. **字典不是覆盖优化或冻结的参考坐标。** 代码把GNPS Gold谱按峰数降序，每个IK14取一张谱后截取前2,000个。该选择偏向峰多的谱，没有按m/z、化学空间、仪器或未知谱图覆盖设计，也没有字典规模敏感性。
3. **所谓entropy不是正式谱熵/WSE。** 代码按0.01 Da四舍五入合并峰后自定义熵比值；它与文章天梯中已验证的`weighted_spectral_entropy`实现不同。
4. **`both`是任意平均。** 余弦与上述非标准entropy直接各占一半，没有开发集、尺度校准或预注册依据，也没有使用P0-L支持的Noise/WSE得分体系。
5. **0.3阈值没有校准。** P0-L验证的是冻结候选排名和Top1-Top2间隔，不曾授权对这个新平均分使用0.3。没有match/no-match混合数据，无法把阈值解释为错误率或置信度。
6. **500 ppm质量窗与P0协议不一致。** P0-L使用冻结10 ppm候选邻域；本作业放宽到500 ppm，却没有重新评价错误映射和no-match风险。
7. **没有可审计分配明细。** 结果目录仅有214字节的汇总JSON，没有坐标注册表、查询—坐标得分、两个被接受的身份、输入哈希或弃权原因，不能复核2个匹配。
8. **feature与效应矩阵对应没有验证。** 查询为262张谱，而Stage-1曾登记263个QC家族；代码按数组顺序静默取前262列，没有断言`family_id`与MGF标题一一对应。
9. **坐标效应实现不符合预定方法。** 多个特征落到同一坐标时只保留得分最高的一个，而不是使用技术可靠度和映射权重投影；没有特征内标准化，也没有不确定性传播。
10. **LIPn分支本身不可运行。** 内嵌Python仍含`PLACEHOLDER`；随后把EIC矩阵直接当作含`patient_effect`的效应文件，并重复使用HSST3n MGF作为第二平台谱图。即使压缩包存在，也不能形成独立LIPn谱图投影。
11. **全部2,000坐标都有已知IK14。** 因而该试跑没有构造稳定的未注释坐标，更不可能检验dark-entity相对known-only的增量。

## 正确顺序

1. P0-G：固定参考字典，加入正确坐标不存在的no-match查询，校准错误强制映射和弃权；
