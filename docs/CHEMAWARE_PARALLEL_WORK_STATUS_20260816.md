## 五、接下来的严格优先级

1. **先完成 P1，再跑锁定评估。** 首先回答全量微调是否在困难任务上稳定改善，同时不损伤随机检索与结构相关性。
2. **完成验证集 MCES 缓存并审查三元组产量。** 数据量足够才进入训练；不足则先扩候选图。
3. **运行三组消融。** 把 P1 的有效成分拆清楚，再决定是否保留峰遮蔽或困难负样本项。
4. **把模块2证据按错误类型做案例册。** 优先解释 P1 修正的样本和仍未修正的样本，验证模型改善是否发生在预期机理上。
5. **再考虑模型内部改造。** 只有 head 训练确认到达上限后，才进入最后一层 adapter 或峰 token gate；目前没有证据支持直接大幅改动整个 Transformer。

## 六、当前结论边界

- 已有证据支持“DreaMS存在可重复的局部错误机制”，也支持反事实 head 可在困难子集上做小幅无回退修正。
- 尚未证明整个 embedding space 已被优化，也尚未证明隐式因子对应唯一化学机理。
- P1、MCES局部排序和模块2证据链是相互衔接的三部分：P1修正错误，MCES提供独立结构顺序，模块2核查修正是否有具体峰级依据。
