# "加入噪声"增强的文献依据与机理说明 —— 逐问回答

> 目的：回应"你现在的加入噪声是什么策略？来自哪个文献？业内公认吗？顶会吗？
> 有没有文献证明能解决谱图解析/同分异构体？为什么适配？" 并给出面向团队的机理依据。
> **口径约束**：本文只给"机理依据与潜力来源"，不承诺"必然提高"。最终以 500 例困难样本 /
> 100 硬三元组的消融数字为准。

---

## 0. 先纠正一个命名（最重要）

我实现的**不是字面上的"加噪声"（Gaussian 扰动）**，而是 **掩码峰建模 / 峰级 dropout
（Masked Peak Modeling）**：

- 随机选一小批峰（强度越高越容易被选，30% 可掩峰），把它们的 **m/z 和强度同时置 -1**；
- 这 **-1 就是 DreaMS 自己的掩码 token**，不是随手定的噪声值。

所以准确的说法是：**把 DreaMS 预训练时的"掩码峰预测"目标，作为微调时的输入增强补回来**。
"加噪声"只是口语叫法。这个区别必须讲清楚，否则团队会以为我们在谱上叠加随机数。

## 1. 逐问回答

### Q1 这是什么策略？
**掩码峰建模（Masked Peak Modeling）**，具体是预训练同款的
"强度正比 m/z 掩码 + 掩码 token -1"：
- 可掩峰 = intensity ∈ (0,1)（排除 precursor 行 0、base peak 1.0、padding 0）；
- 掩码数 `n_masks = max(2, round(n × 0.3))`，按强度比例采样（`intens_p`）；
- 命中行 m/z 和 intensity 都置 -1；
- 对 anchor / positive 双侧施加，negative 不掩。

### Q2 来自哪个文献 / 什么出处？
**DreaMS 论文本身**，不是外部论文：
- Yilmaz et al., **"Self-supervised learning of molecular representations from
  millions of tandem mass spectra using DreaMS"**, *Nature Biotechnology*, 2025.
- https://www.nature.com/articles/s41587-025-02663-3
- 预训练目标原文就写着 **"Masked Peak Prediction + Retention Order"**，其中
  "Masked Peak Prediction" 就是随机掩 30% 的峰、让模型预测被掩峰的 m/z（分类，非回归）。

出处证据在本仓库：
- `dreams_analysis/03_pretraining.md`（§"目标 1: Masked Peak Prediction"，
  §"遮罩策略"：随机遮 30% 峰、排除 precursor、mask_val -1、可选 BERT 80-10-10）；
- `dreams/training/pre_train.sh`：`--frac_masks 0.3 --mask_intens_strategy intens_p`;
- `dreams/utils/data.py` `MaskedSpectraDataset`：`mask_val=-1`，`mask_prec=False`。

### Q3 是业内公认的吗？
**是。分两层说：**

1. **范式层面**：掩码/去噪自监督学习是深度学习过去 5 年最主流的范式之一，谱系清晰：
   - 去噪自编码器 Vincent et al., *ICML 2008*（"Extracting and Composing Robust
     Features with Denoising Autoencoders"）——掩码/损坏输入的鼻祖；
   - **BERT** Devlin et al., *NAACL 2019*——掩码语言建模，把"随机掩掉一部分输入再预测"
     变成标准做法；
   - **MAE** He et al., *CVPR 2022*——掩码自编码器，视觉版同款范式。
   这一脉后来直接长出了 GPT/LLM。掩码-重建是**公认的通用表示学习方法**。

2. **质谱领域**：DreaMS 用这套掩码目标预训练，成为**当前质谱表示学习的事实 SOTA 基座**
   （论文中在结构相似性等任务上超过 MS2DeepScore 等既有方法）。

### Q4 是哪个领域的顶会文章？
需要精确：**它不是"会议"论文，而是 Nature Biotechnology 期刊论文**（2025）。
Nature Biotechnology 是生物技术领域的顶刊（IF ~33），含金量**高于**一般 ML 顶会
（NeurIPS/CVPR/ICML）。它继承的掩码范式源头才是顶会：BERT(NAACL'19)、MAE(CVPR'22)、
去噪自编码器(ICML'08)。

### Q5 有没有文献证明能"解决谱图解析/提高分辨率/增强同分异构体"？
**诚实回答：没有一篇论文直接证明"掩码 → 提高同分异构体区分"这条因果链。** 如果谁这么说，
是过度承诺。能站得住的证据只有两层：

1. **已证**：用这套掩码目标预训练的 DreaMS，是质谱表示的 SOTA 基座；掩码/去噪训练是
   公认的鲁棒性机制（防过拟合、防依赖单峰）。
2. **未证（我们的假设）**：把同一套掩码**在微调阶段补回**，能否扩大那 1–2pp 困难样本
   增益、能否改善同分异构体区分——这**必须靠消融实验测**，不能口头保证。

所以对团队的正确表述是：**"方法有公认的鲁棒性机理背书 + 与模型原生训练分布一致，
因此有强的先验潜力；但同分异构体那条具体因果链，是我们的待验证假设。"**

### Q6 为什么适配（adopt）？
三个理由，从硬到软：

1. **训练/推理分布一致（最强理由，不依赖任何外部论文）**。DreaMS 预训练时，输入
   **长期带 30% 掩码**；微调时我们却给"完整无掩码"谱，然后推理也是完整谱。这本身是
   分布漂移。把掩码补回微调，是**恢复模型见过的输入分布**——这是"train/test consistency"
   的常识，不是新算法。

2. **直接命中错误图谱的 FN 机制**。审计已定位：FN 错误来自"仪器/CE 特异的峰"
   （同一分子在不同采集条件下的峰不同）。掩码训练教模型**不依赖任何单峰、学会在峰缺失
   时仍判对**，正是治 FN 的方向。

3. **与现有增强正交、不冗余**。删除峰(反事实)、掩唯一峰(chemmask) 都是"有目标地删"；
   掩码峰是"随机强度正比地掩"，补上了"随机鲁棒性"这个空位（审计 §4.2 已列为 #1 改进）。

## 2. 为什么比之前更具潜力（面向团队）

先立一个总纲：**我们之前的增益主要来自"有方向、有目标的干预"（删真峰/删假峰/掩唯一峰/
共享难负例），它们打的是"让模型看对特定峰"；缺的是"让模型在峰缺失时不崩"——这正是
预训练掩码补回之后新增的那一块。两者相加 = 定向因果 + 通用鲁棒，覆盖了错误的两个来源。**

### 2.1 同分子量不同分子式（等重/异构质量）
- **机制**：这类分子 MS2 里往往有一批**共享的高强度碎片**（撞脸峰），区分靠的是少数
  **低强度特征峰**。模型若过度依赖共享强峰，就会误判。
- **掩码的作用**：强度正比掩码**优先掩掉强峰**，逼模型在没有最强共享峰时仍能靠
  次级特征峰判对——把注意力从"共享主峰"赶到"区分性小峰"。这直接对应 FP 方向
  （拒绝撞脸分子）。

### 2.2 同分子式不同结构（同分异构体）
- **机制**：同分异构体的谱差异常常集中在**一两个峰的位移/强弱**，而非整谱大改。模型若
  只盯一个主导峰，很容易漏掉那一两个关键峰。
- **掩码的作用**：随机掩掉部分峰后，模型**不能依赖单一判别峰**，必须学习"多个峰的联合
  证据"——这正是区分同分异构体所需的表示。这是**机制上 plausible、但需验证**的假设
  （见 Q5）。

### 2.3 同结构不同采集条件（仪器/CE/能量变化）
- **机制**：这是错误图谱的 FN 主因。同一分子在不同 CE/仪器下，峰的出现/缺失/强度会变。
  完整谱训练会让模型"记住"某一条件下的峰集合，换条件就崩。
- **掩码的作用**：训练时随机让峰"消失"，等于**模拟了峰缺失的不确定性**，让嵌入对
  "哪些峰在/不在"鲁棒。这是掩码最**确定**能帮到的一类任务（本身就是去噪鲁棒性的定义）。

### 2.4 之前的种种任务（严格 10ppm 检索 / ROC-AUC / Pearson / Top-1 / 硬三元组）
- 严格 10ppm `s(q,p)>s(q,n)` 的成败，取决于"q 和 p 的余弦是否比 q 和 n 稳"。掩码让
  q 的嵌入**不随峰的随机缺失而漂移**，直接增强"同一分子两次采集余弦稳定"，这正是
  硬三元组想要却一直没补上的那一环。
- 对 ROC-AUC / Top-1 这类**排序**指标，鲁棒性提升通常意味着"正例的边界更稳"，是
  正向而非破坏性。

## 3. 联合损失各项的提升潜力在哪、为什么各有不可替代的潜力

先声明："不可估量"是口语，**科学表述应该是"每项都有独立、非冗余、指向不同错误机制的
潜力"**——合起来覆盖错误图谱的不同象限，所以整体潜力大，而不是每项都等于"翻倍"。

| 损失项 | 打的错误象限 | 潜力来源 | 独立在哪 |
|---|---|---|---|
| 标准三元组 `triplet` | 基础正/负排序 | 把 q 拉近 p、推远 n | 所有项的底座，但只有它不行（没打"峰级因果"） |
| `identity_cf`（删真峰→margin 必须降） | 真峰被高估 | 逼模型承认"真峰支撑正例" | 方向性因果，唯一"删了必须往正确方向走"的项 |
| `confounder_cf`（删假峰→margin 必须升） | 假峰误导 | 逼模型"删掉干扰后更信正例" | 与 identity_cf 成对，方向相反 |
| `preserve`（teacher 保真） | 不破坏已学表示 | 保底，防灾难遗忘 | 压住其它项的副作用，本身不产增益 |
| `random_consistency`（删随机峰→嵌入不变） | 随机峰不应影响嵌入 | 让嵌入对"无关峰的缺失"不变 | 与"有目标删峰"互补：它测的是**中性**删峰 |
| `shared_major_score`（共享峰难负例） | FP/撞脸分子 | 主动挖"和 anchor 最像"的负例 | 唯一在**负例侧**发力的项 |
| `mask_unique_peaks`（掩唯一峰） | FN/条件特异峰 | 让模型不依赖本侧独有峰 | 与 shared_major 成对：一打负例侧、一打正例侧 |
| **`mask_noise`（本次新增，强度正比掩码）** | **随机缺失的鲁棒性** | 恢复预训练分布 + 逼模型多峰联合证据 | **唯一"随机、无目标"的项**，补上之前全部缺失的通用鲁棒象限 |

**一句话总结潜力**：之前的损失项几乎都是"**有方向的**"（删这个、掩那个、挖这个负例），
唯独缺"**无方向的随机鲁棒**"。`mask_noise` 补的是这个空位，且它复用的是模型**预训练时
早已学过的输入分布**——所以它不是"又加一个玄学项"，而是"把模型本该有的输入条件还给它"。

## 4. 结论边界（必须写清）

1. 以上是**机理依据**，不是"必然提高"的保证。每条"潜力"都对应一个可测假设。
2. 同分异构体区分那条具体因果链，**无文献直接证明**，是我们本次消融要验证的核心问题。
3. 下一步：head-only smoke（噪声开）→ 500 例困难样本 / 100 硬三元组，与
   `best_counterfactual.pt` 基线对比。**数字决定结论。**
