中 5 个类级命中的邻居 **3/5 含氟**（C14H10F2N4、C8H7FN6O、C14H15F3N4O）——
含氟芳香/杂环是药物样骨架的强先验（含氟药物占上市小分子 ~20-25%）。
假说：这些暗模块可能是**患者术前用药（或其代谢物）的肿瘤/癌旁蓄积信号**，
而非肿瘤内源代谢。若为真，应从"肿瘤差异代谢物"叙事中剔除或单列为暴露标志。

## 2. 核查步骤（表型盲，先冻结后打开）

1. **邻居结构展开**：对每个含氟邻居 IK14 取 SMILES（manifest 已有），
   检索公开药物库（DrugBank/OpenTargets/PubChem 同骨架子结构匹配），
   列出候选药物名单（含适应症：化疗/降压/精神类等）。
2. **效应方向分层**：五模块的肿瘤 vs 癌旁 log2fc 与患者级一致性
   （lcnec_hsst3n_priority_patient_covariation_v1 工件）并入表。
3. **用药史交叉**（关键步，需临床元数据权限）：LCNEC 队列若含术前用药记录，
   检验"含氟命中模块的效应量是否被用药史（尤其含氟药物：如 5-FU 类、
   氟喹诺酮、某些 TKI）解释"。无用药记录则此步标记 NOT_AVAILABLE，
   结论降级为"暴露假说，未检验"。
4. **共洗脱排除**：用 lcnec_hsst3n_dark_eic_gate 的 EIC 矩阵核查五模块
   峰形与已知药物 RT（若有）不共洗脱。
5. **判定规则（预注册）**：
   - 用药史解释 ≥2 个含氟模块 → 三模块改标"药物暴露标志"，移出肿瘤代谢叙事；
   - 无解释且患者内一致 → 维持肿瘤相关暗模块资格，含氟仅作结构先验；
   - 部分解释 → 分栏报告，禁止合并叙事。

## 4. 边界

- 邻居是**类级类似物**（Δm/z 0.007-1.09 Da），不是身份确认；
  用药史核查只裁决"暴露 vs 内源"，不产生结构主张；
- 结构层结论永远等标准品/正交证据（三层主张体制不变）。
