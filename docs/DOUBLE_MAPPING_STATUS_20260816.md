# 化学可解释性双重映射：实现状态与接口

## 1. 核心对象

双重映射不是把规则名称贴在embedding上，而是验证以下可证伪链条：

`全局/峰级 embedding → 化学概念或局部结构特征 → 具体谱峰与质量差`

并增加忠实性检验：

`删除被定位的谱峰 → 对应概念得分应比匹配随机删峰下降更多`

只有同时满足可解码、可定位和干预方向正确的概念，才允许进入模块2解释输出。

## 2. 第一层：embedding 与化学概念/结构特征的对应

### 2.1 全局 embedding 到实验碎裂概念

已为45,185张MassSpecGym验证谱图重新计算谱图级335维规则标签。与旧的分子级缓存不同，同一分子的不同实验谱图分别标注本次实验实际观察到的质量模式。零padding峰被严格排除。

在5,706个分子上按IK14做完全隔离的70/15/15划分，每个分子最多保留3张谱图。冻结DreaMS，只训练线性探针：

| 指标 | 结果 |
|---|---:|
| 进入探针的CF/NL/ISO概念 | 266 |
| 测试集分子 | 856 |
| 测试集谱图 | 2,185 |
| test macro-AUPRC | 0.659 |
| macro流行率基线 | 0.200 |
| AUPRC达到各自基线至少2倍的概念 | 254/266 |

分类型结果：CF平均AUPRC 0.504（平均基线0.062），NL为0.741（0.266），ISO为0.364（0.114）。因此，冻结的官方DreaMS全局embedding中确实存在可线性读取的“实验碎裂概念方向”。

该结论不等于embedding已经编码唯一分子子结构。规则标签描述观察到的质量模式；一个质量模式可能对应多个碎片结构或断键机理。

### 2.2 峰token因子到分子结构环境

既有无监督峰token因子结果已统一整理：

- 10个稳定谱峰因子；
- 8个在独立确认集中复现“因子—峰质量”对应；
- 2个复现“因子—分子结构环境”富集；
- 2个同时满足结构环境、峰质量和全局embedding删峰效应。

当前两个闭环候选：

| 因子 | 峰质量 | 复现结构环境 | OR | 规则关联 |
|---|---:|---|---:|---|
| 176 | m/z 67.06 | `ccc` | 9.41 | 16条MassBank记录组 |
| 117 | m/z 91.06 | `ccc` | 9.38 | 2条核心规则、6条MassBank记录组 |

`ccc`仍是较粗的芳香碳局部环境，尚不足以给出唯一候选子结构。

### 2.3 全局 embedding 到数据驱动局部结构环境

为降低现有规则库偏置，已直接从5,706个已知结构中枚举半径1/2的中心原子环境。只按分子支持度筛选，不使用embedding或任务结果选择标签。每个分子的实验谱图embedding先取均值，再在Murcko骨架隔离划分上训练冻结线性探针：

| 指标 | 结果 |
|---|---:|
| 初始局部环境词表 | 800 |
| 进入探针的环境 | 469 |
| 测试分子 | 856 |
| test macro-AUPRC | 0.240 |
| macro流行率基线 | 0.0447 |
| AUPRC达到各自基线至少2倍的环境 | 396/469 |
| 测试集中至少20个阳性分子的环境 | 229 |

高可解码环境包括多种含氧糖样局部环境、支链碳、胺、氯代芳环等。这证明DreaMS的分子平均embedding中存在超出现有规则库的局部结构方向；下一步需要把这些结构方向与谱图概念及峰级归因求交集。

### 2.4 结构环境与谱图概念的交叉映射

在发现集和Murcko骨架隔离确认集上，分别检验可解码结构环境与可解码谱图概念的富集关系；两边均要求BH q≤0.05、OR≥2，并要求确认集至少5个共同阳性分子。29,484个候选组合中：

- 1,260个组合在两套数据上复现；
- 再以全部候选方向余弦的99百分位（0.120）作为embedding方向一致性门槛，保留175个候选；
- 涉及40种局部结构环境和43种谱图概念。

例如，`r1:N(C)(C)C`与m/z 70.0651的immonium候选峰在确认集OR=7.01，两个探针的原始embedding方向余弦为0.132。该结果形成“结构环境—embedding方向—谱图质量概念”的候选桥梁。它仍可能受到分子类别、仪器和采集条件混杂，必须经过逐谱图删峰验证后才能进入最终解释。

## 3. 第二层：化学概念与谱峰证据的对应

对规则概念，根据规则质量和谱图峰列表定位支持峰或支持峰对：

- CF：定位目标m/z附近的峰；
- NL：定位产生目标质量差的峰对；
- ISO：定位落在同位素质量差区间的峰对。

对无监督因子，根据独立确认集中的峰token激活定位峰质量。模块2现有证据记录已覆盖：

- discovery：5,116条定向谱图对、46,071条峰证据；
- confirmation：1,152条定向谱图对、9,600条峰证据。

MassBank单记录规则已折叠为质量别名组。质量匹配只产生候选注释，不宣称唯一结构。

## 4. 忠实性闭环

已有两个因子完成峰删除干预：

- factor 117：目标峰删除相对匹配随机删峰产生额外全局embedding位移，95% CI为[0.0021, 0.0056]；
- factor 176：额外全局embedding位移95% CI为[0.0033, 0.0080]。

两者的严格10 ppm检索margin效应置信区间均跨0。因此当前能证明“峰是该embedding因子的真实输入来源”，还不能证明该因子已经控制检索判断。

新的概念级忠实性验证正在运行：对独立测试分子上的高AUPRC概念，比较支持峰删除与强度/质量匹配随机峰删除后对应概念logit的变化。

## 5. 模块接口

### 模块1传给模块2

- 全局ChemAware embedding；
- Top-K候选关系与相似度；
- 最后一层峰token embedding及对应m/z、强度；
- 266个谱图概念logit；
- 模型权重与探针版本。

### 模块2输出

- 被解码的概念及其测试集AUPRC/基线；
- 支持该概念的谱峰或峰对；
- 候选规则组、隐式因子和局部结构环境；
- 支持、冲突或证据不足状态；
- 删峰忠实性结果与结论边界。

P1训练的是projection head，DreaMS主干峰token不变。因此峰级映射可以先独立开发；P1结束后需要重新校准全局概念探针，并比较官方embedding与P1 embedding的概念可解码性和忠实性。

## 7. 多线优先级

1. 完成概念级定向删峰闭环，确定可进入解释输出的概念数量。
2. 用RDKit局部原子环境、官能团和键变化标签替代粗粒度`ccc`，扩展embedding—分子结构映射。
3. P1结束后在同一测试分子上重新拟合/校准探针，检验P1是否提升概念可解码性。
4. 将P1修正与未修正的困难样本接入模块2，检验修正是否由预期峰和概念驱动。
5. 只有通过上述门槛的概念才参与困难样本反馈；未通过的规则只作为候选证据，不进入训练距离标签。
