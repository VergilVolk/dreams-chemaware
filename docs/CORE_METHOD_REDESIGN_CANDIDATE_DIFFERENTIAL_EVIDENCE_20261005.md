# 核心方法再设计：从“模块融合”改为候选差分证据

日期：2026-10-05；2026-10-07 深挖修订  
状态：**Phase 1 已实现并得到关键负结果；完整方法仍未验证，不得写成已完成算法。**

## 0. 最终裁决

此前的三条提法都不足以承担主创新：

1. **专家路由、加权融合或堆叠**：本质上是算法选择或学习排序；Percolator、COSMIC、PeakDecoder 以及大量多证据排序方法已有成熟先例。
2. **候选集合、拒判和层级输出**：2026 年已经出现面向质谱分子检索的 conformal prediction；层级选择性分类也已有通用理论。
3. **潜在匹配下的 e-value / 复现检验**：record linkage、partial conjunction、e-BH 分别已有成熟理论。它可以成为下游生物学统计工具，但不是本项目的核心算法创新。

条件似然比分解也不能单独算新方法。链式分解、条件密度比和相关证据融合都是已有统计工具。若只是把 Noise、P2b、ChemAware 的输出换成三个 likelihood ratio 再相乘，审稿人仍会把它归为 feature fusion。

本项目真正值得投入的唯一核心问题应改为：

> **对于一个查询谱和两个近结构候选，找出只支持其中一个候选的差分谱学证据；再检验该证据是否与两个候选之间的化学差异一致，并且这种一致性是否严格超过同一分子跨实验条件产生的谱图漂移及候选置换、规则反向和峰置换等伪解释。**

简短名称使用“**候选差分证据重排**”。不要再创造宏大缩写，也不要把它叫多模态基础模型、因果发现或新范式。

它与现有方法的根本区别不是输入更多，而是改变待估计对象：

- 现有全谱方法主要问：`query 与候选 A 有多像？`
- 普通融合主要问：`多个分数怎样组合能提高准确率？`
- 本方法问：`在 A 与最强竞争者 B 之间，哪些观测只支持 A；这些差异是否真由 A/B 的结构差异解释，而不是由实验条件或流行规则造成？`

如果这个问题在独立外部数据上不能产生正的条件增量，项目就没有新的融合方法；应退回 Noise encoder + 独立重排器的工程组合，不再包装。

## 1. 最新文献把哪些“伪创新”堵死了

### 1.1 不能再把谱图—结构对齐称为新意

- FLARE 已进行峰级与原子级的细粒度谱图—结构对齐。
- CSU-MS2、MSAlign 已将谱图编码器与分子编码器置于共享空间；MSAlign 直接使用冻结 DreaMS 与 ChemBERTa 加轻量投影。
- 因此“DreaMS + 分子表示”“峰与结构对齐”“不训练大型多模态模型而只训练小头”都不是足够的新意。

### 1.2 不能再把结构变换预测称为新意

2026 年 STEP 已从谱图对预测离散结构变换，并明确以 DreaMS 为组成部分。我们不能声称首次把谱图差异与结构变换联系起来。可争取的边界只能是：**不预测一个通用结构变换标签，而是对当前候选集合内 A 相对 B 的特异解释做成对反事实检验，并直接服务于候选排序。**

### 1.3 不能再把“不确定性输出”称为新意

- 2026 年的 conformal molecular retrieval 已给出覆盖率受控的候选集合。
- 2026 年的 query-focused bootstrap 工作已给出单匹配支持度与排序稳定性。
- COSMIC 已使用多种分数和校准器估计高置信结构注释。

所以本文可以使用校准、拒判和置信区间，但它们只能是验证工具，不能写成首创贡献。

### 1.4 不能再把多证据重打分称为新意

PeakDecoder、Percolator/MS2Rescore、COSMIC 和最新的多源注释工作都已经展示：把多个分数送入 SVM、线性模型或学习排序器并估计 FDR，可以提高检索性能。当前 grand-fusion router 和 MSG stack 都是必要基线，而不是论文核心。

### 1.5 文献审计后的窄创新边界

截至 2026-10-05 的定向检索没有发现一个直接同时满足下列四点的方法：

1. 以**同一查询内的候选对**而不是单候选绝对分数为基本单位；
2. 只计算候选 A 相对 B 的**排他性碎片、中性丢失和质量差证据**；
3. 用同分子多条件实测谱估计实验漂移空分布；
4. 用候选置换、规则反向和峰置换估计化学解释空分布，再取二重差分。

这不是优先权证明。正式投稿前仍须做专利、会议和预印本复检。当前只能说它是本仓库资源能够支持、且与最新直接竞争工作有清晰差异的候选方法。

## 2. 方法的最小定义

设查询谱为 `q`，候选集合为 `C(q)`。基础模型给出每个候选的全谱得分。只对前 `M` 个候选构造有序候选对 `(a,b)`，其中 `b` 是 `a` 的强竞争者。

### 2.1 基础身份边界：双表征，不做逐查询路由

```text
G_ab = alpha_N * z[Delta S_Noise(a,b)]
     + alpha_C * z[Delta S_Chem(a,b)]
     + alpha_W * z[Delta S_WSE(a,b)]
```

`S_Noise` 使用当前已外部确认的 Noise V1/T1-T3 encoder；`S_Chem` 使用 ChemAware 共享权重；WSE 是非学习谱学锚。三个分数先在训练折内按候选规模、参考谱数量和来源分层校准，再形成候选对差分。`alpha` 必须满足非负与和为 1 的约束，并通过 formula/source 外折的 group-DRO 目标冻结：优化最差来源或仪器组的候选对损失，而不是平均准确率。

这一步承认 Noise 与 ChemAware 权重都可能有价值，但不再训练逐查询“信哪个专家”的路由器。若 ChemAware 在统一候选图上对 Noise 错误没有外折残余 headroom，`alpha_C` 必须允许精确收缩到零；“开发期涨过”不是强制保留它的理由。官方 DreaMS、P2b 和 MSG 不直接重复加入 `G_ab`，它们用于必要基线和后续局部证据。

### 2.2 候选排他性的局部谱学证据

对 A/B 的参考谱，只保留能够区分二者的观测：

- A 有而 B 无的稳定产物离子；
- A 有而 B 无的稳定中性丢失；
- 只在 A 的峰间质量差中出现的关系；
- 在多张参考谱中重复、但不是单张谱偶然峰的证据。

共享碎片不给 A 或 B 加分。P2b 的全局 neutral-loss 相似度不能直接使用，因为它在 near-core 上有害；它应被拆成候选对层面的差分通道。WSE 和 MSG 提供附加谱学视图，但也只能贡献 A-vs-B 的差异。

Phase 1 已证明“排他峰个数”不能作为局部差分：参考谱更多的候选会积累更多排他峰。必须把每个候选的参考谱视作对实验条件分布的抽样，而不是可无限累加的票数。对每个方向采用等机会构造：

1. 两个候选各抽取相同数量的参考谱；不足时不重复采样；
2. 每张参考谱分别计算峰、neutral loss 和峰间质量差支持，再在候选内取稳健均值或中位数；
3. 每个方向只保留固定 `K` 个由参考谱稳定性预先选出的排他事件；
4. 分数除以可观测事件数，缺失证据记为零贡献，不记为反证；
5. 对抽样重复取中位数，并报告参考谱抽样方差。

记参考机会平衡后的局部差分为：

```text
L_ab_bal = balanced_local_evidence(q,a | b)
         - balanced_local_evidence(q,b | a)
```

它同时满足共享证据归零、候选交换反对称和参考谱机会平衡。只有这三个性质同时成立，才可能解决 P2b 在 near-core 失败及 Phase 1 的参考谱数量混杂。

### 2.3 化学解释的双重对照

ChemAware 对 A/B 的结构差异生成候选特异解释 `H_ab`。对同一个 `(q,a,b)` 同时计算：

- `H_real`：A/B 的真实候选差异及正确方向规则；
- `H_rotated`：候选身份轮换，但保持边际分布；
- `H_reversed`：相同规则反向；
- `H_peakperm`：保持峰数和强度边际的峰置换；
- `H_zero`：不提供化学解释。

空对照只用于估计特异性，不反向训练真实谱图，也不把 label-preserving 谱图当负例。这保留 A2 审计已经确立的边界。

### 2.4 同分子实验漂移对照

从 Noise 的多条件实测谱中，取同一分子的两张谱形成 `L_nuis`。这里真实化学差异为零，但仪器、碰撞能和峰缺失可以变化。它回答：某个化学规则是否只是碰巧解释了常见实验漂移。

### 2.5 唯一核心统计量：三重空对照的交集门

令 `T_real=F(L_ab_bal,H_real)`。分别在匹配空分布中将它标准化：

```text
Z_chem = robust_z[T_real ; F(L_ab_bal, H_chemical_null)]
Z_ref  = robust_z[T_real ; F(L_refnull, H_real)]
Z_nuis = robust_z[T_real ; F(L_nuis, H_real)]

D_ab = min(Z_chem, Z_ref, Z_nuis)
```

其中：

- `H_chemical_null` 是 rotated、reversed、peak-permuted 和 zero；
- `L_refnull` 在相同 formula、参考谱数量、峰数、仪器和来源条件下交换候选参考谱，专门估计“参考谱机会”伪增益；
- `L_nuis` 是同分子跨实验条件差分；
- `robust_z` 首选匹配空分布的中位数与 MAD，MAD 退化时用条件经验分位数，不使用容易被长尾牵引的简单均值；
- `F` 从受限单调双线性函数开始，不使用大模型。

直观解释只有一句：

> 参考机会平衡后的真实候选差异，是否同时超过匹配参考谱空对照、伪化学解释和同分子实验漂移。

这里使用 `min` 而不是把三个残差相加：只有三个门都为正，`D_ab` 才为正；某一类反证失败不能被另一类很大的分数补偿。这是 intersection-union 纪律，不是把三个相关检验伪装成独立证据。

这不是因果效应；`D_ab` 是通过三类匹配空对照的**候选特异相容性下界**。论文中禁止使用“发现碎裂因果机制”。

### 2.6 最终排序：先形成候选对边流，再投影为全局排序

最终只包含两个可解释部分：

```text
M_ab = calibrated(G_ab)
     + sum_k gamma_k * calibrated(R_k,ab)
     + beta * positive_part(calibrated(D_ab))
```

- `R_k,ab` 是 P2b 的峰、neutral loss、熵和 MSG-OOF 等重排通道的候选对差分；所有 `gamma_k` 非负并可收缩到零；
- `beta` 只在内层公式隔离折冻结；
- `D_ab` 的外折条件风险下界不大于零时，精确设为零；
- 强制 `M_ba=-M_ab`，缺失通道贡献为零；
- 若没有候选获得足够的两两优势，保留基础排序或输出候选集合，不强行唯一注释。

不同通道可能形成循环矛盾，例如 A 胜 B、B 胜 C、C 又胜 A。不能假装任意 pairwise 头天然对应一个全局分数。对 top-M 完全候选图求加权最小二乘投影：

```text
s* = argmin_{sum_c s_c = 0} sum_(a,b) w_ab [M_ab - (s_a - s_b)]^2
rho_cycle = ||M - grad(s*)||_w / ||M||_w
```

`s*` 给出唯一全局排序；`rho_cycle` 是证据冲突比例。高循环残差时回退基础排序或扩大候选集合。该 Hodge/least-squares 投影不是本文的新数学，只是防止多个重排器被生硬投票后产生不可见矛盾的必要实现纪律。

这里不是让模型学习“信哪个专家”，而是把每个组件转换为同一个反对称候选对证据单位，再把其中可全局一致的部分用于排序，把循环冲突显式留作不确定性。

## 3. 三个现有模块怎样真正整合

### 3.1 Noise：定义不应改变的部分

Noise 不再只是第一根柱子的准确率，也不与 ChemAware 盲目串训。它有两个不可替代职责：

1. 提供已经外部验证的身份底座 `G_ab`；
2. 用同分子多条件实测谱构造 `L_nuis`，定义实验条件变化可以造成多大的假差分。

因此 Noise 的价值从“另一个专家分数”上升为**不变性参照系**。

### 3.2 P2b、WSE、MSG：发现局部差分，不投票

- P2b：提供峰匹配和中性丢失差分；near-core 负结果要求共享证据归零。
- WSE：提供对峰强度分布的独立描述，是外部强基线。
- MSG：作为学习型谱学融合基线，并可产生候选对的 OOF 谱学边界。
- RRF：外部确认失败，只保留为负对照；不得进入最终分数。

这样“所有组件都用上”不等于所有组件都进生产模型。失败组件必须在消融和否证中发挥作用，而不是为了齐全被强行加权。

### 3.3 ChemAware：解释差异，不提供无条件加分

ChemAware V2 现有多零语义正适合生成 `H_real/H_null`，但它此前仍以候选效用重排为主。新方法要求它只回答：A/B 的结构差异是否解释了观测到的 A/B 排他性谱学证据。

这使化学规则的独立贡献可被直接否证：

- 真规则不优于 rotated/reversed/peak-permuted：`D_ab=0`；
- 真规则只能解释同分子实验漂移：`D_ab=0`；
- P2b 差异没有化学特异性：`D_ab=0`；
- 只有局部差异与候选结构差异成对一致时，才改变排序。

### 3.4 BioAware：不进入核心方法首轮

BioAware B44-B46 已形成负证据，B47 尚有外部门。样本关系不能用于训练或选择上述主算法。只有谱图—化学方法完全冻结且 B47 通过后，BioAware 才可作为第三层候选对先验接受独立评价。

主论文不能靠 BioAware 凑齐“第三模块”。若 B47 不通过，生物学部分仍可使用冻结结构假说，但不得改变候选排序。

## 4. 为什么它可能是方法，而不是包装

### 4.1 新的不是二重差分公式，而是可否证的质谱估计对象

二重差分、残差化和两两排序都不是新数学。可争取的方法贡献是把代谢物候选判别重新定义为：

```text
候选排他性谱学差异
× 候选特异化学解释
− 实验条件漂移
− 伪化学解释
```

四类对象来自本项目已有的独立资产，而且对应四种不同失败模式。普通 stack 能提高准确率，却不能说明增益来自排他性碎片、条件漂移、数据库偏好还是候选身份捷径；这里每个非零增量必须通过两套反事实。

### 4.2 可以给出的四个性质

正式方法稿至少应证明或由构造保证：

1. **共享证据消去**：A/B 共同拥有的峰、损失或分数对 `L_ab` 贡献为零。
2. **候选交换反对称性**：交换 A/B 后 `G_ba=-G_ab`、`L_ba=-L_ab`、`D_ba=-D_ab`。
3. **冗余证据零贡献**：若真实化学解释与匹配空解释条件分布相同，则 `E[D_ab]=0`。
4. **实验漂移零贡献**：若真实候选差异的相容性不超过同分子多条件漂移，则 `D_ab≤0`，最终化学增量被截为零。

这些性质比“模型学会自动选择专家”更可审计，但仍不能替代外部结果。

### 4.3 最关键反例

必须在正文展示一个 P2b near-core 失败例：A/B 共享大量峰和中性丢失，整体 P2b 更偏向错误候选；差分化后共享证据归零，只有少数候选排他峰保留；若这些峰不能通过 ChemAware 真规则相对三类空规则及 Noise 漂移的双重门，系统保持原排序而不制造新错。

这个反例将方法、仓库负结果与设计动机连在一起。

## 5. 三位审稿人的最严厉意见与补强

### 5.1 计算方法审稿人

**拒稿意见：**“这只是 pairwise reranking、factorial control 和一个小交互头；数学组件都不是新的。”

这个批评成立一半。不能靠定理命名回避。需要以下实证补强：

- 与同参数量 MSG stack、grand router、直接线性加权、V2 ChemAware 和 `no-nuisance/no-chemical-null` 消融同台比较；
- 所有方法使用完全相同的 query、候选池、公式外折和调参预算；
- 证明提升主要来自 `D_ab`，而不是更大的模型容量；
- 在不读取真值的前提下，展示 `D_ab` 对 corrected 与 introduced 的分离；
- 给出 `O(QM)` 或小 `M` 下的明确复杂度，避免全候选 `O(K²)` 爆炸。

只有当候选差分方法在独立外部数据上优于同容量 stack/router，计算审稿人才可能接受“新估计对象带来新能力”。

### 5.2 质谱与组学审稿人

**拒稿意见：**“产物离子和中性丢失并不唯一对应子结构；所谓真实化学规则可能只是库偏好；同分子重复谱也不能覆盖所有基质和仪器漂移。”

必须补强：

- 所有化学动作按 formula、identity、source/lab 隔离；
- 对产物离子、中性丢失、质量差分别报告，不将其混成“机制”；
- 同分子漂移按仪器、碰撞能、加合物和谱图质量分层匹配；
- 报告证据覆盖率；无合格证据必须归零，不允许缺失本身成为候选特征；
- 对无标准品结果只称“候选结构排序改善”，不得升级为确定结构；
- 生物学结论永久区分谱图实体、化学类别和精确结构。

### 5.3 通用审稿人

**拒稿意见：**“Noise、P2b、WSE、MSG、ChemAware、BioAware 名字太多，读者看不出一篇论文到底发明了什么。”

主文必须压成一个方法、两层证据：

1. Noise 给基础身份边界和实验漂移参照；
2. 候选差分证据决定是否有资格改写边界。

WSE/P2b/MSG 是局部证据来源或对照，ChemAware 是解释器，BioAware 是后续应用。正文图不得再画六个并列专家框。

## 6. 冻结实验设计

### 6.1 开发与评价

1. **训练/开发**：只用已消费的 MassSpecGym 公式隔离折，做所有设计和阈值选择。
2. **内部确认**：使用未参与本轮设计的公式/身份隔离面板；若已被此前实验反复消费，只能称确认性开发。
3. **外部确认**：冻结后一次性应用到未参与任何组件训练、选择和阈值设定的外部谱库；当前 GNPS 面板已经被多次用于路线判断，不足以承担最终唯一外测，必须补一个新来源/新实验室面板。

### 6.2 必备比较臂

- official DreaMS；
- Noise V1；
- WSE；
- P2b；
- MSG stack；
- grand router；
- ChemAware V2；
- Noise + P2b 直接相加；
- Noise + ChemAware 直接相加；
- 不含实验漂移对照的差分方法；
- 不含化学空对照的差分方法；
- 完整候选差分方法。

RRF 只作已知失败负对照。BioAware 不参加这张主表。

### 6.3 主指标

- Top-1、MRR；
- corrected / introduced / `corrected-2×introduced`；
- near-core、同分子式和 top-2 小间隔子集；
- formula-cluster bootstrap 区间；
- coverage-risk 曲线；
- 化学证据触发覆盖率；
- `D_ab` 在纠正、引入和未改变查询上的分布；
- 相对 oracle union 捕获的比例。

### 6.4 成功门

完整方法只有同时满足以下条件才有论文资格：

1. 在统一外部面板上严格优于最佳单组件，而不只是优于 official；
2. 严格优于同容量 MSG stack 和 grand router；
3. formula-cluster CI 下界大于零；
4. `corrected > 2×introduced`；
5. near-core 不回退；
6. 完整方法严格优于 `no-nuisance` 和 `no-chemical-null`；
7. 增益在 identity-disjoint 与 formula-disjoint 至少方向一致；
8. 不使用候选数量、参考谱数量、数据库度数、真值派生字段或表型标签等捷径。

若只胜 official 而不胜 stack/router，结论是“工程组合有效”，不是方法创新。若双重对照消融与完整方法无差异，说明反事实设计没有贡献，应停止。

## 7. 最小实现顺序

本轮不先改 encoder，也不做 Noise→Chem 或 Chem→Noise 串训。串训无法回答化学信息是否独立，且仓库已有长训漂移和 matched-control 失败。

第一阶段只实现 CPU/轻量 GPU 的离线证据账本：

1. 从冻结候选图生成 top-M 候选对；
2. 把 P2b/WSE/MSG 拆成候选对差分；
3. 从重复谱库构造按条件匹配的 `L_nuis`；
4. 从 ChemAware V2 导出 real/rotated/reversed/peakperm/zero；
5. 计算无学习参数的原始 `D_ab`，先检查符号、覆盖和 null calibration；
6. 只有原始 `D_ab` 在公式外折上有正的风险净收益，才训练受限单调小头；
7. 通过内部门后再进行一次外部确认。

这一步的最高性价比在于：如果原始双重差分没有信息，可以在训练新模型前停止；如果有信息，再决定是否值得写轻量 listwise 头。

## 8. 对论文故事的修改

论文主线不再是“三个模块融合”。应改成：

> 全谱表征擅长识别总体相似性，但近结构候选共享大部分碎片，局部谱学重排又容易把共享证据重复计分。我们提出候选差分证据：只保留候选间排他性谱学差异，并要求其化学解释同时超过同分子实验漂移和匹配伪规则。该设计把条件稳健谱图表示、局部碎裂证据和候选结构规则变成一个可反证的排序量，而不是若干分数的堆叠。

建议主图：

1. 一个 A/B 近结构例子：共享峰置灰、A 特异峰和 B 特异峰着色；
2. 真实候选差异、同分子漂移、真实规则、伪规则构成的 2×2 证据表；
3. 完整方法相对 Noise、P2b、ChemAware、stack/router 的统一外部 benchmark；
4. corrected/introduced 与 near-core 安全性。

不再用“1+1+1>10”。若结果成立，准确表述是：**从绝对相似度转向经实验漂移与伪规则校正的候选差分证据。**

## 10. 当前结论

这条路线仍然不是“已经硬核”。它只是第一次把核心问题压缩到一个可以被最新文献、仓库负结果和外部实验同时检验的点。其论文价值取决于一个残酷条件：

> 候选差分的双重对照，必须在新的外部面板上胜过同容量 stack/router，并在 near-core 中减少而不是制造错误。

过不了，就没有 1+1+1 的方法学成果；只能诚实发表 Noise 的稳健谱图学习和若干独立重排结果。过了，才有资格声称本项目不是在堆模块，而是在改变近结构候选判别所使用的证据单位。

## 11. 2026-10-07 Phase 1 实证：原始排他证据为什么不能用

已实现 `tasks/GLM_candidate_differential_ledger.py`，在冻结 GNPS identity-disjoint 本地开发底物上构造 Noise top-5 的 77,195 个候选对。数值性质检查通过：

- `L_ba=-L_ab` 精确成立；
- 给 A/B 同时加入共享峰后所有通道不变；
- 查询支持的排他碎片覆盖 93.73%，排他 neutral loss 覆盖 93.72%，质量差覆盖 83.49%。

但真正决定方法生死的是错误救援集：在 1,913 个 Noise 排错且正确候选位于候选对中的比较上，碎片、neutral loss 和质量差的方向正确率分别只有 33.93%、33.87% 和 36.54%，明显低于 50%。错误候选平均有 2.06 张参考谱，正确候选平均只有 1.62 张；原始排他计数会系统性奖励有更多参考谱的候选。

因此：

1. 93% 覆盖率不是成功，可能只是参考库机会更多；
2. 总体 85% 左右的方向准确率主要反映基础模型本来就排对的容易样本，不能证明可纠错；
3. 原始 `L_ab` 若直接送入学习器，模型极可能学到参考谱数量和库覆盖捷径；
4. 下一步必须先实现 `L_ab_bal` 与 `L_refnull`，不得先训练融合头；
5. 这一负结果强化而不是削弱核心方法动机：真正需要估计的是超出“库里看得更多”的候选特异证据。

冻结证据：`data/validation/GLM_candidate_differential_ledger/ledger_p1_identity.json`。

## 12. 统一算法的两层架构

必须把“尽可能强的成品算法”和“论文中的核心方法增量”分开，否则会再次用性能包装创新。

### 12.1 全证据底座：最大化现有资产价值

该层负责性能，不声称原创：

1. 在全候选集合上同时计算 Noise、ChemAware 和 WSE 分数；
2. 用固定总预算的 top-M Pareto 候选池保留任一表征强烈支持的候选，报告 pool recall@M 和计算成本；
3. 用 formula/source 外折 group-DRO 冻结全局 `alpha_N/alpha_C/alpha_W`，禁止逐查询路由；
4. 把 P2b、MSG、谱熵、neutral loss 和 ChemAware V2 全部变成反对称候选对边流；
5. 用 Hodge 投影得到统一候选分数和循环冲突诊断。

这层回答“怎样把已有好组件最大化利用”。ChemAware 与 Noise 的好权重都获得正式入口，但必须通过统一候选图上的条件增量决定权重，不能把不同评价面板的百分点相加。

### 12.2 方法核心：三重反证后的候选排他证据

该层只回答一个问题：在全证据底座之上，`D_ab` 是否增加了普通 stack 学不到的、安全的纠错能力。它由四个不可替代的域知识约束组成：

- 共享谱学证据归零；
- 参考谱观察机会平衡；
- 真实化学解释必须优于匹配伪规则；
- 候选差异必须超过同分子跨条件漂移。

若全证据底座有效而 `D_ab` 无增益，项目得到强工程算法，但没有新的方法核心。若 `D_ab` 在新外部面板上仍超过同容量 stack，才有资格写“候选差分证据”。

## 13. Noise 与 ChemAware 权重怎样真正融合

### 13.1 先问是否互补，再决定是否合权重

在完全相同的 query、候选池和 molecule pooling 规则上，冻结报告：

- `Noise correct, Chem wrong`；
- `Noise wrong, Chem correct`；
- 两者都错但 WSE/P2b/ChemAware V2 可纠正；
- 错误重叠的 formula/source/instrument 分层区间；
- 在控制候选参考谱数与谱图质量后，Chem 对 Noise 错误的条件 oracle headroom。

若最后一项的 formula-cluster CI 下界不大于零，停止 task-vector、串训和蒸馏；ChemAware 共享权重只作对照，ChemAware 的局部化学空对照功能仍保留。只有存在稳定的条件互补，才值得比较三种表征整合臂：

1. 冻结双编码器 + 受限分数融合；
2. 预注册七臂 task-vector/TIES 合并；
3. Noise→Chem 与 Chem→Noise 的等步数、等数据、等优化器串训。

这些都是性能臂，不是主创新。赢家必须同时保住 Noise 的条件不变性和 ChemAware 的化学困难集，不能只看总体 Top-1。

### 13.2 最终才考虑蒸馏为单 checkpoint

只有全证据 teacher 经外部确认后，才训练单一 student：

```text
L_student = L_retrieval
          + lambda_N * L_preserve_Noise_pair_margins
          + lambda_C * L_preserve_Chem_pair_margins
          + lambda_T * L_match_teacher_ranking
```

蒸馏目标是部署简化，不承担发现互补性的任务。直接串训会发生灾难性遗忘，也无法判断性能来自何处，因此不能作为第一步。

## 14. 最新文献后的真实创新边界

2025-2026 年工作已经占据以下位置：

- JESTR、MSAlign：谱图与结构/分子基础模型的候选感知对齐；
- FLARE：峰与分子子结构的细粒度局部对齐；
- MVP：多谱图、共识谱和分子多视图联合表示；
- STEP/MT-GEM：从谱图对预测离散结构变换；
- conformal retrieval 与 selective prediction：候选集合覆盖保证和风险-覆盖；
- MCheM：用正交化学信息重排候选；
- MSFragger-DDA+：在其他质谱领域移除共享碎片后重打分。

所以不能把“双编码器”“局部峰解释”“结构变化”“不确定性”“正交证据”或“共享峰删除”中的任何一个单独写成创新。尚可争取的组合边界非常窄：

> 在小分子同分子式候选检索中，以完整候选图上的反对称边流为统一单位；对局部排他谱学证据做参考机会平衡，并同时用候选匹配化学空对照和同分子跨条件漂移空对照否证；最后只把全局一致的边流分量用于排序，把循环矛盾显式转成拒判信号。

这仍是待验证的优先权边界，不是已证明首创。

## 15. 下一轮代码与实验的严格顺序

### Gate 0：组件互补性账本

- 统一 molecule pooling 与候选图；
- 生成 Noise/Chem/WSE/P2b/MSG/V2 的 query×candidate 冻结分数；
- 输出错误交集、条件 oracle headroom 和候选池 recall@M；
- 若 Chem 权重无稳定残余 headroom，表征合并止步。

### Gate 1：修复 Phase 1 的观察机会偏差

- 实现等参考谱抽样、固定 K 排他事件和方向归一化；
- 构造 matched `L_refnull`；
- 在不训练任何头的前提下，要求 rescue-set 符号率超过 50%，且 corrected/introduced 风险净值为正；
- 若失败，停止候选差分主方法。

### Gate 2：加入 ChemAware 与 Noise 双反证

- 导出 real/rotated/reversed/peakperm/zero 化学解释；
- 构造按 instrument/CE/adduct/quality 匹配的同分子 `L_nuis`；
- 检查 real>null 与 real>nuisance 的分层区间；
- 只有无参数 `D_ab` 通过，才允许训练小头。

### Gate 3：受限统一排序器

- 非负、单调、反对称、缺失归零；
- 与相同参数量的线性 stack、HGB/MLP、router、无 null 消融同台；
- 用 Hodge 投影输出候选分数及 cycle residual；
- 预注册 cycle residual 的回退阈值。

### Gate 4：一次性新外部确认

- GNPS 已是开发/确认底物，不能继续承担唯一终测；
- 在新来源或新实验室面板上冻结运行；
- 主成功条件仍是胜最佳单组件、胜同容量 stack、near-core 不退化、formula/source CI 下界大于零、corrected>2×introduced。

BioAware B44-B46 的负结果必须作为“为何不把所有模块强行进分数”的证据；B47 未过外部门前不进入 Gate 0-4。

## 16. Gate 1 裁决（2026-10-07，预注册停止规则执行）

实现与结果：`tasks/GLM_gate1_fast.py` → `data/validation/GLM_candidate_differential_ledger/gate1_balanced.json`。

- 等参考抽样（n_eq=min(两侧)，4次抽样平均）+ matched reference null（同分子半分裂）后，营救集方向正确率 **28.53% [24.08, 32.98]**——不仅未过 50% 门，反而低于未平衡版的 33.9%；
- 翻转规则风险净值 corrected−2×introduced = 660−2×1120 = **−1580**；
- 可评对覆盖 36.2%（双侧 ≥2 参考谱；单参考谱分子无法构造 refnull）。

两项门全部失败。方向一致性揭示机制：在 Noise 排错的候选对上，查询谱整体上就更像错误候选（这正是排错的原因），排他证据计数无论怎样平衡观察机会都系统性指向错误方。**计数层的候选差分证据不可用；这不是加权或校准能修复的问题。**

按第 15 节预注册规则：**候选差分核心创新线就此停止。** 化学解释层（D_chem）与同分子漂移对照（L_nuis）不再实现——它们的前提（排他证据在计数层有正确方向）已被否证。

存活的部分（第 12.1 节全证据底座）：统一候选图上的多视图分数融合 + HodgeRank 一致性聚合，作为性能层（v0 实测：本地视图下与 WSE 持平，ChemAware encoder 槽位待服务器分数）。该层不承担方法学创新主张。
