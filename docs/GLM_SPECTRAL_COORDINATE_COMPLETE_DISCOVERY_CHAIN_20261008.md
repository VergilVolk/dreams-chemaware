## 完整发现链

### P0-L：坐标映射可行性（PASS）

**问题：** 隐藏结构名称后，同一分子能否跨仪器落入正确坐标？

**结果：** 15 方法 × 双面板 × 3 子集（全量/近结构/严格跨仪器）
- Noise V1 严格跨仪器 R@1 = **84.39%**，vs Official +1.64pp（CI [0.77, 2.49]）
- WSE 严格跨仪器 R@1 = **85.85%**，vs Noise +1.46pp（WSE 仍是最强单方法）
- 60% 覆盖率下错误率 = **1.56%**
- 近结构误合并率：Noise 降低 1.53pp

**结论：** 坐标映射可行。噪声鲁棒表示在跨仪器场景有真实增益。

### P0-G：绝对分数不是弃权信号（STOP — 重要的方法论负发现）

**问题：** 当正确坐标不在字典里时，绝对相似度分数能否检测到这一点？

**结果：** 70/30 身份分割，移除 held-out 查询的正例

| 指标 | Noise V1 | WSE |
|---|---|---|
| match 中位最高分 | 0.856 | 0.906 |
| no-match 中位最高分 | **0.857** | **0.912** |
| 分数分离 AUC | **0.507** | **0.500** |

**结论：** **绝对分数完全不能区分"找到正确坐标"和"找到相似但错误的坐标"。**
这是谱图相似度的本质属性，不是实现问题。

→ 数据：`data/validation/GLM_p0g/p0g_report.json`
→ 提交：`ffb2de2`

### P0-M：边际是有效的弃权信号（AUC 0.848 — 部署级置信层）

**问题：** 边际（top1−top2 分数差）能否区分 match 和 no-match？

**修正：** 初版错误地在 no-match 查询中保留了正例 → AUC 0.499（随机）。
修正后正确移除正例，仅用错误候选计算边际。

| 指标 | Official | Noise V1 | WSE |
|---|---|---|---|
| match 中位边际 | 0.335 | **0.456** | 0.593 |
| no-match 中位边际 | **0.048** | **0.055** | **0.035** |
| 边际分离 AUC | 0.828 | **0.848** | **0.872** |

**结论：** **边际能有效区分"有明确赢家"（正确坐标存在）和"多个错误候选互相竞争"（正确坐标不存在）。** 这是部署级的弃权信号。

**方法论发现：**
> 谱图相似度是一个检索工具，不是一个置信度工具。置信度来自边际（top1−top2），不来自绝对分数。这统一了之前三个"指标劈裂"发现。

→ 数据：`data/validation/GLM_p0m/p0m_report.json`
→ 提交：`c443c9a`

### P2 v2：LCNEC 坐标投影（97.7% 分配率，但中位分数仅 0.072）

**问题：** LCNEC 的 263 个 QC 合格特征投影到 124K GNPS 坐标后，多少可信？

**结果：**

| 置信层 | 数量 | 比例 |
|---|---|---|
| 高/中（margin > 0.1） | **23** | **9%** |
| 低（0.01 < margin ≤ 0.1） | 83 | 32% |
| 纯噪声（margin ≤ 0.01） | **157** | **60%** |
| 无候选 | 6 | 2% |

中位 top1 分数 = **0.072**。没有一个查询的 top1 > 0.5。

**最有趣的可信命中：**
- m/z 199.04 → C8H10N2O2S（cos 0.912，含硫）
- m/z 329.19 → C19H24N2O3（cos 0.873）
- m/z 362.05 → C18H20FN3O4（cos 0.746，**含氟**——又一个药物样骨架）
- m/z 138.06 → C7H9N2O+（cos 0.669，唯一 margin > 0.3）

**核心量化：**
> **LCNEC 263 个 QC 合格特征中，只有 9% 能用公共谱库可信地定位到已知化学空间。其余 91% 在当前谱学方法下是真正的暗物质。**

→ 数据：`data/validation/lcnec_p2v2/run_2354362/`
