# 化学—生物语境联合模型 A0：公共观察账本可行性合同

**日期：2026-09-12**  
**阶段：A0；只验证数据基础，不训练模型，不作生物学结论。**

## 目的

验证公开 StructureMASST/FASSTrecords 与 Pan-ReDU 元数据能否支持下一阶段的严格比较：

1. `B0`：普通谱库命中与命中次数；
2. `B1`：只使用仪器、极性、项目和样本技术信息的可检测性模型；
3. `M1`：化学谱表示、技术可检测性与生物语境的联合模型。

A0 只建立标准谱到项目/样本类型/组织/健康状态/仪器/极性的观察账本。它不证明 M1 有效，更不证明方法创新。

## 冻结抽样

- 从 GNPS-LIBRARY 的 commercial/isolated、具有 IK14 的代表谱中抽取；
- 八个 ClassyFire superclass，每类按 IK14 排序固定抽取八个，共 64 个 anchor；
- 一个 IK14 只保留一个代表谱；
- 固定命中阈值：cosine >= 0.85、matching peaks >= 4；
- blank、QC 与缺失元数据不删除，作为技术混杂审计。

这只是小型存在性抽样。若 A0 通过，A1 必须扩大 anchor 数量并在查看预测结果前冻结项目留出。

## 标签边界

- 达到阈值的谱匹配是一次 positive observation；
- 没有匹配是 unlabeled，不是“该生物系统中不存在”；
- blank/QC 命中是污染、背景或非特异性的风险信号；
- A0 不使用疾病标签选择阈值、样本或模型。

## A0 通过门

- 至少 40 个 anchor、覆盖至少 6 个 superclass；
- 至少 25 个 anchor 有公开命中；
- 至少 20 个 anchor 跨两个项目命中；
- 至少 15 个 anchor 跨两个生物样本类型命中；
- 元数据库覆盖至少 500 个项目；
- 仪器与极性字段可用于后续可检测性控制。

任一门失败均不得直接训练联合模型；应先改变数据抽样或数据来源，而不是降低统计标准。

## A1 的预注册比较

A1 以项目为不可拆分分组，先封存测试项目，再比较 B0/B1/M1。疾病、实验室和仪器信息只能按合同进入相应对照；任何“未命中”必须采用 positive-unlabelled 或显式 observation model。只有 M1 在 project-held-out 下同时超过 B0 和 B1，才进入未知谱邻域与双向任务。

## A0 初始抽样审计与 A0b 扩展（结果后追加，不覆盖原结果）

初始 64-anchor 运行采用按 IK14 字典序抽样。审计发现该顺序并非化学中性：抽中了 palytoxin、复杂天然产物等大量低公共可观察性参考谱。该运行永久保留在 `reverse_context_joint_a0`，不得删除或改写；它未通过原门（23 个有命中、17 个跨项目、10 个跨生物样本类型）。

A0b 只修复抽样代表性并扩大覆盖，不改变任何结果阈值：

- 每个 superclass 固定抽取 32 个，共 256 个 anchor；
- 使用 `spectrum_id_int` 的固定种子伪随机排列（seed 20260912），在查询结果之前冻结；
- cosine >= 0.85、matching peaks >= 4 及所有 A0 通过门保持不变；
- 输出到独立目录 `reverse_context_joint_a0b`；
- A0b 仍只回答数据是否足以支撑 A1，不回答模型有效性或生物学问题。
