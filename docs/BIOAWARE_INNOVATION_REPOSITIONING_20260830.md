# BioAware 创新性重判与项目重新定位（2026-08-30）

## 1. 结论

当前 BioAware 不能作为独立算法创新主张。若将它定义为“DreaMS 高置信种子 + Rhea/KEGG 邻居 + MS1/MS2/峰相关证据传播”，其核心思想已经被 MetDNA、KGMN、NetID、ChemWalker 和 MetDNA3 覆盖；当前实现的完整性、规模、外部验证和新代谢物确认还弱于这些工作。把传统谱图相似度替换为 DreaMS，或把 KEGG 换成 Rhea，属于组件替换，不构成方法学创新。

因此：

- BioAware v1/v2 降级为内部基线、失败诊断器和数据基础设施；
- 不再以“一跳传播”“两层网络”“多证据加权”“概率因子图”本身作为论文创新；
- 离子家族、MS1--MS2 桥接、候选证据账本、网络覆盖审计、冲突与弃权仍保留；
- 真正的算法主线转为 **生化关系约束、峰级反事实驱动的 DreaMS 表示学习**。

## 2. 已被已有工作覆盖的部分

| 我们当前或计划中的组件 | 已有工作覆盖情况 | 裁决 |
|---|---|---|
| 从高置信种子沿代谢反应边传播 | MetDNA 2019 | 不能作为创新 |
| 代谢反应网 + MS/MS 相似网 + 峰相关网 | KGMN 2022 | 不能作为创新 |
| 全局候选一致性/组合优化 | NetID 2022 | 单纯 ILP/因子图也不够新 |
| 谱图网络上的随机游走传播 | ChemWalker 2023 | 单纯换传播算法不够新 |
| MS1 预映射、数据/知识双层交互、递归传播、预测反应扩网 | MetDNA3 2025 | 补齐这些只能叫复现/工程对齐 |
| 结构模板引导的未知结构生成 | MetGenX 2026 | 不是我们的短期优势 |
| 生成候选 + 预测 MS/MS/RT + 多阶段生物验证 | DeepMet 2026 | 单纯扩库/生成也不是空白方向 |

## 3. 当前 BioAware 仍有何价值

它的价值是基础设施而非当前算法创新：

1. 建立了可审计的 MS1 feature、离子家族、MS1--MS2 桥接和候选图；
2. 证明了朴素网络传播会因图外真值、共同底物、密图和错误种子而失效；
3. 建立了候选证据依赖、冲突、缺失和弃权的审计框架；
4. 为 MTBLS13729 的去冗余定量和代谢模块发现提供了工程底座；
5. 为下一阶段表示学习提供训练关系、困难负样本和独立评价协议。

这些资产可进入平台论文的方法与消融，但 BioAware 当前不能单独声称超过 DreaMS、达到 SOTA 或提出新的网络注释范式。

## 4. 唯一值得主攻的差异化方向

### 4.1 核心问题

现有网络方法大多把谱学分数视为固定 unary，再传播或全局组合身份。我们的独特问题应改为：

> 能否利用真实 DreaMS 错误图、采集条件变化、生化反应类型和峰级反事实证据，训练出一个同时保持同分子跨条件不变性、分离同式近异构体、并对生化转化具有类型化几何结构的新谱图 embedding？

### 4.2 方法定义：typed biochemical counterfactual representation learning

共享编码器接收原始谱图，直接输出新的 embedding。训练包含四种互不偷换的约束：

1. **身份不变性：** 同一分子的跨仪器、跨碰撞能、条件缺峰谱应保持接近；
2. **近异构体判别：** 同分子式/高共享峰的错误候选必须保持排序间隔；
3. **反应类型等变性：** 反应相邻物不被简单拉近，而由反应类型算子 `T_r` 描述 `T_r(z_A) -> z_B`；不同反应类型拥有不同方向和不确定度；
4. **峰级忠实性：** 产生上述 embedding 方向的峰必须可定位为具体碎片/中性丢失，目标删峰应显著削弱对应关系，匹配随机删峰不应产生同等效应。

推理阶段只输入一张干净原始谱图，不依赖候选图、表型标签或 P2b。P2b 与 BioAware 网络层只能作为后续独立专家。

### 4.3 与已有网络方法的实质区别

- MetDNA/KGMN/MetDNA3：传播注释；本方向改变谱图表示本身；
- NetID：在固定分数上做全局组合；本方向学习产生分数的表示几何；
- 普通对比学习：只定义相同/不同；本方向建模带类型的生化关系算子；
- 普通峰遮蔽：随机增强鲁棒性；本方向使用错误机制、反应类型和匹配随机对照筛选反事实动作；
- 普通可解释头：事后预测标签；本方向要求 embedding 方向、化学关系和具体谱峰三者通过干预忠实性闭环。

这只是当前最有希望的创新假设，不能在完成系统文献/专利检索和外部实验前写成“世界首创”。

## 5. 必须通过的证据链

### 阶段 A：关系与动作是否真的提供可学习信号

- 在公式、骨架、数据集隔离条件下评价；
- typed-relation 预测显著优于质量差、结构相似和随机网络对照；
- 目标峰干预相对计数/强度/mz 匹配随机干预的效应 CI 下界大于零；
- 不能再用 oracle 逐 query 选动作作为模型结果。

### 阶段 B：共享 embedding 是否学到信号

- 官方 DreaMS、同容量普通 adapter、随机噪声、无生化关系消融四方对照；
- clean retrieval 的 Recall@1/MRR/AUC 均不退化；
- near-isomer、cross-condition 两个困难子集同时改善；
- corrected > introduced，且 `corrected - 2*introduced > 0`；
- 多 seed、formula/scaffold/dataset cluster CI 下界大于零。

### 阶段 C：可解释性闭环

- embedding relation direction 可解码反应类型/结构变化；
- 能定位贡献峰及中性丢失；
- 目标删峰的忠实性显著超过匹配随机删峰；
- 化学规则只作可检验机制标签，不作身份真值。

### 阶段 D：真实注释与生物学价值

- 在锁定外部 Level-1 数据上，于固定 FDR 比官方 DreaMS 增加正确注释数；
- 在 MTBLS13729 中报告相对官方 DreaMS 新增且可复核的离子家族/代谢模块；
- 至少一个候选获得标准品，或由独立队列、正交 MS2/RT/同位素证据形成强复核；
- 静态丰度不得写成通量或酶活性。

## 6. 项目结构重新划分

1. **主创新：BioChem-Embed**（暂名）—— typed biochemical counterfactual DreaMS fine-tuning；
2. **谱学专家：P2b**——新的 embedding 后的候选重排保底模块；
3. **上下文层：BioAware-Context**——离子家族、反应/样本图、冲突和弃权，不再冒充核心算法；
4. **解释层：双重映射**—— embedding 因子到碎裂机理，再到具体峰的干预忠实性；
5. **应用层：MTBLS13729**——冻结身份、患者内配对定量、离子家族去冗余和机制候选发现。

## 7. 立即停止与立即开始

### 停止

- 继续扫一跳网络权重；
- 把更多数据库边直接并入传播；
- 把 DreaMS 替换传统 cosine 当成创新；
- 把 ILP、GNN、因子图这些模型名本身当成创新；
- 在 117-query 已消耗开发集上反复追小数点提升。

### 开始

1. 冻结当前 BioAware 为网络方法复现基线；
2. 建立 typed reaction-pair 外部训练/测试集和随机反应网络对照；
3. 将现有错误图、Noise-v3 动作矩阵、ChemAware 规则和峰 token 汇总成统一的 relation/action ledger；
4. 先验证“typed relation operator + identity/near-isomer 双约束”能否在冻结 embedding 上被读取；
5. 只有可读信号成立，才进入最后层 adapter/有限层解冻；
6. 所有成功必须落到共享 clean embedding 和锁定外部注释任务，不能再由下游 oracle 或开发集传播替代。

## 8. 论文口径

当前不能写“提出 BioAware 网络注释算法”。可以写：

> 我们复现并系统审计了反应网络传播在 DreaMS 注释中的边界，发现固定谱图表示下，网络覆盖、种子错误和非特异连接限制了可迁移增益。基于此，我们提出以类型化生化关系和峰级反事实为监督的谱图表示学习框架，使生化先验进入 embedding 形成过程，而非仅在检索后传播标签。
