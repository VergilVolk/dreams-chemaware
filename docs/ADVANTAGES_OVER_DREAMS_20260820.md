# 我们相对 DreaMS 的优势清单（已验证 vs 潜力）

日期：2026-08-20
来源：本清单每条数字均核对自仓库内报告文件（路径见各节），不转抄第三方转述。

---

## 0. 一句话诚实总结

**目前没有一个「新编码器 / 新检索模型」确定比 DreaMS 本身好**——这个结论与
[PRODUCT_WHITEPAPER_20260818.md](PRODUCT_WHITEPAPER_20260818.md) 第 6 节、
[PEAK_EVIDENCE_STAGE_DECISION.md](PEAK_EVIDENCE_STAGE_DECISION.md) 第 8 节的「禁止宣称」
一致。

我们**确定比 DreaMS 好**的，集中在三个东西：
1. **交付物层面**（平台：FDR + 校准 + 分级 + 差异 + 通路 + 暗物质）；
2. **低置信门控重排器**（唯一有 95% CI 不含 0 的「模型级」确定增益）；
3. **峰级因果发现**（一个可复现的科学发现，证明 DreaMS 有可干预的混淆机制）。

我们**可能有潜力比 DreaMS 好**、但尚未验证的：噪声微调、反事实峰微调、化学感知编码器、化学因子双映射。

---

## 1. 确定比 DreaMS 好（已验证）

### 1.1 平台交付层 —— 工程超越，不是模型超越

DreaMS 交付的是「谱 → 1024 维向量」；它论文里**没有**把这条向量做成可复现、可审计、
可对外交付的注释结论。我们补齐了整条流水线（来源 [PRODUCT_WHITEPAPER_20260818.md](PRODUCT_WHITEPAPER_20260818.md) §1.2 / §10）：

| 补上的东西 | 作用 | 验证数字 |
|---|---|---|
| 前体 m/z ±ppm 硬约束 | 杀掉裸 cosine 的假阳性 | FP 代理 0.764 → 0.000；消融 0.248 → 0.059 |
| 目标-诱饵 FDR → q-value | 注释第一次有错误率 | q ≤ 0.01 才叫 confident |
| 校准 score → P(correct) | 注释第一次有概率 | 正确 hit 均 cos 0.884 vs 错误 0.781 |
| Schymanski 1–5 级 | 诚实封顶 2a+3 | Level 1/4 永不输出 |
| 组间差异 + 通路 + 暗物质 | 非靶向代谢组完整结论 | 94.1% 暗物质被标注 |

**诚实定位**：这一层是「把 DreaMS 真正用起来」，不是「我们的编码器比 DreaMS 强」。
其中 m/z 硬约束是 DreaMS 论文评测同款策略的产品化——价值在交付可审计，不在算法原创。

### 1.2 低置信门控重排器 —— 唯一「模型级」确定增益

来源：[data/validation/confidence_gated_reranker/report.json](../data/validation/confidence_gated_reranker/report.json)、
[COUNTERFACTUAL_PEAK_FINETUNE_STAGE_REPORT.md](COUNTERFACTUAL_PEAK_FINETUNE_STAGE_REPORT.md) §2。

在**公式隔离**（同分子式、前体质量差 ≤10 ppm）的 3,529 条确认查询上，用一个
「冻结 DreaMS top1−top2 分差门控」的轻量重排器，对 ~19.7% 的低置信查询重排：

| | Top-1 | 相对官方 | 95% CI（公式 bootstrap） |
|---|---:|---:|---:|
| 官方 DreaMS | 0.8541 | — | — |
| 原始谱图特征重排 | 0.8612 | +0.0071 | [0.0053, 0.0268] |
| 原始特征＋规则负担 | 0.8620 | +0.0079 | [0.0063, 0.0284] |
| **低置信门控＋原始特征＋规则负担** | **0.8629** | **+0.0088** | **[0.0060, 0.0268]** |

- 转移：改对 108 / 改错 77 / **净 +31**（raw_panel 版）。
- **95% CI 不含 0**，这是目前全项目唯一「确定比 DreaMS Top-1 好」的模型级结果。

**诚实边界（必须说）**：
- 只在**公式隔离**困难查询上验证，不是完整非靶向检索；
- 是「冻结 DreaMS 之上加一个重排器」，**不是新编码器**；
- 规则面板相对原始特征只额外 +0.0014（CI [-0.0006, 0.0035] 跨 0）——**规则本身无独立检索增益**，增益来自门控重排机制本身。

### 1.3 峰级因果发现 —— 科学发现，不是「更好的模型」

来源：[PEAK_EVIDENCE_STAGE_DECISION.md](PEAK_EVIDENCE_STAGE_DECISION.md)。

一次性测试集（551 条错误查询、310 个分子、156 个公式组），对冻结的 8 类混淆峰做删除干预：

| 干预 | 错误纠正率 |
|---|---:|
| 删除冻结面板命中的混淆峰 | 10.74% |
| 数量/强度/mz 匹配的随机删峰 | 4.52% |
| 净排序间隔改善 | 0.0305（95% CI [0.0229, 0.0386]） |

结论（该文档自己的原话）：**「DreaMS 的部分同分异构体误判来自可重复的峰级证据利用偏差」**——
若干中等强度碎片、小中性丢失和特定质量数在错误候选共有峰中稳定富集，删除它们能部分修复排序。

**诚实定位**：这是**机制级因果证据**（可复现、有 CI），但该文档第 8 节明确**禁止宣称
「已经获得优于 DreaMS 的新模型」**。它是后面所有「潜力」路线的因果地基，不是可交付的性能。

## 2. 可能比 DreaMS 有潜力好（未验证 / 门控中）

### 2.1 噪声微调（信息论对比训练）

现状（本路线，评估数字来自旧泄漏划分、绝对值待重跑，方向可信）：
- 异构体分离 separation：0.278 → 0.54~0.62（**大幅**，三种子一致）；
- 但 10ppm 检索 Recall@1：0.939 → 0.92x（**降 1~2pp**）。

**潜力**：若加了 `L_preserve`（把表示拉回官方嵌入）能把检索拉回来，就形成「分离↑ + 检索不降」的 v2。
**状态**：G5 门（λ_p 扫描 {0,5,20} × 10k 锚 × 1 seed）待跑，见 `tasks/run_step4_g5.sbatch`。
**翻正条件**：检索 Recall@1 / AUC 相对 λ_p=0 基线不降，且 separation 保持 ↑。

### 2.2 反事实峰微调 / 投影头

来源：[COUNTERFACTUAL_PEAK_FINETUNE_STAGE_REPORT.md](COUNTERFACTUAL_PEAK_FINETUNE_STAGE_REPORT.md) §5。

冻结主干、只训投影头，用「删除真实候选独有峰 → 分差下降 / 删除误候选独有峰 → 分差上升」做反事实监督：

| 训练方式（100 隔离公式、1049 查询） | Top-1 | 相对官方 |
|---|---:|---:|
| 官方 DreaMS | 0.7712 | — |
| triplet＋反事实峰损失 | 0.7779 | +0.0067 |

- MRR bootstrap 95% CI [0.0006, 0.0081]，但 **Top-1 区间下界 = 0**；
- 表征保持余弦 0.9955（不漂移）。

**诚实定位**：该文档自己的结论是「有方向的内部证据，还不是独立外部验证结论」。
**翻正条件**：在独立外部验证集（非本轮已用的确认集）上 Top-1 CI 下界 > 0。

### 2.3 化学感知编码器（ChemAwareDreaMS）

来源：[PRODUCT_WHITEPAPER_20260818.md](PRODUCT_WHITEPAPER_20260818.md) §1.3 / §5.4。

把 335 条机制性化学规则编码成**最后一层注意力偏置**，逐规则独立可学习（softplus 非负）、
带 `chem_attn_enabled` 等价开关（关掉后与原版 DreaMS 逐位一致，消融干净）。

**诚实定位**：设计上有 DreaMS 没有的点（仅注入最后一层 / 逐规则独立权重 / 等价开关），
但**尚未证明检索超越冻结 DreaMS**，仍在 G0–G5 六道因果门之下。
**翻正条件**：MassSpecGym v1.5 同协议下显著超过最强修正基线，才允许声称「检索超越」。

### 2.4 化学因子双映射（可解释性）

来源：[DOUBLE_MAPPING_STATUS_20260816.md](DOUBLE_MAPPING_STATUS_20260816.md)。

「embedding → 化学概念/局部结构 → 具体谱峰」的可证伪链条，现状：

| 环节 | 状态 |
|---|---|
| 冻结全局 embedding 概念探针 | 完成，test macro-AUPRC 0.659（基线 0.200），254/266 概念 ≥2× 基线 |
| 数据驱动结构环境探针 | 完成，AUPRC 0.240（基线 0.0447），396/469 ≥2× 基线 |
| 稳定峰 token 因子 | 10 个 |
| 因子—峰质量复现 | 8 个 |
| 因子—结构环境复现 | 2 个（factor 176 m/z 67.06 `ccc` OR 9.41；factor 117 m/z 91.06 `ccc` OR 9.38） |
| 删峰 → embedding 位移成立 | 2 个（factor 117 CI [0.0021,0.0056]；176 CI [0.0033,0.0080]） |
| 删峰 → 检索 margin 改变 | **0 个（CI 均跨 0）** |

**潜力**：可解释性创新（「为什么判 A 不判 B，由哪个峰/机理驱动」）。
**诚实定位**：已证明「峰是 embedding 因子的真实输入来源」，**尚未证明**任何因子控制检索判断；
五级证据（F1 稳定 → F5 决策相关）只到 F4 部分，F5 为 0。

## 4. 禁止宣称（诚实边界，写死）

1. **禁止宣称**「我们已经获得整体优于 DreaMS 的新编码器/检索模型」。
2. **禁止宣称**「8 项面板就是完整碎裂机理」或「测试删峰结果 = 部署性能提升」。
3. **禁止**用旧泄漏划分的噪声微调数字当正式结论（绝对值待新 manifest 重跑）。
4. 规则证据的定位是**语义升级**（Schymanski），不是置信度升级；规则本身无独立检索增益（CI 跨 0）。

## 附：可辩护的对外讲法（一句话）

> 「我们不是重训一个编码器去碰运气。我们 (1) 把 DreaMS 的向量做成可审计的注释结论，
> (2) 用一个门控重排器在公式隔离困难查询上拿到确定的小幅 Top-1 增益（CI>0），
> (3) 定位了 DreaMS 可干预的峰级混淆机制，并据此在做噪声微调 / 化学感知编码器，
> 方向明确、验证严格，但不拿未验证的承诺当卖点。」
