# BioAware B9：反应边条件化谱学特异动作

## 为什么需要 B9

B7 的约 `+4.84 pp` 动作头间接值主要来自 `network_member`、图度数和质量候选覆盖率；Action Atlas 中度数控制自身约 `+6.02 pp`，完整路径模型没有超过它。因此该结果属于“目录机会度引导的困难样本挖掘”，不是特定生化反应证据。

B2 的反应变换增量只有约 `+0.21 pp`。其核心变量是候选—种子的理论前体质量差；在严格质量匹配、同加合物候选图中，该变量几乎重复了候选质量约束，对同分子式异构体没有辨别力。

## 固定科学问题

对同一个候选、查询谱和交叉验证种子池：

> 真实一步反应邻居的谱学证据，是否高于在极性、加合物、种子分子式质量、元素组成、峰数和网络度数上匹配的非邻居？该“真实边减匹配非边”的残差，能否在跨生物来源、身份与分子式隔离下稳定纠正 DreaMS？

这把三种现象拆开：

1. 普通谱相似是否有用；
2. 网络中是否有可用种子；
3. 具体反应配对是否带来超过 1–2 的增量证据。

只有第 3 项是 B9 的 BioAware 主张。

## 预注册动作矩阵

固定六格，不按结果删格或改名：

1. MetDNA3 风格截断后的直接 sqrt-cosine，跨边均值；
2. 同一截断分数的最佳边残差；
3. 中性丢失 sqrt-cosine 残差；
4. 直接峰与前体差双匹配的 modified cosine 残差；
5. 直接碎片与中性丢失同时成立的双视图最小值残差；
6. KGMN 风格 `dot product >= 0.5` 或至少 5 个匹配峰的连续支持残差。

每条真实边配三个匹配非邻居。候选的真实邻居全集、候选自身和当前真实邻居均禁止成为对照。公式/元素/度数匹配失败的边不进入主动作，不能用宽松随机谱替代。

## 验证合同

- 动作构建阶段不读取 truth outcome；
- 使用四个生物来源 leave-one-source-out；
- 外折来源的 truth identity 与 truth formula 从训练中完全清除；
- 每格都与“目录机会度 + 匹配对照分数”的嵌套模型比较；
- 六格使用 Bonferroni family-wise identity/formula cluster bootstrap；
- `corrected > 2 * introduced`；
- 至少 25 个不同身份被纠正；
- 四个来源均不得为负；
- 主增量必须达到 `>= 3 pp` 才能进入直接 shared-embedding 训练。

## 边界

B9 是打开的动作发现，不是最终泛化性能。即使通过，也只证明反应特异候选排序动作存在；下一阶段才以原始谱为输入、共享查询/参考编码器进行直接微调，并在独立封存测试上判断 embedding 是否提高。
