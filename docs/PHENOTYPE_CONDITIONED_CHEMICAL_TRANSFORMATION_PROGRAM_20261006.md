# 表型条件化的化学转换程序：应用方法学候选主线

日期：2026-10-06  
状态：冻结的 Stage-1 可证伪合同；得到首轮数字前不得继续升级概念；不是现成成果  
英文工作名：*Phenotype-conditioned chemical transformation programs from untargeted MS/MS*

## 1. 核心判断

仅在 DreaMS 空间中寻找疾病相关区域，仍然只回答“哪些相似谱图整体变化”，生物学意义有限。更值得检验的问题是：

> **疾病是否使若干类化学转换在许多不同分子骨架上发生方向一致的重排；这种重排能否在不要求逐峰同一、也不要求先知道精确结构的情况下跨患者、跨色谱平台复现？**

研究单位不再是单个峰、候选结构或抽象谱图区域，而是一个由二级谱图支持的“转换实例”；多个底物背景中具有同类化学变化的转换实例，再组成“化学转换程序”。

这不是代谢通量分析。静态丰度数据不能证明底物直接生成产物，也不能证明某个酶活性改变。未经过示踪或干预时，允许的主张只有“表型相关的化学转换偏向”或“化学重塑程序”。

### 1.1 再上一层：转换程序只是全局化学重塑分解的边层

仅列出若干显著转换仍可能退化为 Reactomics 加严格过滤。更完整的研究对象应是每位患者在一个表型盲冻结的谱图—化学关系图上的**化学重塑信号**。

对患者 \(p\) 和离子实体 \(i\)，先只在同一实体内部计算配对变化：

\[
d_{p,i}=\log x_{p,T,i}-\log x_{p,N,i}.
\]

这一量只比较同一离子在两种组织中的相对变化；若离子响应因子在配对样本间稳定，未知的分子响应系数会相消。随后在表型盲构建的关系图上将同一个 \(d_p\) 分解为三类彼此相关但生物学不同的变化：

1. **分子家族整体升降**：相邻实体的 \(d_{p,i}\) 同号且接近，表示整个化学家族共同扩张或耗竭；
2. **家族内部化学替换**：一条可信转换边两端的效应明显不同，即 \(d_{p,v}-d_{p,u}\) 在患者间方向一致；
3. **孤立出现或消失**：无法由邻域共同变化或可信转换解释的实体残差。

因此主方法不再只是“找反应”，而是回答一个全局问题：

> **疾病造成的可观测化学变化中，有多少是整个分子家族的总量变化，有多少是家族内部沿特定化学改造发生的组成替换，又有多少是当前化学关系图无法解释的新出现/消失信号？**

所有分量来自同一个患者级效应信号和同一张冻结关系图，不是事后增加多条互不相干的证据轴。转换程序是第二类分量中可跨底物、跨平台聚合的边模式。

### 1.2 明确拒绝“化学空间最优传输即代谢流”的诱人包装

不能把不同分子的原始 LC–MS 峰强直接归一化为可在化学空间中搬运的“质量”，再把最优传输路径解释为代谢流。不同分子的离子化效率和响应因子不可比，跨分子运输量没有守恒意义。最优传输最多能作为统计距离或匹配工具，不能成为主要生物学解释。

本方案只在同一实体内部计算肿瘤—癌旁相对变化，再比较关系边两端的相对变化；任何“底物生成产物”“净通量”或“酶活性”主张仍需稳定同位素或直接扰动。

## 2. 为什么比静态化学区域更有生物学意义

单个代谢物变化可能来自饮食、药物、清除、组织组成或技术波动。一个化学转换若在多个不同底物家族上重复呈现相同方向，并且在同一患者的肿瘤—癌旁比较、不同 LC 平台和独立数据中复现，则更接近一个分布式生化过程。

可形成的生物学问题包括：

1. LCNEC 是否普遍增强某类氧化、去饱和、酰基化或结合反应所对应的化学重塑，而不是只改变一个已知代谢物；
2. 同一转换偏向是否同时作用于已知代谢物和远离谱库的暗分子家族；
3. 一个转换程序是否与蛋白组中的酶家族、药物暴露或组织状态一致；
4. 对首要程序进行酶扰动或稳定同位素示踪后，相关转换实例是否按预期改变。

最后一项才把“相关重塑程序”升级为机制或代谢流证据。

## 3. 与 DreaMS 的本质差异

| 层面 | DreaMS / DreaMS Atlas | 本候选方法 |
|---|---|---|
| 基本对象 | 单张 MS/MS 谱图及其表示 | 同一研究内两个离子实体之间的转换实例，以及跨底物复现的转换程序 |
| 主要输入 | 谱图与谱图元数据 | 冻结谱图表示、前体质量/分子式差、局部碎裂证据、患者级 MS1 定量与表型设计 |
| 主要问题 | 谱图是否相似、邻居是谁、化学空间如何组织 | 哪类化学改变在疾病中系统性偏移，并能否跨平台复现 |
| 统计单位 | 谱图或 atlas 节点 | 患者；转换实例不能充当独立样本扩大显著性 |
| 输出 | 静态谱图地图、预测或邻域 | 有方向的表型相关转换程序、贡献底物家族、患者一致性和不确定性 |
| 生物学边界 | 可生成结构/来源假说 | 未经干预只称化学重塑，不称反应通量或酶活性 |

DreaMS 在这里是条件稳定的化学坐标和谱图关系测量器，不是研究结论。真正新增的功能是把病例—对照的定量差异组织成可跨分子、跨平台复现的化学动作，而不是继续扩张 atlas。

## 4. 现有工作占据了什么，不能重新命名

- Reactomics/paired mass distance 已经把质量差和“反应活性”作为分析对象；因此“无需注释分析反应”不是新意。
- MetDNA、KGMN 和 MetDNA3 已经把代谢反应网络、MS/MS 相似网络和峰相关网络用于已知到未知的注释传播；因此“谱图网络加反应网络”不是新意。
- Qemistree 和 TidyMass2 已经把未注释特征纳入化学树或功能模块分析；因此“未知峰也做通路/模块”不是新意。
- DreaMS Atlas 已经提供大规模谱图化学空间和跨研究邻域；因此“建立谱图地图”不是新意。

唯一可能形成独立贡献的差异是：

> **不把一个质量差直接视为反应，而是用前体组成变化、跨条件稳定的谱图关系和局部碎裂变化共同判定转换实例；再从许多不同底物背景中学习/聚合同类转换，并以患者为单位检验其表型偏移和跨平台迁移。**

如果最终实现只是 PMD 边加 DreaMS 相似度阈值，应判为 Reactomics 的增量过滤器，不能承担主创新。

## 5. 方法对象

### 5.1 离子实体

先用同位素、加合物、源内碎片、共洗脱和峰形证据合并离子家族。每个实体必须有：

- phenotype-blind 的 QC/blank/dilution 合格记录；
- pooled-QC 或等价代表 MS/MS；
- 患者级 MS1 定量；
- 极性、加合物和前体质量的不确定性。

### 5.2 转换实例

实体 (u,v) 只有同时通过以下证据才成为候选转换实例：

1. 中性质量或分子式变化与某一化学改造相容；
2. 两张谱图的共享骨架证据超过质量匹配置乱对照；
3. 新增/消失碎片、中性丢失或峰间质量差能解释改造发生在局部结构上；
4. 在不同碰撞能或技术重复下关系稳定；
5. 排除同位素、加合物、源内碎片和常见污染物解释。

每条边输出校准的可靠度与弃权状态，而不是二元“有反应/无反应”。

### 5.3 转换程序

不把转换类型限制为预先列出的 PMD。一个转换程序由多个底物背景上的相似动作组成，其表示至少包括：

- 前体的质量/元素组成变化；
- 成对谱图的结构保留程度；
- 局部碎片和中性丢失的变化模式；
- DreaMS 空间中的成对位移，但不得假定原始 embedding 向量差天然具有化学线性。

已知反应对只用于给程序命名和验证，不允许在表型结果出来后反向挑规则。

## 6. 患者级统计，而不是边数投票

对患者 (p) 的转换实例 (e:u\rightarrow v)，先形成肿瘤—癌旁的端点变化，再构造转换对比：

\[
\Delta r_{p,e}=
[\log x_{p,T,v}-\log x_{p,T,u}]
-[\log x_{p,N,v}-\log x_{p,N,u}].
\]

对同一转换程序 (g)，使用表型盲冻结的边可靠度与底物家族去冗余权重，形成患者级程序分数：

\[
A_{p,g}=\sum_{e\in g}w_e\Delta r_{p,e}.
\]

显著性使用患者配对 sign-flip、患者 bootstrap 或等价方法。共享节点、共享离子家族和同一底物系列必须先聚合或成簇抽样，禁止把几百条边当成几百个独立样本。

## 7. 与现有模块的诚实分工

- **Noise 改进的 DreaMS**：提供跨实验条件更稳的谱图表示和候选边召回；必须与官方 DreaMS、余弦和谱熵比较。
- **ChemAware**：只提供已经冻结且可复核的局部碎片证据。当前动作到共享 embedding 的 24-action A2 筛选没有超过匹配对照，不能假定其已经学会可迁移化学算子。
- **P2b 与重排器**：用于首要转换实例两端的结构候选跟进，不定义转换程序，也不参与主统计筛选。
- **BioAware**：只在转换程序发现后连接可能的反应、酶或通路。B44 的外部反转、B45 的覆盖中性弱结果和 B46 的负结果禁止作为发现权重或生物学正确性的证明。

强行让所有模块进入一个总分会重新制造目录覆盖、网络度数和候选先验捷径。真正的整合是各模块回答互不替代的问题，并通过消融证明每一层是否增加信息。

## 8. 五个必须通过的实验

### Gate O0：转换是否可识别

在结构已知、反应关系已知且公式隔离的谱图对上，隐藏身份后区分真实反应对与以下诱饵：同质量差错误对、同结构相似度非反应对、候选互换、峰置乱。必须显著优于 PMD-only、DreaMS-only、余弦和谱熵。

若不能，停止“MS/MS 分辨转换”主张，只保留静态化学空间分析。

### Gate O1：转换能否跨底物复用

按底物骨架或第一层 InChIKey 留出；训练/定义程序时从未见过验证底物。若同类动作只在同系物或身份近重复中成立，不能称化学算子，只能称家族模板。

### Gate O2：能否恢复真实生物扰动

在隐藏标签的单酶反应、基因扰动、药物扰动或稳定同位素数据中，冻结方法后检验受影响转换程序是否优先恢复。主要比较：

- 单峰差异分析；
- Reactomics/PMD-only；
- Qemistree/FBMN/TidyMass2 类模块；
- 已知代谢物 only；
- 全部合格实体。

若全部实体不增加受扰机制的留出恢复，未知谱图的应用价值未成立。

### Gate O3：LCNEC 多平台复制

HSST3n 用全部 263 个 phenotype-blind QC 合格家族发现程序；冻结转换定义、方向、权重和阈值后，在 LIPn/LIPp/HILICp 或其他兼容平台检验同类程序。验证允许具体分子不同，但必须要求：

- 同一转换动作；
- 相同肿瘤—癌旁方向；
- 患者级效应而非边数效应；
- 优于 PMD-only 和静态 DreaMS 区域；
- 去掉已知代谢物后仍有暗实体增量。

### Gate O4：一个前瞻生物闭环

只选择一个跨平台最稳、具有酶/蛋白组先验的程序，通过酶扰动或稳定同位素示踪验证。标准品只用于少量端点身份确认，不再承担整篇工作的唯一收口。

## 9. 论文级 money figure

一张图必须同时显示：

1. PMD-only 在同质量差诱饵中产生多少假转换；
2. 加入 MS/MS 局部变化证据后，隐藏真值转换识别提高多少；
3. 一个冻结转换程序在未见底物与独立平台上仍可恢复；
4. LCNEC 中该程序在 34 个患者的肿瘤—癌旁比较中方向一致；
5. 未知实体相对 known-only 带来独立增量；
6. 一个酶扰动或示踪实验按预测改变该程序。

缺少第 2–3 项，这是 PMD 工程改进；缺少第 5 项，暗代谢组主张不成立；缺少第 6 项，只能称队列关联方法，不能称机制发现。

## 10. 当前结论

这条路线比“谱图实体复现”“化学空间差异区域”和“审计门”更值得探索，因为它提出了一个新的生物学分析单位和一个可被实验击中的结论：**疾病相关的化学转换程序**。它也与 DreaMS 形成明确分工：DreaMS 提供静态谱图坐标，本方法估计患者级、表型条件化的化学重塑。

但它现在仍然不是成果。项目现有 ChemAware/BioAware 负证据说明，最危险的假设正是“谱图关系天然等于可迁移化学动作”。因此第一优先级不是在 LCNEC 上画网络，而是完成 Gate O0 的隐藏真值转换识别；只有 O0 和 O1 通过，才值得处理五平台 LCNEC 原始数据。

## 12. 冻结后的首轮执行

首轮只检验 HSST3n 的 263 个 phenotype-blind QC 合格家族和 34 对患者，不检验转换机制、LIPn 复现或暗实体增量。唯一提交入口为：

```bash
sbatch tasks/run_lcnec_global_remodeling_stage1.sbatch
```

作业从服务器原始 HSST3n 压缩包重新生成 QC ledger、263 张代表谱图、官方 DreaMS embedding 和完整 85×263 EIC 矩阵，不读取历史 81 个差异模块或 221 个作者表外目标作为分析宇宙。

冻结的主图为 unit-normalized official DreaMS embedding 上的 mutual 3-NN 图；2、5、8-NN 只作预注册敏感性分析。患者效应严格分解为非单点连通分量均值、分量内残差和 singleton 信号，三者在欧氏内积下正交并要求能量恒等式相对误差不超过 \(10^{-10}\)。病例效应只使用患者级 sign-flip 检验。

只有以下全部通过才允许进入 LIPn 与 known-only/all-feature Stage-2：主图非单点覆盖至少 25%；最大连通分量不超过 50%；不同 k 下 family 与 within 能量占比极差均不超过 0.15；family 或 within 至少一个患者级 sign-flip \(p\le 0.05\)。这些是首轮停止规则，不是领域通用阈值，也不得在看到结果后修改。
