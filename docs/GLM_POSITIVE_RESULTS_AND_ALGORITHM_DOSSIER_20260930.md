## 一、共享 embedding 微调（W 层）——改变 DreaMS 权重的正向结果

### 卡 1：ChemAware 原生三重奏 stage-1（role-3 +1.8144pp）

- **结果：** run_2340721_resume_2340524 best.ckpt（全局步 3,000）：role-3 确认图 1,929 queries，R@1 0.904614→0.922758，**+1.8144pp**，57 纠正/22 引入（净 35，效用 13），公式簇 CI [+0.8155,+2.8703]，MRR +1.0789pp。项目**最强的已确认共享权重学习结果**。last.ckpt（41.2 万步）退化至 +0.4147pp——早期停止是设计的一部分。
- **算法选型：** "真值盲化学选择 + 原生训练不变"范式：化学证据只决定三重奏课程里 (query, true, false) 关系的**准入**，训练事件本身是标准身份三重奏，DreaMS 原生 cosine triplet-margin 铰链（margin 0.1）、原生 ContrastiveHead/数据集/Adam 一概不改；化学分数永不进入损失或推理。
- **为什么赢：** 此前一切把化学信号写进损失（教师蒸馏/伪标签/规则解码/边际回归）的路线全部失败（0905 GPU 封锁的直接原因）；唯一幸存的机制是"化学做课程、原生做优化"。这也是把"动作→权重迁移缺口"绕开的方式：不需要动作语义可迁移，只需要关系选择有信息。
- **实现：** 池 7,688 事件/4,032 queries/2,518 formulas；冻结角色面板（0/1 训练、2 审计、3 评估）；best.ckpt 由训练损失回调监测（验证加载器软泄漏已注记）；SHA 09c419dcabf2ff42…，commit af37d73，tag chemaware-role3-positive-20260921；.filepart 恢复 3 ckpt 全 CRC 验证。
- **边界：** role-3 已被开发消费；化学归因零臂实验未执行（增益可能部分来自普通困难负例课程）；不能外推为 outer 结论。

### 卡 2：ChemAware Phase-A max-boundary（role-2 +2.1266pp）

- **结果：** run 2343962 step-2000：role-2 选择面板 1,975 queries，official 0.896203→**0.917468**，**+2.1266pp**，54/12（净 42；引入从 stage-1 家族的 24 降到 12），CI [+1.2761,+3.0303]，MRR +1.3645pp。**过全部安全标准的 role-2 最强开发结果**。
- **算法选型：** 检索对齐单例 max-boundary 事件构造：每个查询取其当前决策边界的极端事件——安全层（3,605，60.53%）+ official 错误层（777，13.05%，覆盖全部 427 个 official 错误 query）+ 化学层（550，9.23%）+ 精确重放层（1,024，17.19%），共 5,956 事件；lr 5e-6、margin 0.1、batch 4、固定步检查点 500–3,000。
- **为什么赢：** 对比同周三条竞争构造（多条件 V5 6,602 锚 11,280 事件差 1 净 query；密集真支持 V8 身份广播稀释 64.63%；受益边界替代 V13 全 CI 跨 0）——**事件多≠事件有效；每查询有界剂量 + 边界对齐才有效**。2,000 步 = 曝光预算最优点（1,489 步/epoch）。
- **实现：** `build_chemaware_max_boundary_native_triplets.py`；冻结账本 `CHEMAWARE_PHASEA_2PP_RUN_2343962_FROZEN_LEDGER.json`；便携复现 SHA a8428329…（run_2345481/phasea_reproduction_gate）是后续一切 V13/V16 的挖掘几何。
- **边界：** 对已发布 stage-1 的增量门未过（+0.6076pp，utility −13）——它是**绝对增益冠军**而非增量冠军；role-3 非回归确认未消费。

### 卡 3：Noise Stage-1 硬正例原生（+0.496pp 绝对 / +1.265pp 因果）

- **结果：** run 2344820：18,333 held queries 上 vs official **+0.49637pp**、vs mature-E8 +0.22910pp；因果对比 vs 同 query 同剂量注册对照 **+1.26548pp**（455/223，CI [+0.87586,+1.65425]）——**动作内容具有被证实的因果价值**。
- **算法选型：** action 视图=硬正例关系：anchor=注册动作视图、positive=同分子独立测量谱、negative=该动作识别的假候选；**clean→action 桥接关系被明令禁止入训练账本**（run 2344688 证伪：桥接 margin −0.0667、胜率 21.2% vs 硬正例 +0.1365、92.5%）。全部原生运行时（ContrastiveHead/数据集/预处理器/Adam lr 5e-6）。
- **为什么赢：** 0816–0919 一切把动作语义直接注入损失/优化器的路线（G5–G7、注入器 V1–V11、动态权重、蒸馏）全部失败或 ≤+0.15pp；Stage-1 证明动作的**关系选择价值**可以迁移，动作的**张量语义**不能。
- **实现：** `run_noise_dreams_hard_positive_native_2gpu.sbatch`；七源 32,114 动作别名账本（别名折叠防剂量乘法）；~33,575 基础事件/8,394 步硬上限 9,000 预检门。
- **边界：** 绝对规模 ~110 净决策 vs 5pp 的 917；p01 保持 0.980–0.982。

### 卡 4：Noise Stage-2 残差（~+0.6000pp 点估计）

- **结果：** vs official ~+0.6000pp（+0.3327 vs mature-E8），为 Noise 线最强绝对点估计；增量 CI 未确立新冠军故未晋级。
- **算法选型：** 三重边际残差选择：动作存活需 (a) 当前边际 < 0.1 铰链、(b) 靶向边际 > 对照 +5e-6、(c) 靶向边际 > 干净边界 +5e-6；每 query ≤1 动作 + 1 干净事件 + 256 保护事件；**lr 1e-6 晚期续训尺度**（5e-6 在 Stage-3 被证伪为晚期续训过大步）。
- **为什么有价值：** 确立"晚期续训必须用 1e-6"与"每 query 有界剂量"两条后续全部沿用的尺度律。

### 卡 5（历史资格）：E4-A 直接微调（旧 cohort +0.636pp，15/15 折）

- **结果：** 五折×三种子平均 **+0.635pp** / near +0.530pp，15/15 折公式簇 CI>0——旧 cohort 上唯一可复现权重增益。
- **算法选型：** 定向噪声课程直接微调：最后 1/7 块+头解冻，lr 2e-6/1e-5、clip 1（>90% 步截断但保 preservation 0.99524）。
- **资格：** 0906 修正图重置后仅作机制证据（E1 历史级）；其因果归因门后来测得 targeted−matched-random 仅 +0.0338pp（CI lb=0）——**E4-A 的价值是"定向课程可微调成功"的机制证明，不是可部署增益**。

## 二、embedding 后融合与重排（X 层）——不动 DreaMS 权重的正向结果

### 卡 6：P2b 秩融合（封存 +1.07pp，项目唯一 E3 级算法结果）

- **结果：** 封存 P3-main 3,000 queries：R@1 +1.07pp（89/57，CI [+0.24,+1.89]，McNemar p=0.0101）。
- **算法选型：** `S = 0.10·DreaMS 分数 + 0.10·熵 + 0.80·中性损失 sqrt-余弦` 的候选秩融合；零初始化有界残差（初始≡基线，不可能开局破坏基线）。
- **为什么赢：** 三通道里中性损失通道承载了化学结构区分（同分子式干扰的主战场）；熵提供置信度校正；两者都只重排不训练。
- **实现：** 7 项 SHA256 溯源；强制地板模块；替换需新封存测试。
- **边界：** near-core **−4.23pp**（20/41）——极近异构体不可宣称解决；此边界是全项目融合方法的共同墓地。

### 卡 7：V2 多零对称残差重排（role-3 dev +3.94pp）

- **结果：** 1,929 确认图 dev：93/17，**+3.9399pp**，CI [+2.8191,+5.1921]；胜全部三个内容置换零（+3.3178，CI>0）；V1 直接优先+残差退避集成 +3.7325pp（78/6，CI [+2.6927,+4.8339]）。
- **算法选型：** 对称残差重排：残差学习器对每个候选输出修正量，与 3 个内容置换零（旋转/置乱/反序）同场对比；干扰交叉拟合；零语义全 CI>0 才准入。
- **为什么赢：** 交叉校准被拒（54 纠正 < 冻结序）；多零设计把"重排器学到的是内容不是顺序"变成可检验命题。
- **边界：** 无新独立确认面板（开发已消费 role-3）；awaiting 新源确认。

### 卡 8：E0 峰重叠纠正器（+2.04pp，历史）

- **结果：** 21,163 queries（旧 cohort）：0.9020→0.9224，1,237/805，5/5 折。
- **算法选型：** LR(cos + 4 峰特征)，其中 top_overlap 特征暴露了稳定排序并列伪影（0.9482 假 → 诚实 0.8857）——**度量卫生的奠基案例**。
- **资格：** 旧 cohort E1 历史；方法论遗产（并列对正例不利原则）沿用至今。

### 卡 9：A1 多通道表示（NDCG@5 +2.962pp，边界宇宙）

- **结果：** 153 谱/69 身份显式多通道宇宙：NDCG@5 +2.962pp，CI [+1.317,+4.767]。
- **算法选型：** 多通道显式表示（m/z、强度、中性损失、共享峰等通道显式编码）+ 融合排序。
- **边界：** A1b 切回 official 单余弦空间即 −0.590pp CI 跨 0——**信号存在于显式通道，不存在于 DreaMS 余弦空间**；按预注册门停止样本级路线。保留价值=标准品/碰撞能选择优化。

### 卡 10：A0 参考锚定峰算子（硬子集 +5.37pp）

- **结果：** 2,707 queries：总体 +1.03pp（CI lb≤0）；**硬子集 +5.37pp**；+MS1 硬子集 **+8.64pp**；增益集中于酰基肉碱。
- **算法选型：** 参考锚定峰算子（6 证据通道的峰级操作子）；sqrt-余弦基线 0.7281。
- **边界：** 无通用方法主张（总体 CI）；分层主张合法。

### 卡 11：rule-mass 核探针（+1.2442pp）

- **结果与选型：** 规则×质量核加权探针 +1.2442pp（32/8，CI [+0.6491,+1.7847]）> 纯 mass 核 +0.881pp（CI [+0.389,+1.291]）> 适配器 +0.3629pp——证明**化学先验作为核权重优于作为训练信号**（E1 保留资产）。

### 卡 12：RAW-v1 门控重排器（dev +4.35pp）

- **结果：** dev 0.8081→0.8516（+4.35pp，44/17，McNemar p=0.0009）；Test-A/B 点估计正但 CI 跨 0；P1 选择性部署 +0.0355（CI>0）。
- **算法选型：** 有界残差 S=s_DreaMS+α·ΔS_peak（零初始化）+ 分歧门控切换；门控=学习门 λ=2 效用。
- **遗产：** "零初始化有界残差"模式被 P2b/V2 全线继承。

### 卡 13：A4-B0 正证据教师（4/4 门全过）

- **意义：** 证明正证据方向存在可学习的几何结构。

### 卡 15：R0 切向投影（+4.0039pp，诊断转折点）

- **结果：** 2,048-query dev 图：85/3，+4.0039pp；正确能量解释 95.30%；对照 −0.3906/+0.0488。

- **意义：** **证明几何不是瓶颈**——在正确方向上,现有表示已能表达大部分所需区分；瓶颈在可观测性/优化。这一定位直接催生了原生三重奏路线的成功。

### 卡 16：动作空间 oracle 阶梯（上限账）

- **意义：** 动作空间的真实容量边界；**禁止从这些数推断部署性能**（5pp 修正账本明令）。
