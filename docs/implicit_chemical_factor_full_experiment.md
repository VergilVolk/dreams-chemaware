# DreaMS隐式化学因子全流程预实验

## 1. 实验问题

本轮不使用335条或3486条规则作为标签，直接比较：

- 原始自监督权重：`dreams/models/pretrained/ssl_model_server.pt`；
- DreaMS官方微调主干：`data/e1/official_embedding_slim.pt`，来自官方`embedding_model.ckpt`。

需要依次回答：

1. 官方微调是否真正改善同加合物、前体质量差不超过10 ppm的困难检索；
2. 改善和残余错误集中在哪些结构关系；
3. 是否存在可独立复现的微调增益方向；
4. 模型判断能否落实到具体谱峰；
5. 当前证据是否足以扩充化学规则库。

## 2. 数据与无泄漏协议

MassSpecGym验证集先经过与DreaMS DataFormatA一致的谱图质量控制。每个分子单元包含同分子、同加合物、仪器不同和/或碰撞能量差至少10 eV的两张谱图；困难负候选必须是不同分子、同加合物且前体质量差不超过10 ppm。

| 项目 | 发现集 | 独立确认集 |
|---|---:|---:|
| 分子单元 | 464 | 464 |
| 谱图 | 928 | 928 |
| 有向困难关系 | 808 | 812 |
| IK14跨集合重叠 | 0 | 0 |
| 困难关系跨集合泄漏 | 0 | 0 |

确认集的最大最近负样本质量差为9.901 ppm，每个查询均有困难负候选。

## 3. 严格10 ppm检索

| 表征空间 | pooled ROC-AUC | Top-1 | Top-1 95% CI |
|---|---:|---:|---:|
| 原始SSL完整embedding | 0.615 | 0.559 | 0.529–0.589 |
| 原始SSL条件稳定子空间 | 0.673 | 0.636 | 0.606–0.667 |
| 官方微调完整embedding | **0.799** | **0.763** | 0.734–0.789 |
| 官方微调条件稳定子空间 | 0.757 | 0.736 | 0.705–0.764 |

官方微调显著改善质量近邻分子的身份检索。条件稳定投影可以改善原始SSL，但会削弱官方完整embedding，说明官方微调利用的信息不只包含跨条件不变量。

该0.799来自本项目构造的MassSpecGym队列，与DreaMS论文NIST20结果不是同一协议。

## 4. 失败转移

确认集928个查询中：

| 查询类型 | 数量 | 比例 |
|---|---:|---:|
| 原始错误、官方纠正 | 196 | 21.1% |
| 两者都错 | 213 | 23.0% |
| 原始正确、官方变错 | 7 | 0.75% |
| 官方完整空间正确、条件稳定投影变错 | 25 | 2.7% |
| 两者均正确且投影仍正确 | 487 | 52.5% |

官方微调主要消除了原始SSL对结构差异较大分子的混淆，但未解决局部异构体辨别。

## 5. 结构富集

发现集和确认集结果方向一致：

- 官方残余错误中同分子式比例分别为96.2%和96.4%；
- 官方残余错误中同Murcko骨架比例分别为43.9%和41.8%；
- MCES 0–2对官方失败的风险比分别为2.26和3.05；
- MCES 3–5的风险比分别为2.38和2.15；
- Morgan 0.50–0.74及≥0.75均约有2.2倍失败富集；
- 官方最容易修复的是不同分子式、不同骨架、Morgan<0.25或MCES>10的原始错误。

MCES仅复用了既有缓存，查询覆盖率为发现集69.3%、确认集65.2%。MCES结果作为部分覆盖的结构诊断，不视为全队列精确统计。

## 6. 微调增益方向

使用冻结的第7层query embedding训练线性探针，并在分子完全不重叠的确认集测试。

### 预测官方是否失败

| 输入 | 外部AUC | 独立方向余弦 |
|---|---:|---:|
| 原始embedding | 0.652 | 0.089 |
| 官方embedding | 0.633 | 0.087 |
| 官方－原始delta | 0.620 | 0.077 |

### 预测原始错误是否会被官方修复

| 输入 | 外部AUC | 独立方向余弦 |
|---|---:|---:|
| 原始embedding | 0.551 | 0.002 |
| 官方embedding | 0.536 | 0.022 |
| 官方－原始delta | 0.516 | 0.002 |

结论：不存在可跨集合复现的单一全局“微调增益方向”。机器目前识别到的是分布层面的子空间变化，不能命名为具体化学因子。

## 7. 峰遮蔽忠实性

选择12个确认集代表案例，每例执行：32个单峰删除、最强20%峰删除、最弱20%峰删除和12次随机20%删峰。重新计算的未遮蔽embedding与缓存余弦均超过0.9999999。

官方微调模型的案例级中位结果：

| 类型 | 最关键单峰删除后的边际下降 | 最强20%删峰 | 随机20%删峰 |
|---|---:|---:|---:|
| 两者均正确 | 0.143 | 0.829 | 0.067 |
| 两者都错 | 0.039 | -0.109 | -0.076 |
| 官方完整空间正确、投影错误 | 0.026 | -0.012 | 0.012 |
| 原始错误、官方纠正 | 0.038 | 0.053 | 0.027 |

两者均正确时，强峰是主要支持证据；两者都错时，删除强峰经常改善边际，说明共享强碎片可能在异构体之间形成误导。官方修复案例的关键峰中位相对强度仅3.9%，提示部分增益可能来自低丰度诊断峰。

一个案例中删除相对强度2.3%的m/z 247.0993峰，官方正确边际下降0.327，而原始SSL仅下降0.019。该现象目前只有单案例证据。

唯一在0.02 Da内重复的支持峰m/z 205.086及中性丢失185.105来自同一对异构体的双向查询，不属于分子独立复现。

## 8. 架构决策

本轮确认：

1. DreaMS官方微调的真实增益可以在严格质量近邻队列中复现；
2. 剩余主要痛点是MCES 0–5、同分子式和同骨架的局部异构体；
3. 简单条件不变投影会删除官方模型已有的有效信息；
4. 重建式Crosscoder、确定性条件不变分解和线性增益探针均未得到稳定单因子；
5. 峰遮蔽显示模型依赖具体峰，但当前没有跨分子复现的峰或中性丢失证据。

因此，当前可进入下一轮训练的监督定义为：

- 正样本：同分子、同加合物、跨仪器或跨碰撞能量谱图；
- 困难负样本：同分子式优先，MCES 0–5、同骨架、同加合物且前体质量差≤10 ppm；
- 主损失：身份对比损失；
- 辅助约束：官方embedding保持；
- 增强：随机20%谱峰遮蔽的一致性约束，先单独消融；
- 化学规则：仅用于错误诊断和冲突样本说明，不作为距离标签。

当前**不扩充规则库**。规则候选必须同时满足：独立方向稳定、分子独立峰/中性丢失复现、随机遮蔽对照和第二数据集复现。
