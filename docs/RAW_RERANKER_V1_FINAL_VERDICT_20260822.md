# RAW Reranker v1 最终裁决（2026-08-22）

**结论**：RAW reranker v1 是"冻结 DreaMS 候选排序 + RAW 峰匹配特征 + 候选组内重排"的**系统级**修正，不改善 DreaMS embedding 或权重。开发集 +4.35pp 证明峰级信息有补充价值；冻结盲测显示当前重排+门控不稳定，未达到显著超越官方 DreaMS。

---

## 一、冻结盲测最终结果（复现门 PASS，模型身份确认）

| 面板 | base Recall@1 | reranker Recall@1 | Δ | CI | McNemar p | corrected/introduced |
|---|---:|---:|---:|---:|---:|---:|
| Test-A | 0.9225 | 0.9270 | +0.45pp | [−0.0067, +0.0160] | 0.444 | 59 / 50 |
| Test-B | 0.8956 | 0.9029 | +0.73pp | [−0.0063, +0.0213] | 0.312 | 77 / 64 |

- Test-A/B 重叠 1427 个 IK14（Test-B 是 Test-A 的异构体困难亚组，非独立验证集）。
- 结论：**正向点估计保持，但效应从 +4.35pp 衰减到 +0.45~0.73pp，CI 跨 0、McNemar 不显著，不能宣称优于官方 DreaMS。**

## 二、根因

不是"峰级信息无用"，而是**当前模型不能可靠判断哪些 query 值得推翻 DreaMS**——干预质量接近五五开（A 59/50、B 77/64），改动很多但净收益小。

## 三、RAW-v1 处置

- 冻结永久归档，不再调参。
- A/B 只做 corrected/introduced 失败类型分析，不再重构、不再第三次盲测。
- 不宣布 SOTA。
- 保留为 v2 的峰级基线 + 消融项。

## 四、下一代方向（审核员定）

- **P1 风险受控残差重排器**：`S_final = S_DreaMS + g(q)·ΔS_peak`，`g(q)∈[0,1]` 门控；训练对"新增错误"惩罚高于"漏修正"；门控在训练集 IK14/分子式分组 CV 学习，不用 A/B 调。
- **P2 候选组内 listwise**：`L = -log(exp S(q,p) / (exp S(q,p)+Σ_n exp S(q,n)))`，每 query 等权，含自然 + MCES 0–2 困难负例；规则仅作特征/解释证据，不作正负标签。
- **P3 新 v2 一次性测试集**：从 185,919 条 train 谱预先锁定 IK14/骨架分组的测试集，剩余重训；模型/门控/阈值全冻结后只跑一次。

## 五、全程教训（写死）

1. 不把"证据不足"写成"已证明"；不把"弱泛化"写成"完全没有泛化"。
2. 测试协议必须在开测前锁定、冻结工件、哈希核验、复现门。
3. 开发/部署协议错位是真实风险，开发集结论必须经冻结盲测才能成立。
