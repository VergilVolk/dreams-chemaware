# DreaMS 定向噪声微调 v3：候选条件化高梯度路线

日期：2026-08-24

## 1. 本路线与 ChemAware 的边界

本文件只定义噪声微调，不把化学规则作为标签，也不训练规则解码头。

- 正确/错误由真实分子身份与严格 10 ppm 候选组决定；
- 峰只用于构造训练扰动；
- 化学规则库以后可解释被验证的峰，不参与本轮样本正负定义。

## 2. 为什么旧结果没有否定噪声路线

最初反事实实验的干预以 `(查询 q, 正确候选 p, 最难误候选 n)` 为条件：

- 删除误候选独有峰，相对匹配随机删除的检索分差增加 0.0494，95% CI [0.0330, 0.0675]；
- 删除正确候选独有峰，检索分差降低 0.0558，95% CI [-0.0786, -0.0450]。

后来的 directional-noise v2 改成了“同分子组内低频、低强度条件峰”，并一次删除整组峰；它不再围绕实际误候选，且排除了强峰，因此检验的是另一个弱得多的假设。它与随机删除持平，不能推翻上面的候选条件化信号。

旧训练还有一个目标错位：它要求删去误导峰后的 margin 高于干净谱图，却没有要求干净谱图学习删峰后得到的正确判断。因此干预顺序可以满足，原谱检索仍不改。

## 3. v3 的科学问题

对完整严格 10 ppm 候选组，DreaMS 的错误是否集中在少量对候选排序产生负贡献的查询峰？如果这些峰被轻微衰减，完整候选组排名能否相对强匹配随机对照稳定改善？

记官方相似度为 `s`，正确候选代表为 `p`，最难错误候选集合为 `N_K`：

`J(q) = s(q,p) - sum_j stopgrad(w_j) s(q,n_j)`

其中 `w_j = softmax(s(q,n_j)/tau)`。对查询峰强度 `I_k`：

`a_k = I_k * dJ/dI_k`

当 `a_k < 0` 时，降低该峰强度预计提高候选分差。该量只用于在训练集上构造增强，不是推理时需要的标签。

## 4. 峰角色与主选择器

查询峰相对 `p` 和官方最难误候选 `n*` 分四类：

1. identity-only：匹配 p、不匹配 n*；原则上保护；
2. confounder-only：匹配 n*、不匹配 p；优先检查；
3. shared：同时匹配 p 和 n*；允许由梯度判断；
4. unmatched：两边都不匹配；允许由梯度判断。

主选择器从非 identity-only 峰中选择预测改善量最大的单峰。不得预设峰必须低强度，不得一次删除整个条件峰组。

## 5. 因果干预审计

在 P3 隔离的全部 23,876 个真实查询上运行：

- 25% 和 50% 强度衰减；
- 单峰硬删除作为压力测试；
- 干预后将剩余碎片强度重新归一化，前体 token 不动；
- 每个目标峰配 3 个强度/m/z/角色匹配随机对照；
- 对完整候选组重新计算 Top-1、MRR 和正负分差，而非只看一个谱图对。

同时报告：baseline 正确/错误、near/non-near、峰角色、仪器/加合物、分子式和身份聚类 bootstrap CI。

## 6. 进入正式训练的硬门

只有同时满足以下条件才训练：

1. 覆盖不少于 1,000 个 baseline 错误和 500 个身份；
2. 目标干预相对匹配随机对照的 margin 改善，在身份和分子式聚类 CI 下界均大于 0；
3. baseline 错误组的完整候选 Top-1 净修正显著为正；
4. baseline 正确组不劣，新增错误受到预注册上限约束；
5. 25%/50% 衰减方向一致，效果不能只依赖硬删除；
6. near 亚组方向非负。

## 7. 正式训练目标（G1 通过后实施）

正式训练不再复用旧的“masked margin 必须高于 clean margin”单边目标。采用：

- 干净候选组 listwise 排序损失；
- 衰减视图候选组 listwise 排序损失；
- 仅当衰减视图实际改善时，将其候选分布 stop-gradient 后迁移给干净谱图；
- identity-only 峰保护和 baseline-correct 安全回放；
- 冻结层保持 eval，关闭 dropout；优先训练末层 adapter/最后一层，不再只训线性 head。

训练的目标是让原始谱图纠错，不是让模型记住“删峰后会变好”。

## 8. 结论边界

G1 是大规模可学习头寸审计，不是模型性能结果。通过后才允许正式训练；未通过时只能否定当前峰选择器/干预算子，不能笼统宣判“噪声微调无效”。
