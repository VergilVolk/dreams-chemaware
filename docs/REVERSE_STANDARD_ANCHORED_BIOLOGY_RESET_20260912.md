# 标准锚定的反向谱学表型：生物学路线纠偏与实施合同

**日期：2026-09-12**  
**状态：生效；替代 A0–A2 公共元数据预测主线**

## 1. 本轮错误

A0–A2 把师兄提出的“将标准/参考谱作为化学探针，反向检查每个生物样本”换成了“根据公共库命中元数据预测样本大类”。这个换题不能用于回答真实生物学问题，也没有利用项目已有的 shared embedding、ChemAware 和 MS1 定量资产。

A0–A2 仅作为负结果保留，不再扩展，不再称为反向代谢组学主线。

## 2. 正确的研究单位

主要输入不是一张未知谱，而是一个预先冻结的化学假设：某个有参考谱的分子，或一个化学家族。对每个参考谱，在每个生物样本中独立计算：

1. 前体质量和加合物兼容的 MS/MS 命中证据；
2. 官方 DreaMS、改进 shared embedding 和传统谱相似度在同一候选图上的分数；
3. 诊断峰、中性丢失、同分异构冲突和 ChemAware 证据；
4. 连接的 MS1 feature、检出状态、EIC 峰面积和峰形质量；
5. 无法区分异构体时的弃权和身份上限。

基本数据对象是 `reference spectrum x biological sample x evidence channel`，而不是一个公共项目的样本类型标签。

## 3. 两个必须分开的探针面板

### 3.1 校准面板

使用原论文在同队列报告的 Level-1 身份锚点。用途是检查方法能否在同一样本空间中找回既知身份。这不是独立外部真值，也不是新代谢物发现。

### 3.2 假设面板

化学家族必须在查看表型统计前冻结。首版固定为：

- 长链酰基肉碱；
- 修饰核苷；
- 乙酰化多胺；
- 唕液酸/Neu5Ac 相关结构。

该面板用于检验“化学家族在多个样本中的检出、丰度与证据层级如何变化”。不得根据 Rmu-vs-RN 显著性再选家族或参考谱。

## 4. 四路必须同协议比较

1. 传统原始谱相似度；
2. 官方 DreaMS shared embedding；
3. 通过冻结工程门的改进 shared embedding；
4. P2b 作为嵌入后的证据融合专家。

P2b 不是新 embedding，ChemAware/BioAware 不得偷改身份真值。ChemAware 可以提供诊断峰证据和异构体 veto；BioAware 只能在检测/定量矩阵之后用于排序生物学一致的模块，不得用表型反向修改身份。

## 5. 身份与生物学声称边界

- 参考库谱命中是发现证据，不自动等于本实验的 MSI Level 1。
- 只有在同平台注入真实标准品并同时匹配 RT/MS/MS 时，才允许升级 Level 1。
- DDA 没触发 MS2 不等于生物学缺失；缺失必须由 MS1 EIC 与技术机会共同解释。
- MTBLS13729 的 Rmu 只有 10 对，只能支撑发现级丰度结论。
- 静态代谢组只能声称丰度差异，不能声称通量或酶活改变。

## 6. 最小闭环与停止门

1. 冻结探针清单和参考谱来源；
2. 用同一样本、同一质量窗和同一聚合规则产生四路命中矩阵；
3. 对 Level-1 校准锚点报告召回、跨样本一致性、错干预和弃权；
4. 对假设面板报告逐样本 MS2 证据、MS1 丰度、身份上限和配对表型统计；
5. 方法结论必须在校准面板上优于官方 DreaMS，生物学结论必须在至少一个独立队列方可称为复现。

若本地缺失三路候选级工件，先生成探针 manifest 和传统谱学基线；不得从聚合日志反推逐样本结果。
