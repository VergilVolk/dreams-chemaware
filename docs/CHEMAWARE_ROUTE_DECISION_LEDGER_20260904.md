# ChemAware 路线决策账本

**日期**：2026-09-04  
**边界**：只讨论如何让化学先验提升共享单谱 DreaMS embedding；不授权正式训练或对外性能声明。

## 已否定或降级的路线

1. **平面质量规则直接加权**：规则缺少结构适用域、反应路径和概率校准；候选间不可区分。
2. **MAGMa 二值碎片掩码**：覆盖率高，但正确碎片解释不稳定胜过同分子式结构置换。
3. **最终 DreaMS 峰 token 化学头**：最终 token 的精确子式可读性弱于原始质量特征。
4. **原始谱图子式预训练后只读 aggregate token**：正确臂未胜过谱内峰置乱臂。
5. **显式 formula × m/z/intensity/loss 化学矩**：一轮配对烟雾测试中正确臂与置乱臂近似，且弱于未预训练臂；暂不扩大训练。

共同原因不是参数不足，而是教师只告诉模型“这个峰可能有什么元素组成”，没有可靠回答“为什么这个候选结构比同分子式异构体更能产生整张实验谱”。

## 当前最强候选路线

### 训练期结构条件化碎裂教师，部署期共享谱图学生

1. 使用结构条件化 forward model 为训练候选生成碎裂 DAG 和条件化强度谱；
2. 在完整同分子式候选组内，用实验谱与每个候选预测谱的匹配得到教师分布；
3. 先审计教师本身是否显著纠正官方 DreaMS 的残余错误，并胜过候选置换、峰置换和边际控制；
4. 只有教师过门，才把候选分布蒸馏到 query/reference 共用的单谱 embedding；
5. 候选结构、碎裂图和 forward model 均不进入最终部署。

当前首选教师为 ICEBERG 2.1，而不是继续扩写人工 neutral-loss 表。原因是它显式生成多步碎裂图，随后预测碎片强度、氢迁移、加合物和碰撞能量条件；其检索训练还专门使用同分子式和图突变负例。人工规则库在这条路线中的角色改为：硬约束、审计、teacher 校准和失败解释，不再直接给共享 embedding 广播权重。

## 效率排序

1. **先做 teacher-headroom**：只在本地 2,529 个候选分子/927 张谱的小图运行；教师不过门立即停止。
2. **离线编译 teacher ledger**：一次生成，训练反复读取稀疏分数，不在线调用碎裂模型。
3. **冻结 DreaMS + 小 residual 蒸馏**：先只训练输出残差；过门后再考虑 rank-4 最后一层 LoRA。
4. **最后才扩大教师和数据**：只对低 margin、同分子式难例运行昂贵碎裂预测；容易样本不浪费 forward-model 算力。

## 不可越过的归因门

正确 teacher 必须在同一 query/candidate ledger 上稳定胜过：

- identity-only clean；
- 同分子式候选结构置换；
- 预测谱峰置换；
- 保持分数边际分布的随机控制。

如果只是“教师筛出的样本”提高了 identity-only 训练，则只能称 curriculum 增益，不能称化学先验增益。
