# 生物应用 agent 下一阶段任务：从大图转向可复现实体响应

下达日期：2026-10-27。依据：最新 `bd3cd0e` 固定边应用结果、截至 `5d17fc1` 的 v1.1 有界修订与同日竞争研究报告。无界 v1.1 已有负结果，有界修订尚未晋级；应用主线仍使用 v1。本任务继续利用已有 15 sources / 51 contrasts，不启动无目标扩库。

## B0：保留真实进展与明确主终点

不要再用旧 2/30 或 1/12 概括最新状态。当前 all/nonmass 药物正控为 24 directions / 12 无向药物对单元：coverage-matched fragment、Official、Stage-1 的 Top-5 是 10/24、13/24、13/24，中位 rank 为 7.5、4.5、4.5；成人→儿科 IBD 是 combined Top-1，反向 rank 4。保留这些结果及负结果，但它们尚未证明自研系统优于 Official，也不是 Full23 的完整新连接实验。

本阶段主问题：**在同一可观测范围内，算法改变哪些实体连接，进而增加多少可被独立研究支持的响应？** 先把具体实体账本做完，再决定 atlas 名称和规模。疾病/药物检索排名保留为诊断，不能作为唯一生物学真值。

## B1：先交设计适格性登记表

对现有 51 contrasts 登记：来源 accession、样本/受试者 ID、重复测量结构、物种、基质、疾病/处理定义、时间/剂量、极性/仪器/色谱、样本量、beta 的尺度、SE 计算、协变量、药物暴露、原始文件及 feature/MS2 可追溯性。

产物 `contrast_eligibility.tsv`：每项注明可支持“同实体效应复现 / 家族关系 / occurrence / 仅方法诊断”中的哪些终点，及排除原因。不同基质、不同物种或时间尺度不强行合成同一个效应。beta 尺度不兼容时不直接 inverse-variance meta-analysis；优先在合适设计内比较方向或预定义的标准化效应。SE 的单位也必须兼容。

51 contrasts 不是 51 独立研究，24 directions 也不是 24 独立药物重复。不同药物并不全是真负例；同药不同组织/剂量未必应当最相似。未审定的关系标为 unjudged。保留原预设正控，不为抬排名事后改真值。

## B2：两个互不混淆的候选实验

**旧轴：固定边重加权诊断。** 原始 fragment-cosine 预选图及世界标签不改，用于复现新旧权重差异。41,082 行包括 evidence worlds；all-world unique edges 是 20,485，不能把重复行当新增连接。

**新轴：模型无关身份候选发现。** 只在当前资产内按预设 precursor/adduct/polarity 等合法条件构建 complete candidate blocks。先保存轴/分母/hash，后评分，后关联响应。它评估旧图漏掉的连接，不覆盖旧实验结果。与算法 agent 对齐 query/candidate/reference/pair ID；旧 22,046 对 handoff 不自动等于新轴。

Full23 的 query-local 特征必须使用完整候选块，不能在 mutual Top-1 表上把每条边伪装成 singleton query。v1 先做，v1.1 尚无晋级结果，不让应用等待。所有方法都在相同轴和 eligible universe 上比较；不让 WSE 或其他单模型阈值决定竞争方法准入。

不同前体的 **relation 轨**独立保留。此处边是化学关系假说，需 analog 方法、片段/中性丢失/家族证据；禁止传递聚类后默认整组件同一分子。关系图可以做家族响应，但不能合并各分子 beta 后声称同实体复现。

## B3：实体变化与外部支持账本

生成 `entity_change_ledger.tsv`，每条包含：旧/新候选、参考谱、身份/关系类型、模型版本、输入覆盖、V2 状态、retained/changed/gained/lost、谱学与化学支持、响应研究及方向/效应/SE、独立验证状态、矛盾证据和未判定原因。

主比较至少包括 WSE、Official、Noise 和合法 Full23。对于传统网络应用，使用相同下游响应统计；不能把复杂方法全流程与一个未连接相同统计流程的裸相似度比较。known-only / all / unresolved 比较加入 coverage、观测率、实体数/边数及 degree 匹配，分辨“多连边”与“更可靠连接”。

结构未知的候选，不编造 SMILES 运行 V2。发布包允许的 unavailable profile 可如实使用，但单独报告适用率和结果，不能写成全覆盖化学证据。已知结构的合法 V2 应真实计算。

报告支持、反对、无信息三类；未检测不等于生物学不存在。统计重抽样遵循研究/受试者/实体依赖，而非以边为独立 n。若探索多个家族/疾病对，保存完整测试集合并处理多重检验，不只报最小 p。

## B4：一个主应用，另留一条有条件备线

### 主应用：实体或家族的跨研究响应

已有成人/儿科 IBD 只作为 consumed discovery 起点。先核实基质与临床定义可比性，以及药物暴露、年龄和采集条件混杂。按预先记录的谱质量、覆盖、身份证据和设计完整度筛出一个核心实体组或化学家族；保留所有筛选记录。不要把“IBD→IBD 排名第一”当生物机制。

应用需要交付一个可读证据链：镜像谱/候选排除 → 为什么新算法改变连接 → 每个研究的效应和不确定性 → 哪些独立证据支持/反对 → 这个结果相对 WSE/Official 新增什么。可先做一个具体家族，不要求立即解释全部 51 contrasts。

已知胆酸-IBD 关系是正控而非新机制。未知谱实体也可以有科学价值，但命名止于证据允许的身份/家族级别。发现阶段选出具体假说后，仅增加必要的独立队列或标准品/正交化学验证，先锁分析再打开结果；不能将已看过的儿科数据重新称封存外测。标准品支持结构身份，独立队列支持响应复现，两者不互相代替。

### 条件备线：具体药物扰动/转化

只选现有确有时间、剂量、菌培养或合适处理对照的子集，提出一个 parent–product 或家族响应问题。利用 GNPS Drug Library、MassQL/碎片规则和公共反向搜索补证据。只有适配时间序列才比较 ChemProp2；只有病例对照的 beta/SE 不冒充生物转化动力学。

药物在公共库出现已被成熟工具覆盖。必须说明算法找回了哪个此前漏掉且得到独立支持的具体候选/转化，而不是生成另一张药物-疾病热图。

## B5：BioAware 的角色与终止条件

BioAware 仅在真实样本事件存在时使用。若它消费当前 contrast 的响应来选择候选，当前响应就不能再作为独立成功证据；需用未参与打分的研究/终点验证。没有真实上下文时不强行插入，不为“全模块”而制造循环。

若新增响应收益在 coverage/degree 匹配后消失，结论是未证实额外生物增量；若身份覆盖不足，先完成连接限制诊断；若只有既有知识再现，作为方法应用/正控而非新发现。保留 HFD 与 unresolved 等负结果。不继续通过换阈值、删研究或扩大数据去追同一目标 p 值。

这不要求放弃 atlas 资产：将其作为可追溯证据目录交付。稿件主结论的强度由实际验证决定，不由图的节点数决定。
