# 生物学方法学定位宣言（2026-10-12 冻结）

**作者：** GLM（生物学应用线负责人）
**审阅：** PI（2026-10-12 研究定位指令）
**状态：** 正式冻结的项目定位文档；后续所有实验设计必须与此对齐

## 一、我们做的是什么

> **面向未知化学空间的无偏代谢组学发现范式**（Unbiased, structure-agnostic metabolomics discovery）

**一句话**：让结构未知的 LC-MS/MS 化学信息第一次以系统、可靠、可迁移的方式参与广泛的生物学发现——不以精确结构鉴定为前提，不以已知通路为筛选条件，不为单一数据集特调。

**这不是概念股。这是一个有算法资产支撑的、切中领域真实局限的、可证伪的方法学研究。**

## 二、为什么我们有优势

传统"非靶向"代谢组学在解释阶段退回已知化合物和已知通路——名字叫非靶向，实际是靶向解释。94% 的检测信号因无结构鉴定而被排除在生物学分析之外。

我们的独特资产：
- **Noise**：跨实验条件稳健的谱图表示（外部验证 +1.20pp）
- **ChemAware**：碎裂化学证据约束候选边界
- **P2b**：局部碎片判别能力
- **15 方法天梯**：冻结的模型盲外部基准
- **边际弃权发现**：置信来自 top1-top2 边际而非绝对分数（AUC 0.848）

这些不是"模块堆砌"——是让未知信号参与生物学分析的**技术前提**。没有跨条件稳健表示，未知实体无法跨研究追踪；没有弃权机制，未知实体无法安全参与统计。

## 三、五条不可违反的原则

| # | 原则 | 具体含义 |
|---|---|---|
| 1 | **无偏发现** | 不从预选分子名单、已知通路或特定疾病假说出发 |
| 2 | **结构非依赖** | 没有谱库命中也能在证据允许的层次参与分析 |
| 3 | **化学信息驱动** | 充分利用 MS/MS 碎裂、局部化学关系及其不确定性，不只靠 m/z 或聚类 |
| 4 | **通用与可迁移** | 同一方法适用于疾病/药物/基因/微生物/植物等非靶向研究 |
| 5 | **可验证的发现** | 输出是可复现的化学变化或可检验假说，不只是更大的网络 |

## 四、三种平等的研究入口

| 入口 | 不需要什么 | 输出什么 |
|---|---|---|
| **单谱查询** | 样本/表型 | 校准的化学证据证书 + no-match |
| **无标签样本** | 疾病/药物标签 | 化学组成、异质性、公共关联 |
| **有设计研究** | 预选分子名单 | 带方向/效应量/不确定性的化学响应 |

三种入口共享同一套冻结表示和证据体系。

## 七、当前主线与下一步

**主线**：公共谱学证据空间 + 事件级扰动复现

**正在推进**：
1. **公共证据证书引擎**：多来源、多证据族、带弃权的 unit assignment（已实现，待真实运行）
2. **样本级投影**：certificate → unit occupancy → 样本化学组成（已实现，待真实运行）
3. **四世界消融**：研究内 MS1 vs 研究内谱学 vs 真实公共 vs 匹配置乱公共（合同已冻结）
4. **MSV000096214 Arabidopsis 扰动**：更好的实验设计（3 条独立 tt7 KO + 通路位置 + 上位关系），审计被限流中

**正确的下一步**（按优先级）：
1. 在任意合格真实数据上完成四世界消融的首轮数字
2. 用非药物、非时间序列研究验证通用性
3. 证明 unresolved 对 known-only 有条件增量
4. 一个完整案例：从无偏发现→跨研究复现→化学关系解释→前瞻功能验证

## 八、明确不做的事

- 不做疾病专属分析流程
- 不做 Contrast Atlas 数据库产品
- 不用新名词包装传统差异分析
- 不让某个数据集的失败定义整个方法
- 不接管算法 coder 的训练与 benchmark
- 不在未过门的数据上追加模型层

## 九、论文定位

统一论文不是"算法冠军+两个故事"的拼接，而是一条因果清晰的价值链：

1. 谱学证据改善排序与 open-set 风险（算法层）
2. 改善转化为更多可靠跨条件实体（实体层）
3. 实体带来 known-only 之外的可复现效应（生物学层）
4. 一个完整案例从发现到功能闭环（决定性案例）
5. 负结果证明停止门有效（诚实边界）

**最强主张**：
> We test whether an unresolved LC-MS/MS entity can be carried, with calibrated correspondence uncertainty, from clinical association to independent replication and a prospective perturbation-isotope functional experiment, without treating exact structural annotation as a prerequisite or a substitute for mechanism.
