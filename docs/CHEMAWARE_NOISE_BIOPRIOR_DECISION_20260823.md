# ChemAware 主线收敛决策：峰级微调、双重映射与生物网络先验

**日期**：2026-08-23  
**目的**：在不推翻原架构的前提下，明确排序器、噪声微调、化学解释和生物学应用的关系、优先级与停止条件。

## 一、不可再改变的四项架构决策

1. **P2b 排序器永久保留。** 它是通过封存主面板验证的性能保底和局部化学证据层，不承担全部创新。
2. **ChemAware 主创新仍是峰级化学感知微调。** 目标是让模型针对真实错误调整谱峰贡献，同时保持 DreaMS 已有全局表征。
3. **双重映射继续作为解释核心。** 解释链为 `embedding/peak token -> 化学概念/局部结构环境 -> 具体谱峰和质量差`，并通过删峰干预验证忠实性。
4. **生物网络先验后置。** 先作为候选后验和置信度层，不直接写入通用 DreaMS embedding；只有跨数据集证明有效后，才考虑蒸馏到 context-conditioned adapter。

## 二、目前究竟完成了什么

| 部分 | 已完成的真实结果 | 尚未完成 |
|---|---|---|
| P2b 局部排序 | 开发 OOF Recall@1 +3.91 pp；封存主面板 +1.07 pp，CI 为正 | near-core 下降，必须保留安全边界 |
| 噪声/反事实微调 | 旧 head 在内部验证约 +0.57 pp；已证明部分峰删除会改变 embedding | 没有用当前完整错误图训练；没有证明可稳定改善外部检索 |
| 规则与概念解码 | 266 个谱图概念 test macro-AUPRC 0.659，基线 0.200 | 概念对检索决策的因果作用未证明 |
| 数据驱动结构环境 | 469 个环境 macro-AUPRC 0.240，基线 0.0447 | 不能唯一定位子结构 |
| 双重映射 | 175 条复现且 embedding 方向一致的结构—谱图概念桥梁 | 逐谱图忠实性闭环尚未大规模完成 |
| 隐式峰因子 | 2 个候选通过“目标峰删除导致额外 embedding 位移” | 两者检索 margin CI 均跨 0；检索因果因子仍为 0 |
| 生物学应用 | MTBLS13729 长链酰基肉碱类别积累及 C20:4 候选形成真实结果 | 外部队列复核、标准品和确定机制仍缺失 |

结论：规则库、解释模块和生物学线都没有白费；它们目前处在“有可复核信号、尚未完成决策级闭环”的阶段。

## 三、旧噪声路线为什么迟迟没有收敛

### 1. 三种不同实验被统称为“噪声”

- Transformer 内部 dropout；
- 通用随机删峰、抖动、加峰；
- 根据真实错误定位的反事实峰干预。

关闭 backbone dropout 只解决了训练时的随机混杂，不等于检验峰噪声。通用随机增强只检验稳健性，也不等于纠正某一类真实错误。真正的主线只能是第三类。

### 2. 通用随机遮峰与 DreaMS 预训练部分重复

DreaMS 已在预训练中按峰强度比例随机遮蔽 30% m/z 并重建。继续做无条件随机遮峰，新增信息有限。旧 `noise_augment.py` 还允许随机删除强峰、对全部峰做 ±40% 强度抖动，并在谱图质量范围内均匀添加假峰；这些扰动可用于压力测试，但并不等价于真实仪器或碰撞能变化。

### 3. 旧反事实样本不是当前真实错误图

`build_counterfactual_peak_finetune_manifest.py` 的主要限制：

- 样本来自旧 discovery reranker 和旧低置信阈值；
- 只有 2,207 个例子、1,163 个分子和 539 个分子式；
- 每个 query 只取一个正例和一个负例；
- 选取 DreaMS 分数最高的正例与负例，不表示最有因果信息的对；
- 峰定位仅用固定 0.02 Da 的贪心集合差；
- 不利用完整候选组，也不使用当前 P2b 的修正、新增和持续错误。

这套样本足以做 pilot，不足以裁决 ChemAware 主假设。

### 4. 早期模型主要改变最终向量，难以真正调整峰贡献

`train_causal_chemmask_head.py` 冻结整个 116M backbone，只训练线性 projection head。它可以重新缩放 embedding 方向，但不能改变 Transformer 内部峰 token 的注意和交互。旧 last1 实验虽然解冻最后一层，却仍在小而偏的三元组清单上训练，且封存外部收益未建立。

### 5. 旧遮峰目标只覆盖了错误机制的一半

`mask_unique_peaks` 删除的是同一分子两张谱图之间的差异峰，主要学习跨条件一致性；它没有直接删除“查询与错误异构体共享、却不支持真实身份”的混淆峰。因此它更容易修 false negative，却很难纠正 shared-main-peak false positive。

## 四、新的 ChemAware 峰级微调：保持原思想，修正实现

### 4.1 错误图谱必须来自当前完整系统

数据源固定为 train fold、P3 身份完全排除的全部有效候选组。第一版直接使用现有 P2 数据池：23,876 个有效真实 query rows、2,522 个身份，保留每个 query 的完整 strict-10 ppm、同加合物候选组。

每个查询分为四类：

1. DreaMS 错、P2b 对：局部峰/中性丢失证据能够修正；
2. DreaMS 对、P2b 错：局部证据会误导，作为保护和冲突样本；
3. 两者都错：真正未解决的困难样本；
4. 两者都对：不允许破坏的稳定对照。

再按 MCES、分子式、Murcko、仪器、碰撞能、谱峰缺失和规则类别分层。训练、验证按分子式或骨架隔离，不再截取按 IK14 排序的前 N 行。

### 4.2 先做因果定位，后做训练

每个错误 query 在训练前必须通过“目标干预 vs 匹配随机干预”审查。

#### A. 异分子过度相似

- 目标峰：查询中与错误候选共享、但在同分子真实谱中不稳定或缺失的高贡献峰；
- 干预：删除目标峰后，query—错误候选相似度应下降，或正负 margin 应上升；
- 对照：删除相同数量、相近 m/z 和强度的随机峰。

#### B. 同分子跨条件分离

- 目标峰：只在某一仪器/碰撞能条件出现的条件特异峰；
- 干预：删除这些峰后，同分子跨条件相似度不应下降，并应优于匹配随机删峰；
- 稳定主峰和类别诊断峰默认受保护。

只有当目标干预的分子式聚类 bootstrap CI 优于匹配随机干预，样本才进入反事实训练。规则命中用于描述和分层，不用于定义正负标签。

### 4.3 模型只增加小型“峰贡献残差”，不重训整个 DreaMS

建议第一版：

```text
官方 DreaMS peak tokens h_i
  -> 轻量峰门控/残差 adapter a_i
  -> z_chem = normalize(z_official + A(sum_i a_i h_i))
```

- `a_i` 只由该谱图的 m/z、强度、peak token 和可选规则概念产生，不读取候选标签；
- 残差初始为 0，模型从官方 embedding 的恒等映射开始；
- 先冻结 DreaMS 主干，只训练峰门控和残差 adapter；必要时才解冻最后一层；
- P2b 保留在 embedding 之后，作为独立保底。

这比单纯训练 projection head 更有能力改变“哪个峰影响全局 embedding”，又比解冻整个 Transformer 更省预算、更容易保持原性能。

### 4.4 损失函数与每项职责

\[
L = L_{\mathrm{group-rank}}
  + \lambda_{inv}L_{\mathrm{real-condition}}
  + \lambda_{cf}L_{\mathrm{counterfactual}}
  + \lambda_{concept}L_{\mathrm{concept}}
  + \lambda_{distill}L_{\mathrm{preserve}}.
\]

- `L_group-rank`：同一 query 的完整候选组内 listwise/ranking 损失，结构身份是真值；
- `L_real-condition`：真实同分子跨仪器/碰撞能谱保持一致，不用合成噪声替代；
- `L_counterfactual`：目标删峰产生预期 margin 变化，并强于匹配随机删峰；
- `L_concept`：从全局/峰级表示解码已验证的 CF、NL、ISO 和局部结构环境；
- `L_preserve`：在稳定对照和官方正确样本上蒸馏官方 DreaMS 候选分布，而非只约束一个向量余弦。

规则不作为距离标签；规则在这里承担概念监督、峰保护、样本分层和解释输出。

### 4.5 不可跳过的门

#### Gate N0：错误图覆盖

- 使用全部合格 query，不以固定前缀截断；
- 报告 IK14、分子式、骨架、near/mid、仪器和 CE 覆盖；
- P3 身份重叠必须为 0。

#### Gate N1：峰定位有效

- 目标删峰相对匹配随机删峰的 margin 改善 CI > 0；
- 至少在两个主要错误类别中复现；
- 按分子式聚类 bootstrap。

#### Gate N2：微调内部验证

- 主 Recall@1 不低于官方 DreaMS；
- near Recall@1 改善或至少不退化；
- 新增错误数低于修正数；
- 规则概念 macro-AUPRC 不下降；
- 稳定样本的候选分布蒸馏保持。

#### Gate N3：新封存测试

- 模型、阈值和错误类型定义全部冻结后一次性评估；
- 同时报 DreaMS、DreaMS+P2b、ChemAware、ChemAware+P2b；
- 任何新模型不能以牺牲 near-core 换主面板增益。

## 五、双重映射怎样真正接入主线

现有结果已经构成第一版映射骨架：

```text
embedding / peak token
  -> 266 个实验碎裂概念 + 469 个局部结构环境
  -> 175 条复现桥梁
  -> 支持峰/峰对与质量差
  -> 目标删峰忠实性检验
```

下一步不再无目的地挖更多无监督因子，而是优先验证三类对象：

1. P2b 修正而 DreaMS 错的样本中，哪些中性丢失概念提供真实支持；
2. P2b 新增错误的样本中，哪些概念造成误导；
3. DreaMS 与 P2b 都错的样本中，175 条桥梁是否存在系统缺口。

通过忠实性门的概念用于 `L_concept` 和模块二；未通过的概念只展示为候选证据。这样，解释模块与微调共用同一批真实错误，并形成“解释—反馈—再训练”的闭环。

## 六、生物网络先验应该放在哪里

### 6.1 可以做，而且已有充分方法学依据

已有工作已经证明代谢网络可以提高候选优先级和注释覆盖：MetDNA 使用代谢反应网络递归传播种子注释；NetID 用质量差、加合物、碎裂、同位素和生化转化做全局优化；mWISE 直接在 KEGG 生物/生化网络上做图扩散；KGMN/MetDNA2 和 2025 年的 MetDNA3 进一步组合反应网络、MS2 相似网络和峰相关网络。

因此，“把网络 diffusion 加进来”本身不是创新。我们的价值必须来自：**DreaMS/ChemAware 谱图证据 + 峰级解释 + 生物网络上下文 + 冲突和弃权机制**。

### 6.2 第一阶段采用后验融合，不改通用 embedding

对候选结构 `c`：

\[
S(c)=S_{spectral}(c)+\gamma S_{network}(c)+\eta S_{sample}(c),
\]

其中：

- `S_spectral`：ChemAware + P2b 的冻结谱图证据；
- `S_network`：从高置信种子沿 KEGG/MetaCyc/自建反应边扩散得到的先验；
- `S_sample`：同一队列中共洗脱、同位素/加合物、跨样本丰度相关等无表型证据。

网络扩散可使用 personalized PageRank 或图核：

\[
f=(1-\alpha)(I-\alpha P)^{-1}y,
\]

`y` 只由标准品/高置信谱库种子和冻结谱图概率构成。疾病标签不能进入候选身份评分，否则会形成“用预期通路决定结构，再用结构证明通路”的循环论证。

### 6.3 图的三层组织

1. **观测层**：MS1 feature、MS2 谱图、离子家族、RT 和跨样本相关；
2. **化学层**：候选分子、加合物、同位素、碎片/中性丢失和结构相似关系；
3. **生化层**：代谢物—反应—酶—通路网络。

ChemAware 提供观测层到化学层的似然和解释；网络扩散只提供化学层到生化层的上下文先验。

### 6.4 防止网络先验自我证明

- leave-one-seed-out：隐藏已知代谢物，检验能否从邻居恢复；
- degree-matched network decoy：排除高连接节点天然得高分；
- pathway-holdout：整个通路不参与种子构建，测试跨通路泛化；
- 冻结谱图分数后再估计网络权重；
- 同时报谱图证据强、网络一致；谱图证据强、网络冲突；谱图不足、仅网络支持三种状态；
- 仅网络支持不能升级为 MSI Level 2。

### 6.5 为什么暂时不把生物先验直接用于 DreaMS 微调

组织来源和通路先验高度依赖队列。直接写入通用 embedding 会把常见代谢物、常见组织和已知通路偏好固化进模型，可能压制罕见代谢物和真正的新发现。正确顺序是：

1. 后验融合证明跨队列有增益；
2. 建立校准和弃权；
3. 再考虑把网络后验蒸馏到一个可选的 context adapter；
4. 官方/ChemAware 通用 embedding 始终保留不带生物上下文的版本。

## 七、生物学应用的短期主线

### 7.1 MTBLS13729 不是零结果

当前已获得一条可审计发现线：

- 1,653 条酰基肉碱类别支持 MS2；
- 20 个独立长链特征的 Rmu-RN 类别分数约 `+1.35 log2`，精确 `p=0.0059`；
- 匹配随机背景经验单侧 `p≈0.0005`；
- C20:4 酰基肉碱候选最佳 cosine 0.903，但仍是 Level 2 候选。

下一步不是重新寻找故事，而是：

1. 用 P2b 和模块二重新审查 31 个有 MS2 的优先候选；
2. 对酰基肉碱相邻反应、肉碱穿梭和 β-氧化网络做后验扩散，检查是否出现独立相邻代谢物支持；
3. 在公开 CRC 队列做类别级外部复核；
4. 若无标准品，只写“类别积累和候选机制”，不写通量或确定酶靶点。

### 7.2 MTBLS1905 作为外部错误与注释验证线

已知 36 张谱的小面板中，DreaMS 的错误集中在核苷/嘌呤、氨基酸、含硫代谢物、泛酸和色氨酸相关分子。该面板太小，不能训练，但适合检验新的 ChemAware 是否真正纠正具有生物意义的真实错误。任何参数选择都必须在 MassSpecGym/train 完成，MTBLS1905 只作外部验证和案例解释。

## 八、执行优先级

### P0：立即完成（已完成）

- 正式冻结并归档 P2b；
- 保留主面板收益与 near 边界；
- 不再在 consumed P3 上调门。

### P1：当前最高优先级——重建真实错误图与峰因果定位

- 使用当前 DreaMS + P2b 的完整候选组；
- 生成四类 transition 和完整分层；
- 重做目标峰 vs 匹配随机峰因果审计；
- N1 不通过则不训练。

### P2：通过 N1 后——轻量峰残差 adapter 微调

- 完整候选组 listwise；
- 真实跨条件同分子一致性；
- 错误驱动反事实；
- 化学概念辅助；
- 候选分布蒸馏；
- P2b 作为独立保底，不被覆盖。

### P3：并行低成本——完成双重映射忠实性

- 从 175 条桥梁中优先选与当前错误富集相关的概念；
- 逐谱图目标删峰；
- 只保留可解码、可定位、干预方向正确的解释。

### P4：并行生物学——锁定酰基肉碱主线并做外部复核

- 用新排序器/解释模块提高 31 个候选的结构证据；
- 建立不使用表型标签的反应网络；
- 复核公开 CRC 队列；
- 形成“算法纠错—新增注释—代谢网络变化”的应用闭环。

### P5：最后再做——生物网络 diffusion 产品化

- 先做后验候选排序和不确定性；
- 通过 leave-one-seed-out、网络 decoy 和 pathway holdout；
- 跨数据集有效后再考虑 context adapter。

## 九、停止规则

- 若目标峰干预不优于匹配随机峰，停止该错误类别，不进入训练；
- 若峰残差 adapter 只提高开发集、封存集不改善，保留 P2b，不宣称 embedding 改善；
- 若网络 diffusion 只提高已见通路、在 pathway holdout 失败，则只作为探索性可视化；
- 若生物学候选没有独立 MS2/类别/外部队列证据，不升级结构和机制结论。

## 最终裁决

项目不转向单纯排序器，也不把网络 diffusion 当作新的口号。最终架构保持为：

```text
ChemAware 峰级微调
  -> P2b 保底候选排序
  -> 双重化学映射与置信度
  -> 生化网络上下文后验
  -> 生物学发现与冲突样本反馈
```

近期成败的第一决定点不是再训练一个模型，而是能否在当前完整错误图上证明“定向峰干预确实比匹配随机删峰更能纠正真实错误”。这个门通过，噪声微调才有坚实的因果基础；不通过，则必须保留排序与解释成果，停止把随机遮峰包装成 ChemAware。
