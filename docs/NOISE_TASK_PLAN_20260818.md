| # | 决策 | 内容 | 备注 |
|---|---|---|---|
| 1 | 正例噪声 | **纯合成噪声**，不用真实跨仪器对 | 之前"合成噪声无 headroom"结论作废——上次是工程实现问题 |

## 3. 方法学验证（这套方法有先例，不是拍脑袋）

对比学习（InfoNCE）+ 同分异构体 hard negative 是当前 MS 谱表示的主流范式：

1. **专利 CN122084812B**：明确把 hard negative 构造成"**同分异构体**，或谱相似但保留时间不同的样本"。
2. **MS2-SMILES AlignNet (MSAN)**（Anal. Chim. Acta 2026）：InfoNCE + Tanimoto-MSE 结构保持，明确为改善
   **同分异构体区分**（单分支不足，双分支+结构保持才够），CASMI 2016/2022 验证。
3. **CLERMS**（Anal. Chem. 2023）：对比学习谱嵌入，InfoNCE + MSE。
4. **CSU-MS2**（Anal. Chem. 2025）：跨模态对比学习。

我们的定位：上述方法打"谱↔分子结构跨模态对齐"，我们打"谱嵌入自身对噪声不变 + 对异构体可区分"——
同一范式，但直指 DreaMS 审计定位的 FN（条件漂移）/FP（撞脸）两个错误。

## 4. pair-classes 方法（用户猜想，逐条定义）

对分子 A 及其同分异构体 B/C/D，以及 A 的噪声版本，构造以下 pair 类（InfoNCE 天然覆盖）：

| # | 对 | 标签 | 教什么 |
|---|---|---|---|
| 1 | A vs 噪声A | 正例 | 噪声A = A（不变性），错就惩罚 |
| 2 | A vs 异构体B | 负例 | B ≠ A（区分） |
| 3 | 噪声A vs B | 负例 | 噪声不影响区分异构体 |
| 4 | A vs C | 负例 | 同上 |
| 5 | 噪声A vs C | 负例 | 同上 |
| 6 | A vs 噪声B | 负例 | 噪声作用于负例侧仍须区分 |
| … | 以此类推 | | 噪声 + 异构体两侧交叉 |

实现：anchor=A，正例=噪声A，负例列表={B, 噪声B, C, 噪声C, D, …}，InfoNCE 一次性覆盖全部组合。
噪声在**正负两侧都施加**，保证模型学到"不变性不等于抹平异构体差异"。

## 5. 数据构建方案（待确认参数）

### 5.1 合成噪声菜单（**已定案 2026-08-18**：四轴全上）

FN 的物理机制：同一分子在不同 CE/仪器下，峰强度变、峰出现/消失、峰位置微移。合成噪声对齐这四轴：

| 轴 | 操作 | 参数 | 模拟的物理来源 |
|---|---|---|---|
| 删峰 | 随机删 p% 峰（**含强峰**，非只弱峰） | p ~ U[0, 0.3] | CE 相关碎片消失 |
| 强度 | 抖动 ×U[1−α, 1+α] | α=0.4 | 丰度/电离波动 |
| 加峰 | 加 0–10 个弱峰 | 强度 U[0, 0.05]，m/z 随机 | CE 相关新碎片 |
| **m/z** | **位移 δ** | δ ~ N(0, 0.01 Da) | 质量校准/仪器漂移 |

**关键新增轴 = m/z 位移**（之前 pilot 缺失，且 DreaMS 预训练只掩峰、从不位移——见
`docs/MS2DEEPSCORE_NOISE_METHOD_RESEARCH_20260817.md` §2）。

**实施顺序（关键）**：噪声加在**原始谱（raw m/z + intensity）上，再走 spec_preproc**。
这样 trim→top-n→归一化会与噪声交互，真实模拟"峰进入/掉出 top-n"，而不是在 token 上做表面扰动。

### 5.2 异构体负例（**已定案 2026-08-18**：MassSpecGym 内找，复用 T1 方法）

在 **MassSpecGym train fold 内部**找异构体（不复用 annotated01.mgf 的 T1 数据）：
- 数据：MassSpecGym HDF5 直接有 `smiles` 字段 → RDKit 算 formula。
- 分组：同 formula + 不同 ik14（连接层不同 = 异构体候选）。
- **判据：MCES（myopic_mces），弃用 Tanimoto**（用户：Tanimoto 可能把同分子误判成不同分子=灾难性；
  而 MCES 只量骨架连接差异，同分子 MCES 差=0，不会误判）。分级 [0,2]=近异构体、[6,10]=远异构体、[3,5]=中间。
- **标签**：本任务按分类式，异构体（无论 MCES 远近）一律当**负例**（≠ T1 的度量式"近=正例"）。
- 规模（2026-08-18 审计）：formula 组 14891，含 ≥2 ik14 的组 3865，异构体对 21944，组 median=2。
- 预留接口：MolFormer/Chemprop 后续替换 MCES 找异构体。

### 5.3 组装（anchor, pos, neg_list）

- anchor = 干净谱 A（从 MassSpecGym train fold 挖，有 IK14 + 有异构体对的分子）。
- pos = 合成噪声谱 噪声A。
- neg_list = 该分子的异构体负例谱（含噪声版本）+ in-batch 其他分子。

## 6. 之前失败的原因（反例，这次必须逐一避开）

1. backbone 被冻结（只训 head）→ 这次解冻 backbone（至少 last-1/last-2 层）。
2. LR 3e-5 过低 → 重扫。
3. 样本 600 太小 → 数千~万级。
4. 随机负例非异构体 → 用异构体 hard negative（T1）。
5. 正例 = 谱 vs 自身抖动（cos 0.91 平凡）→ 正例要真模拟 CE/仪器（含 m/z 位移）。
6. triplet margin 0.05 已饱和 → InfoNCE 多负例。

## 7. 因果门（每步过门才推进）

- **G1 数据构建**：噪声菜单 + 异构体负例 + 组装产出样本，规模/配比/标签正确性通过审计。
- **G2 训练 smoke**：小样本跑通 InfoNCE，确认 backbone 动了、梯度真、无 NaN。
- **G3 噪声一致性**：锁定尺上 原谱 vs 噪声谱 余弦稳定性 ↑，且检索/子群不降（FP 守卫）。
- **G4 全量 3 种子**：方向一致才采信。
- 任何一门不过 → 定位原因、调参重跑；仍不过 → 停。
