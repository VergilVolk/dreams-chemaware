## 0. 用户定下的方向（2026-08-16 原话要点）

1. FP/FN 之前都有化学因子挖掘记录：命中化学规则库规则的程度的记录。
2. 某任务命中某类化学规则多 → 扩充该类规则（**目前决定：先不扩充，只用 3,486 条**）；
   通过非线性学习头在 [0,1] 内学每条规则权重（初始全 0.5，学到如 0.62/0.49，**不要差太多**）。
3. 用带权规则命中度构造正负样本与 triplet（困难样本挖掘）。
4. 不用老训练方式，改 **MS2DeepScore 式加噪声**：让模型能区分困难样本与加了噪声的困难样本。
   困难样本 = 同分子 / 同分异构体 / 不同条件的同分子；**有的拉近、有的拉远**。

## 2. 总体方案（一段话）

在 DreaMS **官方微调权重**上，为 FP、FN 各学一套**规则权重头**（规则元特征 → 非线性 MLP → w∈[0,1]，
初始 0.5，正则压住不许极端）。带权规则命中度**不定义标签**（标签仍 IK14+严格 10ppm），只做两件事：
**挖矿**（按带权规则分排序选困难样本）和**可微软加权**（带权规则分作为 pair 难度权重进 triplet 损失，
梯度端到端回传给规则头——这就是"学习"的通路）。构造出的优质样本加 **MS2DeepScore 式噪声**
（改丰度，先经小实验验证），同分子（含跨条件同分子）及噪声变体**拉近**、同分异构/质量近邻难负例及
其噪声变体**拉远**。全程每步过严格因果证明门，训练样本数万级。

## 3. 分步严格实验计划（每步有通过门，不过就停）

### Step 1 — 规则命中证据统一与复现（数据地基，不改模型）
- **做什么**：优先最近的工作（`double_mapping/spectrum_rule_labels`、`compact_rule_panel`），
  统一成两张表：① 逐谱带权规则画像；② pair 级规则证据表（每候选对：共享命中规则、冲突命中规则、
  按类别计数）。同分子对里的"冲突规则"= 条件敏感证据（FN 信号）；不同分子对里的"共享规则"=
  撞脸碎片证据（FP 信号）——与 P1"规则是冲突/不确定性信号"的结论一一对应。
- **第一个数据门（关键）**：数 train-fold 内**真实跨条件同分子对**（同 adduct、仪器不同或 CE≥10）
  有多少。≥数千 → FN 训练可用真实对；只有几百 → 用噪声变体做条件代理补足（Step 3 结论兜底）。
  同时确认 10ppm 池规模（112k anchor / 5.1M 正边 / 4.8M 负边）满足数万级采样。
- **门 G1（复现）**：从所选工件复现 P1 数字（错误判别 ROC-AUC 0.647 不同分子 / 0.599 组内；
  3,486 全同权 > 筛选面板）。复现不上 → 停，查工件口径，不往下走。

### Step 2 — 每任务规则权重头（FP/FN 各一套）+ 可微挖矿
- **做什么**：规则元特征（P1 审计的覆盖度/稳定性/错误方向签名等）→ 非线性 MLP → w∈[0,1]，
  初始 0.5，正则 λ‖w−0.5‖² 压住（目标分布集中在 0.5 附近，"别差太多"）。
  训练时：带权规则分作为 pair 难度权重**软加权**进 triplet 损失（可微，梯度回传规则头）；
  挖矿时：按当前权重排序**离线采**困难样本。FP 头加权难负例侧（不同分子、共享规则证据高→推远）；
  FN 头加权正例侧（同分子、条件敏感规则分歧大→拉近）。标签仍 IK14+严格 10ppm，规则不进推理模型。
- **门 G2（小 dev 集，数千对）**：① 权重不极端（仍集中在 0.5 附近）；② **加权 ≥ 全同权**
  （P1 的线：筛选面板输给全同权，学出来的软权重必须赢过全同权）；③ 高梯度规则与 Step 1 审计
  签名一致（学出来的重要规则 = 审计发现的信息规则）。

### Step 3 — MS2DeepScore 噪声验证小实验（先行，不进主训练）
- **做什么**：先**上网调研**近期（2024–2026）谱图/分子表征的噪声增强方法，与 MS2DeepScore
  三件套（强度抖动 ±40% + 删弱峰 0–20% + 加峰）结合，写依据文档。小实验：冻结 backbone +
  官方头初始化，2–5k 对，head-only；噪声变体**继承原谱标签**（同分子连同抖动变体拉近、
  难负例连同其变体拉远）。
- **门 G3（"可用"判定，见 §4 待确认 1）**：锁定尺上噪声一致性↑（原谱 vs 抖动谱余弦）+
  10ppm 检索与 FP/FN 子群指标不降 + 3 种子方向一致。不过 → 调噪声强度/菜单，重跑，仍不过 → 停。

### Step 4 — 规则加权 + 噪声联合正式训练（数万级样本）
- **做什么**：官方微调权重（`embedding_model.ckpt`）初始化；10ppm 池为样本源；
  FP 侧：带权规则挖的难负例；FN 侧：真实跨条件对（若 Step 1 计数 ≥数千）+ 抖动变体做条件代理；
  联合损失 + 3 种子；head-only 起步（CPU 可跑，有 GPU 更快），主计划 §8 的逐层解冻只在通过门后。
- **门 G4（主守卫）**：§8 全套（Top-1 / 10ppm AUC / Pearson / Spearman / 残差 RMSE / 已验证
  错误子群），fixes > regressions 逐对审计，test 只读一次。

### Step 5 — 因果证明链闭环与判定
- **做什么**：对账链条：规则命中记录 → 权重头学到的重要规则 → 挖出的样本构成 → 噪声训练 →
  锁定尺上错误子群变化，每一环对得上才宣称；对不上回对应环修正。
- **门 G5（判定）**：只有 G1–G4 全绿 + 链条对账一致，才写"改正成立"的结论；否则如实记录。

## 3.5 Step 1 已核实结果（2026-08-17，脚本 `tasks/step1_rule_evidence_unify.py`）

- **G0（匹配器一致性）通过**：3,486 规则匹配器在 200 张留出谱上，与既有 335 规则缓存
  及 P1 代码路径位级一致（0 mismatch）。
- **G1（P1 复现）通过**：重跑两个 P1 验证脚本，面板 ROC-AUC 最大绝对差 = **0.0**（位级复现）。
- **池规模确认通过**：train 10ppm = 112,601 / 5,125,411 / 4,828,326；val = 21,163 / 924,136 /
  772,886，与主计划一致。并集 140,272 张唯一谱。
- **跨条件数据门（关键发现）**：train fold、`[M+H]+`、real-only 同分子同加合物对中，
  **跨仪器 = 86,390 对 / 3,956 分子**（≥数千，FN 训练数据充足）；但**跨 CE 真实对 ≈ 0**
  （ce_only=2, both=0）。含模拟谱才有大量 CE 变化（ce_only 687,937 / both 316,830）。
  → 结论：**跨仪器 FN 可用真实数据训练；跨 CE FN（gap 最大 0.676→0.19）真实数据几乎为零，
  只能靠噪声（强度抖动=CE 代理）补**。Step 3 的 MS2DeepScore 小实验因此是**必需**而非可选。

## 3.6 Step 1 类别级证据（2026-08-17，pair 证据按类别拆分）

pair 级共享/冲突证据按 6 类拆分（train 10ppm；pos=同分子对 5,125,411，neg=不同分子对 4,828,326）：

| 类别 | pos 共享 | neg 共享 | Δ共享(pos−neg) | pos 冲突 | neg 冲突 |
|---|---|---|---|---|---|
| **CF** | 26.1 | 13.6 | **+12.5** | 70.4 | 103.6 |
| **NL** | 56.3 | 51.9 | **+4.4** | 72.7 | 92.1 |
| HR | 5.3 | 5.1 | +0.2 | 2.5 | 3.0 |
| EE | 1.0 | 1.0 | 0.0 | 0.0 | 0.0 |
| ISO | 0.1 | 0.1 | 0.0 | 0.8 | 1.1 |
| NR | 0.9 | 0.9 | 0.0 | 0.1 | 0.1 |
| **all** | 89.6 | 72.6 | +17.0 | 146.5 | 199.9 |

（val 同向：pos 共享 95.1 > neg 79.0，CF 30.3 vs 20.7、NL 57.2 vs 50.8。）

**结论**：身份判别信号几乎全部集中在 **CF（Δ共享 +12.5）与 NL（Δ共享 +4.4）**；
EE/HR/ISO/NR 的共享数正负例几乎无差（Δ≈0），是近普适规则、不携带身份信息。
这与规则库构成一致：CF 3,174 条（其中 3,072 条是 MassBank 近普适中性丢失）、NL 293 条、
HR/ISO/NR/EE 仅 19 条。**预期 Step 2 权重头应学出：主库 CF/NL（信息规则）权重偏离 0.5，
MassBank 大批量 CF 与 EE/HR/ISO/NR（近普适）权重停在 0.5 附近** —— 这就是 G2
"高梯度规则与审计签名一致" 的可证伪预测。

## 3.7 Step 2 结果（2026-08-17，脚本 `tasks/step2_rule_weight_head.py`）

规则权重头（12 维规则元特征 → 32→16→1 MLP，w = 0.5 + δ·tanh(z)，δ=0.25 硬界）在
801 错误分子 + 1304 对照分子（分子不相交 70/30 训练/评估，eval 631 条查询）上训练。
三门全绿：

- **G2-1（非极端）通过**：max|w−0.5| = 0.25（被硬界顶住，不再到 0/1），饱和比例
  0.67%（<5%），98.0% 规则在 |w−0.5|≤0.10 内，均值 0.0091。
- **G2-2（加权≥全同权）通过**：加权 ROC-AUC **0.6382** > 全同权 **0.6177**（+0.0205）。
  关键：与无硬界那次（0.6387）几乎一致 → 增益来自 NL/主库规则的**集体重加权**，
  不是先前失控的极端规则；硬界去掉那条规则几乎零成本（−0.0005）。
- **G2-3（签名）通过**：按重要度 |w_fp−0.5|+|w_fn−0.5| 排，top-100 = NL 92 + HR 5 +
  CF 2 + NR 1（73% 主库）；bottom-100 = 100% MassBank CF。与 §3.6 可证伪预测一致：
  信息规则（主库 NL 为主）偏离 0.5，MassBank 近普适 CF 批量停在 0.5 附近。

**诚实口径**：G2-2 是点估计获胜（+0.0205），95% CI 大幅重叠（加权 [0.592, 0.684] vs
全同权 [0.571, 0.666]），**不是统计显著**。门按"点估计 ≥ 全同权"通过，但不可宣称
"显著提升"。方向上稳健（硬界前/后一致），量级上是软增益。

**category-only 消融（2026-08-17，`--cat-only`）**：去掉 5 个连续特征、只留 6 类别
one-hot + is_main（7 维），加权 ROC-AUC **0.6352** vs 全特征 0.6382（−0.003，bootstrap
噪声内）。结论：+0.02 的增益是**粗类别信号**（NL↑、MassBank CF↓），5 个连续元特征几乎
无贡献。两次 run 的 max|w−0.5| 都顶到 0.25 硬界 → 头已榨干粗信号、正压着"别差太多"的
上限，**调 lr/reg/δ 无空间**（只会更极端、不会变显著）。另更正：cat-only 下 top-100
主库占比 73%→21% 但 AUC 不变 → 驱动 AUC 的是**类别（NL vs CF）**而非"主库 vs MassBank"，
之前"主库 73%"是过度解读。

## 3.8 Step 3 结果（2026-08-17，脚本 `tasks/step3_noise_consistency_pilot.py`）

强度域噪声（MS2DeepScore 三件套：删弱峰 0–20% + 抖动 ±40% + 加峰）head-only 小实验，
3 种子（split 固定，426 train / 174 eval）：

- **头几乎没动**：baseline vs trained 噪声一致性分离度只差 ~1e-4（0.805353→0.805473 /
  0.815135→0.815123 / 0.792556→0.792566），是浮点噪声。
- **原因**：官方头下 cos(原谱,抖动谱)≈0.91、cos(原谱,异分子)≈0.10，triplet 项
  （margin 0.05）**一开始就满足**，loss 从 epoch 1 就 ≈0，无梯度可学。
- **结论（诚实）**：DreaMS 在 ±40% 强度抖动 + 删弱峰 + 加峰下**本来就噪声不变**
  （与掩峰预训练重叠），强度域噪声**无 headroom**。G3"噪声一致性↑"名义上 seed 1/3 pass、
  seed 2 fail，是接近零的 Δ 在正负号飘，**无意义**。
- **推论**："强度抖动 = CE 代理"假设被削弱——真实 CE gap 在嵌入空间很大（Step 1），
  ±40% 抖动复现不出。→ 噪声兜底方案无效，转回**真实跨条件对**（方案 3）。
- retrieval 子集 n_queries=5 无统计意义，仅作 smoke。
