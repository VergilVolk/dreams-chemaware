# Noise-v3 A4-B0：同身份正证据几何上限

## 阶段结论

A4-B0 在完整 A4 诊断面板（4,998 queries；1,805 个官方错误，3,193 个安全对照）上通过预注册门槛。结果证明：真实同身份参考谱形成的正证据方向，包含足够大的纠错梯度，可以进入公式隔离的学生蒸馏实验。

这仍是训练期教师上限，不是可部署模型性能。教师使用了查询真实身份对应的其它谱图；封存测试时无法获得该信息，也没有更新 DreaMS 权重。

## 预注册主结果（alpha = 0.25）

| 指标 | 结果 |
|---|---:|
| Baseline accuracy | 0.6389 |
| Teacher-target accuracy | 0.7351 |
| Corrected / introduced | 542 / 61 |
| Risk-weighted net（corrected - 2×introduced） | 420 |
| 超出历史与 A4 的新增修正 | 159 |
| 公式簇 bootstrap risk-net / query | 0.0840 [0.0691, 0.0997] |
| 错误集 target - matched-random accuracy | 0.2526 [0.2240, 0.2834] |
| Positive-deficit corrected | 465 |
| Near corrected | 374 |

四个预注册门全部通过：新增修正不少于 80；风险净收益的公式簇置信区间下界大于 0；错误集教师方向显著优于匹配随机方向；新增错误不超过修正数的一半。

## 剂量结果的使用边界

- alpha=0.10：189/23，梯度较保守，新增独立修正仅 14。
- alpha=0.25：542/61，是预注册主剂量，作为 B1 教师目标。
- alpha=0.50：1168/173，显示更大几何上限，但属于看过结果后的探索性剂量；不得替换主剂量或据此声称模型提升。

## 下一步 B1

以 alpha=0.25 生成训练期教师目标；学生推理只接收干净的官方查询 embedding。采用 formula-group OOF，对照线性残差与非线性残差，并锁定官方候选分数后仅叠加学生造成的相对分数位移。只有当非线性学生同时满足公式簇显著净收益、至少 80 个净修正、near 不退化、安全对照保持以及显著优于线性残差时，才进入峰 token / backbone 微调。
