# 反向语境联合模型 A1：双轴留出与观察模型合同

**日期：2026-09-12**  
**状态：在任何模型拟合前冻结。**

## 任务不是“再做一次谱库检索”

给定一个具有标准谱和化学结构的 anchor，估计它在公共项目、样本大类和组织语境中被观察到的相对强度，同时显式控制仪器、极性、项目规模和 blank/QC 命中。输出不是代谢物身份，而是化学结构在生物语境中的可观察分布及不确定度。

## 两个不可混淆的泛化轴

1. **project holdout**：测试项目在训练中完全不可见，检验跨实验室/队列迁移；
2. **identity holdout**：测试 IK14 在训练中完全不可见，检验向新化学结构迁移；
3. **joint holdout**：项目与 IK14 同时不可见，是第一版最严格的主压力测试。

所有拆分由固定 seed 20260912 的 SHA-256 哈希决定，不按观察结果重抽。

## 三个必须同协议比较的模型

- `B0`：公共库暴露量和全局观察率；
- `B1`：B0 加仪器、极性等技术可检测性，不含化学—语境交互；
- `M1`：B1 加化学表示与生物样本语境的交互。

只有 M1 在 project holdout 与 joint holdout 上同时超过 B0/B1，且 blank/QC 风险不升，才说明学到了增量化学—生物语境信号。

## 标签与结论边界

- 严格谱匹配是 positive observation；
- 未匹配是“在当前公共数据及采集条件下未观察”，不是生物学不存在；
- v1 采用观察强度/点过程或 PU 口径，不训练朴素 presence/absence 分类器；
- HealthStatus 缺失占主导，v1 仅审计，不用于模型选择；
- A1 manifest 不产生任何模型增益或疾病机制结论。

## A1 初始封存结果与唯一允许的扩容

256-anchor A1 使用固定 seed 后，project holdout 与 identity holdout 单独均有足够正观察，但 joint holdout 只有 34 条生物正观察，低于预注册的 50 条，因此不得开始拟合。

唯一允许的修正是扩大标准谱覆盖，不改变命中阈值、拆分 seed 或通过门：每个 superclass 最多取 64 个；若该类库中不足 64 个则全部保留（核苷类当前为 39 个）。扩容结果写入 `reverse_context_joint_a0c` 和 `reverse_context_joint_a1c`。若 joint holdout 仍不足 50，首版 M1 停止，不再通过重抽拆分或降低门槛补救。
