# 基于 MS/MS 实体对应的跨研究扰动响应指纹

日期：2026-10-05  
状态：研究提案 v0.2（高风险假说；尚无最小隐藏真值证据，不得作为既成成果或投稿主方法）  
暂定英文名：*Spectrum-anchored transfer of metabolomic perturbation-response fingerprints across studies*  
范围：只讨论应用方法及其实证；算法模块沿用冻结版本，不以重新包装算法作为创新。

> **证据成熟度修订（2026-10-05）：** 本路线目前只有具体问题、可证伪假设和失败条件，没有完成跨研究实体迁移、未知实体增量或前瞻闭环中的任何一项。全部价值依赖“未知 MS/MS 谱图实体能够跨仪器、跨研究可靠迁移”这一未验证地基。在最小实验通过前，本文件只能作为研究提案；详细审查和停止规则见 [证据门审查记录](./SPECTRUM_ANCHORED_PERTURBATION_EVIDENCE_GATE_REVIEW_20261005.md)。

## 0. 判决先行

上一版“以可辨识生物学结论为中心”的方案不够资格承担论文主创新。它本质上是敏感性分析、信息价值和报告规范的组合，可以保留为质量控制层，但没有产生新的科学对象、新的测量功能或新的发现能力。没有隐藏真值实验和前瞻性发现时，它只是一张复杂清单。

本文件提出一个更窄、也更容易被证伪的候选方法：

> **不先给未知峰强行命名，而是用 MS/MS 将同一谱图实体跨研究连接起来，并把该实体在一组受控基因或药物扰动下的定量响应向量定义为“扰动响应指纹”。随后在独立疾病队列中寻找同一实体，检验疾病变化与哪些受控扰动同向或反向。**

它试图增加三件现有常规流程没有的东西：

1. **新对象：** 一个谱图实体的跨实验扰动响应指纹，而不是一个候选化学名称。
2. **新功能：** 在尚不知道精确结构时，仍可测量该实体受哪些干预控制、与疾病状态是否同向，以及什么干预可能逆转它。
3. **新发现单元：** “同一 MS/MS 实体 + 可重复的疾病方向 + 受控扰动方向 + 前瞻响应”，而不是“差异峰 + 数据库通路故事”。

这三点目前只是可检验假说。只有完成跨仪器隐藏身份、留出扰动检索、疾病已知机制和前瞻干预四类实验，才有资格称为方法学贡献。否则应降级为一次应用分析。

## 1. 它究竟解决什么过去解决不了的问题

### 1.1 现有代谢扰动图谱有响应，却没有可跨研究复用的未知实体坐标

药物或基因扰动代谢组学可以产生大规模响应矩阵，但这些矩阵通常依赖本研究内部的 feature 编号、保留时间和处理流程。已知代谢物可以凭名称跨研究连接；大量未知 feature 无法可靠迁移，因而在外部疾病队列中被丢弃。

这里的关键技术对象不是“另一个扰动图谱”，而是一个跨研究对应关系：

\[
q_{ij}=P(z_i=z_j\mid \mathrm{MS/MS},m/z,\text{ion mode},\text{quality}),
\]

其中 \(z\) 表示“产生该观测谱图的分析实体”。它不等价于立体化学层面的精确结构身份。匹配失败或歧义过大时必须弃权。

### 1.2 公共谱图检索提供“在哪里出现”，却通常不提供受控的变化方向

MASST、ReDU 和 StructureMASST 可以把谱图或结构放回公共样本背景，但出现次数或元数据共现不等价于处理—对照效应。相反，本方法要求每条扰动证据来自具有处理、对照、重复和样本级 MS1 定量的实验，并估计方向、效应量和不确定性。

### 1.3 Connectivity Map 有共享基因坐标；非靶向代谢组学没有共享未知物坐标

转录组连接图可以比较疾病和药物签名，是因为各研究共享基因 ID。非靶向代谢组学中，未知 feature 没有稳定 ID，跨研究保留时间又不可直接比较。本方法的实际增量，是用 MS/MS 对应构造可弃权的共享实体坐标，使未知实体第一次能够进入跨研究扰动检索。

## 2. 新科学对象：扰动响应指纹

设扰动实验包含 \(P\) 个预先定义的药物、基因或环境干预。对谱图实体 \(z\)，其响应指纹为：

\[
\mathbf b_z=(\beta_{z1},\ldots,\beta_{zP}),
\]

其中 \(\beta_{zp}\) 是在控制批次、细胞量或样本量、培养时间和必要协变量后的处理效应；每个分量同时保存标准误、重复数、剂量、时间和实验背景。缺失不是零，必须显式记录。

这个向量赋予未知谱图一种**实验功能坐标**：它不宣称该分子的结构或直接底物关系，但能回答哪些干预会稳定改变它。两个碎裂谱相似的候选可以具有不同响应指纹；一个完全未知结构的实体也可以拥有高度特异的干预响应。

为避免把普遍应激误写成机制，指纹至少拆成：

- 特异响应：扣除细胞量、死亡率、总体离子强度和广泛应激轴后的残差效应；
- 剂量—时间响应：同一干预是否呈现可解释的梯度；
- 节点一致性：化学抑制和遗传扰动，或两个作用于同一节点的独立干预，是否方向一致；
- 背景依赖：效应是否只在特定细胞或培养条件出现。

因此“功能身份”只指经实验限定的控制关系，不等于“已经证明该代谢物是该酶的直接底物”。

### 2.1 这不是换名，而是一种新的数据结构和查询能力

扰动库的主体不再是“已注释代谢物 × 药物”的普通表，而是一个稀疏、有符号、带不确定性的响应数组：

\[
\mathcal R[z,p,c,t]=(\hat\beta,\mathrm{SE},n,\text{QC}),
\]

其中 \(z\) 由可复查的前体与 MS/MS 证据定义，\(p\) 是扰动，\(c\) 是生物背景，\(t\) 是时间或剂量。精确结构只是实体的可更新属性，不是进入数组的前提。

这套数据结构必须真正支持三种过去会因未知物没有共同 ID 而中断的查询：

1. **未知谱图 → 控制节点：** 哪些独立扰动稳定改变同一未知实体？
2. **疾病谱图签名 → 干预：** 哪些扰动在同一批谱图实体上复制或逆转疾病方向？
3. **扰动 → 未知响应模块：** 某个干预除了已知代谢物，还系统改变了哪些可跨研究追踪的未知实体？

若最终产品只能展示热图，不能在留出数据上正确完成这三类查询，就没有新增功能。

## 3. 跨研究转移与疾病连接

### 3.1 从扰动实验转移到疾病队列

疾病研究中的实体 \(i\) 有效应 \(d_i\)，扰动研究中的实体 \(j\) 在干预 \(p\) 下有效应 \(x_{jp}\)。由冻结谱图模型和质量规则得到匹配权重 \(w_{ij}\)，并要求：

\[
w_{ij}\ge0,\qquad \sum_j w_{ij}\le1.
\]

未分配的概率质量表示弃权，而不是被归一化给一个最相似候选。转移后的扰动效应为：

\[
\tilde x_{ip}=\sum_jw_{ij}x_{jp}.
\]

疾病—扰动连接可用预注册的加权有符号统计量或加权秩富集计算。负连接表示扰动可能逆转疾病谱图签名，正连接表示可能复制该签名。公式本身不是创新点；创新是否成立取决于未知实体能否在严格留出条件下增加可复现的机制检索能力。

### 3.2 分析单位必须是实体或离子家族，而不是重复计算的峰

同位素、加合物、源内碎片和同一色谱峰的多次 MS/MS 不能作为多个独立证据。分析前必须形成离子家族，主统计使用家族代表实体；其他离子仅用于增强对应置信度。MS1 丰度用于估计变化，MS/MS 触发次数只能作为采集覆盖信息，不能代替定量。

### 3.3 输出不是药物名单，而是可验证的四元组

每个主结果必须包含：

\[
(\text{谱图实体},\ \text{疾病方向},\ \text{受控扰动方向},\ \text{前瞻验证结果}).
\]

结构候选、化学类别和数据库反应关系放在独立解释层。没有第四项时只能称为假说；没有第一项的跨研究证据时只能称为研究内 feature 关联。

## 4. 与相邻工作的硬边界

| 已有路线 | 已经做到 | 本方法不能冒领的内容 | 必须证明的新增量 |
|---|---|---|---|
| Reverse metabolomics | 从合成化合物的 MS/MS 出发，检索公共数据，发现表型关联，并用独立队列、培养和功能实验兑现 | “用谱图搜索公共数据”“未知物也能联系表型” | 不依赖预先合成或精确结构，从受控扰动响应出发给未知疾病实体建立功能坐标 |
| 大规模药物代谢扰动图 | 大规模测量药物—代谢 feature 依赖并推断作用机制 | “做药物扰动图”“用代谢谱找 MoA” | 使未知实体跨仪器、跨研究进入扰动检索，并在疾病数据中复现 |
| CRISPRi/代谢组学 MoA | 用遗传与化学扰动代谢谱关联药物和靶点 | “遗传扰动可解释药物机制” | 对未知 MS/MS 实体进行可复用的响应建档和跨队列转移 |
| MASST、ReDU、StructureMASST | 按谱图或结构检索公共数据中的出现和元数据背景 | “谱图可连接公共样本” | 使用样本级处理—对照定量估计方向与效应，而非出现次数 |
| PAIRUP-MS、跨数据集 feature 对齐 | 跨队列匹配未知 feature 并用于关联或通路分析 | “未知 feature 可以跨数据集匹配” | 对齐之后完成受控扰动检索、隐藏机制回收和前瞻干预验证 |
| IsoNet、知识引导反应网络 | 借助稳定同位素或已知反应推断未知反应 | “未知物也可获得生化语境” | 以干预响应而非反应数据库或同位素关系定义跨研究功能坐标 |

截至 2026-10-05 的定向检索未发现完整实现“MS/MS 未知实体跨研究对应—受控扰动指纹—疾病连接—前瞻干预”的直接先例，但这不是首创权证明。投稿前仍需系统检索、方法作者交叉核查和引用追踪；任何同构先例出现都应收缩标题与主张。

## 5. 不是清单的关键：四个必须用结果说话的实验

### 实验 A：隐藏结构名称的跨仪器实体迁移

目的：证明 MS/MS 确实能为未知实体建立可靠的跨研究坐标。

1. 选取具有真实结构身份、跨仪器或跨来源重复谱的分子；评估时隐藏名称。
2. 严格按分子身份、分子式和来源留出，避免同物泄漏。
3. 比较前体质量、质量加保留时间、余弦、谱熵、MS2DeepScore、官方 DreaMS 和冻结整合模型。
4. 主要指标是固定错误率下的可匹配覆盖率、错误匹配率和校准；Top-1 只作为辅助指标。

**通过条件：** 在来源或仪器完全留出的条件下，冻结方法相对最佳简单基线显著提高覆盖率，同时错误率不升高；公式簇和来源簇置信区间下界均为正。  
**停止条件：** 只有随机谱划分有效，或模型必须强制为每个查询指定匹配。

### 实验 B：留出扰动或作用机制回收

目的：证明响应指纹不是复杂描述，而能检索被隐藏的干预机制。

1. 将一种药物、一个靶点家族或一个完整实验来源从建库阶段留出。
2. 用该实验的谱图响应签名检索其相同靶点、相同作用机制或相反作用的已知干预。
3. 分别运行“仅已知代谢物”“全部 feature 但仅 m/z 对齐”“全部谱图实体”三条路线。
4. 使用 leave-drug-out、leave-target-out、leave-source-out 和 leave-instrument-out 四种分割。

**通过条件：** 未知谱图实体在最严格的来源/仪器留出下，仍能对作用机制 Top-k、MRR 或富集带来预注册的实质增益，并通过标签置换和质量匹配伪谱对照。  
**停止条件：** 加入未知实体后不优于已知代谢物，或增益完全由细胞死亡、总离子量、批次或同一实验泄漏解释。

### 实验 C：用已知致病节点做隐藏生物学真值

目的：避免直接在复杂肿瘤上讲无法判真的故事。

优先使用具有明确酶缺陷或干预节点的遗传代谢病、同基因敲低模型或药理抑制模型。先隐藏诊断和节点信息，仅用疾病—对照代谢谱检索扰动库，再检查真实节点及其上下游是否被回收。

**通过条件：** 在多个疾病/模型上，真实节点或等价机制的排名显著优于置换，并且未知实体相对已知物带来独立增益。  
**停止条件：** 只有已知标志物驱动结果，或去除这些已知标志物后方法完全失效。

### 实验 D：一项前瞻“财报”

目的：产出一项 Reverse metabolomics 水平的实质兑现，而不是审计报告。

1. 方法和阈值全部冻结后，在 MTBLS13729 或肺大细胞神经内分泌癌数据中选出一个未用于调参的谱图实体模块。
2. 该模块必须在独立队列或独立平台复现，并连接到至少两个指向同一节点的独立干预，最好是一种遗传和一种化学干预。
3. 在疾病相关细胞、类器官或来源明确的培养系统中施加预测干预或 rescue。
4. 检验完全相同的前体—MS/MS 实体是否按预测方向移动，同时测量一个预注册的疾病相关表型。

**最低可发表兑现：** 一个未精确命名的谱图实体模块，在独立疾病数据中重复、在受控干预中按预测移动，并伴随方向一致的表型变化。  
**更强兑现：** 在此基础上，用现有注释算法缩小结构范围，最后用标准品、合成或等价正交证据确认精确结构。  
**失败判定：** 只得到候选药物排名、网络图或回顾性解释，不构成方法论文的核心结果。

## 6. 三类审稿人的预期攻击与硬门槛

### 6.1 计算方法审稿人：“这只是 CMap 加 soft matching”

该批评在以下任一情形成立：没有新的跨研究实体 benchmark；没有来源/仪器留出；没有弃权；没有已知物-only 对照；没有证明未知实体增加机制回收。

必须交付：

- 冻结、无泄漏的实体迁移基准；
- 错误率—覆盖率曲线和校准，不只报 AUC；
- 强制 argmax、质量匹配、经典谱相似度和现代表示模型的完整基线；
- 已知物、未知物及二者联合的增量分解；
- 谱图标签、扰动标签和研究标签三类置换。

### 6.2 代谢组学审稿人：“匹配的是离子，不是化合物；定量也不可信”

必须明确只声称同一“谱图生成实体”，除非有 RT、离子淌度或标准品等证据。还必须控制离子家族、加合物、源内碎片、色谱峰形、DDA 触发偏倚和批次；效应来自 MS1 定量，不能用 MS/MS 谱数冒充丰度。

### 6.3 生物学审稿人：“药物逆转只是相关，不是机制”

必须有：同节点的独立化学/遗传干预一致性、剂量或时间关系、rescue、疾病相关模型、同一谱图实体的前瞻变化和疾病表型。若只有连接分数，应将结论限制为“优先验证假说”，不得称为机制。

### 6.4 通用审稿人：“你们到底发现了什么”

论文摘要必须能够写出一个具体四元组，而不是六轴框架。若答不出“哪一个谱图实体、在哪个疾病、被哪个节点控制、哪项前瞻实验验证”，就没有完成应用方法。

## 7. 数据可行性：当前最大的真实风险

现有大规模人类药物扰动图证明了生物学价值，但其公开主矩阵以注释离子和变化矩阵为主，未必提供可供本方法使用的逐样本原始 MS/MS。一个只有 feature 表、没有原始谱图的资源不能被包装成谱图实体扰动库。

因此第一阶段不是训练模型，而是对每个候选数据集执行四项审计：

1. 是否有原始 LC–MS/MS，而不只是结果表；
2. 是否有逐样本处理、对照、剂量、时间和重复信息；
3. 是否可从 MS1 独立定量，并将 MS2 可靠映射回 feature；
4. 是否允许来源、仪器和干预层面的严格留出。

若找不到至少三个具有互补仪器/来源的可用扰动研究，应停止“跨研究扰动指纹库”的大标题，只做单研究的可行性分析。IsoNet 的公开原始数据可用于测试未知反应/同位素场景，但不能单独支撑药物或疾病连接图。

## 8. 如何使用项目现有算法，而不把模块堆砌冒充创新

- **面向实验条件变化训练的 DreaMS 模型：** 用于跨仪器谱图实体候选检索。
- **Noise 的 P2b 及两个重排器：** 用于困难候选的对应置信度和拒绝强制匹配；必须分别做消融。
- **ChemAware：** 在实体已经获得疾病—扰动联系后，帮助区分近结构候选；不提供干预因果证据。
- **BioAware / 样本代谢关系：** 只做结果解释和候选优先级，不作为主要连接证据，避免静态数据库偏好循环论证。
- **谱熵、余弦、MS2DeepScore、官方 DreaMS：** 作为实体迁移基线。

算法模块的价值只能由实验 A 和 B 的增量证明。若简单双阈值谱图匹配已经足够，应用方法应使用简单方法，不得为了“用全组件”而增加复杂度。

## 9. 首篇论文的最小结果结构

1. **新测量对象：** 谱图实体扰动响应指纹及其跨研究可弃权转移。
2. **技术真值：** 隐藏名称的跨仪器实体迁移 benchmark。
3. **功能真值：** 留出干预/作用机制回收，明确未知实体的增量。
4. **生物学真值：** 已知致病节点的盲法回收。
5. **发现结果：** 一个疾病相关未知谱图模块的独立复现和前瞻干预验证。
6. **质量控制附件：** 原六轴审计、敏感性、候选世界、验证预算和报告层级。

推荐主图不是流程图，而是四张结果图：实体迁移的错误率—覆盖率；留出作用机制回收；已知疾病节点盲法回收；真实未知实体的疾病—扰动—前瞻验证链。

### 9.1 与 Reverse metabolomics 对账时必须拿出的“财报”

Reverse metabolomics 的说服力来自新化学实体、跨队列表型关联、来源实验和功能实验。我们的路线不必复制其合成规模，但至少必须交付等价强度的四项资产：

| 资产 | 本项目必须拿出的结果 |
|---|---|
| 可复用对象 | 一组公开的谱图实体及其带重复和不确定性的扰动响应指纹 |
| 可量化新增功能 | 未知实体使留出作用机制或致病节点回收显著优于已知物-only |
| 生物发现 | 一个在独立疾病队列复现、与特定干预节点相连的未知谱图模块 |
| 实验兑现 | 预测干预使同一模块按预测方向变化，并改变预注册表型 |

少一项都要在标题和摘要中降级。尤其不能把“建立数据库”“开放代码”或“给出候选列表”当作生物发现。

## 10. 明确的一票否决条件

以下任一项成立，就不能以“新应用方法”推进：

- 可用扰动数据没有原始 MS/MS 或缺少样本级处理—对照定量；
- 跨来源实体对应在可接受错误率下覆盖过低；
- 未知实体不能提高留出机制检索，只增加噪声；
- 结果被细胞死亡、增殖、批次、总离子量或 DDA 触发概率解释；
- 已知致病节点的盲法回收失败；
- 真实应用只有回顾性网络图，没有同一实体的独立复现；
- 前瞻干预未使同一谱图实体按预测方向变化；
- 不能交付一个具体生物学发现，只能交付方法清单。

## 11. 近期工作顺序

1. 只读审计候选扰动数据的原始 MS/MS、样本元数据与再分析许可；先形成可用/不可用清单。
2. 以现有冻结跨仪器重复谱为实验 A，不改模型、不碰疾病队列。
3. 若实验 A 通过，选择两个小规模但原始数据完整的扰动研究构造实验 B；先测已知物-only，再测未知实体增量。
4. 只有 B 通过，才选择遗传代谢病或明确酶缺陷数据做实验 C。
5. A–C 全部通过后，才冻结方法并打开 MTBLS13729/LCNEC 做实验 D。

这个顺序有意把最便宜、最能否定路线的实验放在前面。它保留原方案的严谨功能，但不再把严谨本身冒充创新。
