# 谱图实体扰动响应路线：证据门审查记录

日期：2026-10-05  
结论：保留研究假说，撤销成果定位；在最小隐藏真值实验通过前，不得作为论文主方法。

## 1. 本次审查的核心判决

这一路线比此前“六轴—候选世界—VOI”框架有实质进步：研究对象变成谱图实体的扰动响应身份，提出了实体×扰动×背景×时间/剂量的响应结构，也给出了未知谱图到控制节点、疾病签名到逆转干预、扰动到未知响应模块三类可测试查询。

但这些目前只是方法学创新的结构，不是成果。全部价值押在一个尚未验证的前提上：

> 未知 MS/MS 谱图实体可以在仪器、碰撞条件、色谱、离子源、DDA 触发和研究来源变化下，以足够低的错误率被可靠匹配和迁移。

若该前提失败，响应数组、跨研究查询和疾病—扰动连接全部失去可信基础。因此当前状态应描述为“已写好研究合同但尚无营收”，不能把提案当作财报。

## 2. 已经成立与尚未成立的内容

### 已经成立

- 问题具体：未知 feature 缺少跨研究共享坐标，因而无法进入扰动检索。
- 假设可证伪：可直接测试隐藏名称后的跨仪器实体匹配。
- 查询可 benchmark：机制回收、节点回收和逆转检索都有明确输出。
- 失败条件清楚：未知实体若不增加留出机制回收，核心创新即失败。

### 尚未成立

- 尚未证明跨仪器、跨研究实体迁移达到可用错误率和覆盖率。
- 尚未证明未知实体相对仅使用已知代谢物提供独立增量。
- 尚未证明代谢组连接检索相对已有 CMap 式思想具有不可替代的信息。
- 尚无一个“未知实体—疾病—控制节点—前瞻干预”的完整闭环。
- 现有 MTBLS13729 与 LCNEC 资产不能独自承担最终前瞻验证：前者样本量、QC/blank 和全 feature 多重校正能力受限；后者跨平台重叠主要是技术复现，并非独立患者复制。

## 3. 固定的三级证据门

### Gate 1：跨研究谱图实体迁移

只做地基，不建大规模扰动数组。

- 选择至少两个独立数据集或仪器平台，使用具有真实身份的重复谱，但在评价时隐藏名称。
- 评价前体质量、质量加 RT、余弦、谱熵、MS2DeepScore、官方 DreaMS 和冻结整合模型。
- 主要结果是错误率—覆盖率、弃权后错误率、校准以及按分子式和来源聚类的置信区间，不以随机谱划分 Top-1 代替。
- 必须审计加合物、同位素、源内碎片、共洗脱和同一分子多谱问题。

**通过：** 在来源或仪器留出条件下，相对最佳简单基线提高覆盖率且错误率不增加，严格聚类置信区间支持正向增益。  
**失败：** 只有随机划分有效、必须强制 argmax、或可接受错误率下覆盖不足。失败即停止全部后续应用方法开发。

### Gate 2：未知谱图实体的独立增量

只在 Gate 1 通过后启动。

- 在具有药物/基因扰动和已知作用机制的数据中冻结三条路线：仅已知代谢物；所有 feature 但只做 m/z 对齐；加入谱图实体迁移。
- 按药物、靶点、实验来源和仪器分别留出，禁止同实验泄漏。
- 比较作用机制或真实节点的 Top-k、MRR、富集和校准，并控制细胞死亡、增殖、总离子量及批次。

**通过：** 未知谱图实体在严格来源/仪器留出下显著提高机制回收，且增益不能由已知标志物或通用应激解释。  
**降级：** 与已知代谢物相当但无增量，则只能定位为已知代谢物扰动分析的工程扩展。  
**失败：** 加入未知实体降低或不稳定地改变机制回收，则终止“未知实体功能身份”主张。

### Gate 3：单一真实闭环

只在 Gate 1 和 Gate 2 均通过后启动，且只选一个具备 MS1、MS2、QC/blank、明确干预和独立验证条件的案例。

必须形成：

> 同一未知谱图实体或模块 → 疾病中稳定变化 → 受控扰动中反向/同向变化 → 前瞻干预使同一实体按预测移动 → 预注册表型随之改变。

一个完整案例优先于多个半成品。MTBLS13729 和 LCNEC 可作为探索或候选来源，但除非补足独立生物学复制与前瞻干预，不得充当 Gate 3 的最终兑现。

## 4. 论文定位由证据门自动决定

| 完成状态 | 允许定位 |
|---|---|
| Gate 1–3 均通过 | “基于 MS/MS 实体的跨研究扰动响应身份：未知代谢物在机制回收中的增量价值” |
| 仅 Gate 1–2 通过 | “谱图实体跨研究迁移及其在扰动响应分析中的可行性评估” |
| 仅 Gate 1 通过 | 技术可行性报告，不宣称疾病—扰动新方法 |

## 5. 不得再出现的表述

在 Gate 1 通过前，不得写：

- “建立了跨研究扰动响应指纹”；
- “赋予未知代谢物功能身份”；
- “实现疾病—干预连接”；
- “形成新的应用范式”；
- “未知实体提高了机制发现能力”。

只允许写：

- “提出并计划检验”；
- “高风险研究假说”；
- “核心跨研究迁移前提尚未验证”；
- “是否具有增量价值取决于预注册隐藏真值实验”。

## 6. 当前最冷静的项目判断

上一版的主要问题是包装过度；这一版的主要问题是证据为零。包装问题可以通过降级标题解决，证据问题只能通过实验解决。文档已经足以约束后续工作，不应再继续增加概念或扩展宏大叙事。

下一项唯一有资格启动的工作是 Gate 1。Gate 1 的结果出来以前，不建立大数组、不打开疾病故事、不讨论投稿主标题，也不把 MTBLS13729 或 LCNEC 的既有候选反向解释为该方法的验证。
