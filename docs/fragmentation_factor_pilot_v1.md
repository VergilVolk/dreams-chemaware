# DreaMS–KPGT 碎裂因子预实验 v1

## 1. 这次实验要回答的问题

DreaMS 的峰级表示中，是否存在能够跨分子重复出现、并可对应到局部键环境和实际碎片/中性丢失的方向？

本实验不再把“能预测分子量、元素组成、芳香性或极性”的方向称为碎裂因子。这些是全局分子性质，最多作为混杂因素和阴性对照。

## 2. 碎裂因子的操作性定义

一个候选因子必须同时包含四部分：

\[
R_k=(S_k,\Delta m_k,A_k,C_k)
\]

- \(S_k\)：跨分子复现的局部键环境或子结构；
- \(\Delta m_k\)：与该局部结构共同出现的碎片质量或中性丢失分布；
- \(A_k\)：DreaMS 峰级 token 中可重复检测的激活方向；
- \(C_k\)：离子模式、加合物、碰撞能量和仪器等适用条件。

缺少任意一项时，只能称为“表示因子”或“结构相关方向”，不能称为碎裂规则。

## 3. 两个模型各自提供什么

### DreaMS

- 前体/global embedding：用于检索和全局结构关系，不作为碎裂规则的直接证据；
- peak token：保留每个实际谱峰的上下文表示，是碎裂侧的主要输入；
- 实际 m/z、强度和前体质量：提供可核查的实验事实。

### KPGT/LiGhT

- `vavn == 0` 的真实 line-graph 节点：每个节点锚定一条分子键；
- 输入层 bond token：由原子/键特征产生，作为显式局部结构基线；
- 12 层 contextual bond token：包含全图上下文，作为非线性局部结构表示；
- 指纹和200维描述符虚拟节点：仅为运行官方权重所需，不导出为规则证据；
- 全局 pooled embedding：不进入本实验的因子发现。

KPGT 是“带先验的局部结构参照”，不是无偏真值。因此必须报告上下文化向量相对原始键特征是否带来额外信息。真实键在 Transformer 中仍可能受到指纹/描述符虚拟节点影响，所以每个分子同时导出：正常先验的 contextual bond token、将512维指纹和200维描述符置零后的 contextual bond token，以及二者差值。只过滤虚拟节点而不做该消融仍不足以排除全局先验泄漏。

## 4. 分阶段实验

### P0：逐键导出冒烟测试

对少量分子验证：

1. 每条 RDKit 化学键与一个 KPGT token 一一对应；
2. 输出局部 SMARTS、原始键 token 和 contextual bond token；
3. 排除全部虚拟节点；
4. CPU 推理的内存和时间可接受。

P0 只验证工具链，不声称发现化学因子。

### P1：失败病例与匹配对照

从已经审计的 10 ppm 检索任务中选取：

- DreaMS Top-1 错误的同分子式/近质量病例；
- 按前体质量、峰数、碰撞能量、仪器和分子大小匹配的正确病例；
- discovery 与 confirmation 严格按分子身份隔离。

为每张谱图提取全部有效 peak token；为对应结构提取逐键 KPGT token。

### P2：峰—键稀疏对齐

只在同一个“已知结构—实验谱图”内部建立候选峰—键联系。匹配分数由三部分构成：

\[
q_{pb}=\operatorname{sim}(W_p h_p,W_b h_b)
+\alpha\,M_{pb}-\beta\,G_{pb}
\]

- \(h_p\)：DreaMS 峰 token；
- \(h_b\)：KPGT bond token；
- \(M_{pb}\)：碎片质量或中性丢失的可行性约束；
- \(G_{pb}\)：分子量、元素组成、峰强和采集条件等全局混杂惩罚。

采用稀疏匹配或熵正则最优传输；不使用 MIL，不以规则重叠度作为标签。

### P3：跨分子复现与规则命名

先在 discovery 集聚合重复的“局部结构—质量差—峰激活”模式，再在 confirmation 集冻结验证。现有 3,486 条规则只在发现结束后查询，用于标记：

- 已知规则的再发现；
- 已知规则的适用条件修正；
- 规则库未覆盖的候选模式。

## 5. 候选因子的通过条件

候选只有同时满足以下条件才进入规则库候选区：

1. 在多个独立分子骨架中复现，不能由同一分子重复谱图撑起；
2. 局部键环境一致，峰或中性丢失质量在容差内集中；
3. 在冻结 confirmation 集中方向、质量和条件依赖均复现；
4. 控制前体质量、元素组成、峰数、碰撞能量和仪器后仍有增量信号；
5. 删除对应峰后 DreaMS 因子激活下降，或遮蔽对应键后跨模态匹配下降；
6. 对随机峰、随机键和质量匹配的错配对照有显著优势。

## 6. 立即停止的信号

- 因子只预测分子量、N/O 数、芳香性或极性；
- 只能在同一分子重复谱图中复现，跨骨架消失；
- 去掉 KPGT 指纹/描述符虚拟节点后效果消失；
- 峰删除和键遮蔽都不能改变匹配；
- confirmation 集无法复现。

这些结果说明得到的是全局结构相关性、数据集捷径或模型共性，不是质谱碎裂规则。

## 8. 官方权重加载后的先验依赖审计

官方 `base.pth` 已成功加载，参数结构与12层 LiGhT 完全匹配；文件 SHA256 为 `8811C117CFEDDDFF5EF2A512290D1A7A73D3D9560773860BC3B06942C597D15D`。随后从现有 DreaMS 10 ppm Top-1 错误中抽取16组“同分子式、不同骨架”错误对，共32个独立分子、366条化学键。所有分子均成功生成768维逐键表示。

以分子为统计单位进行2,000次 bootstrap：

- 正常 KPGT 与“512维指纹、200维描述符置零”键表示的平均余弦为0.747，95%区间0.722–0.773；平均相对变化为0.660；
- 正常 KPGT 与“彻底删除两个虚拟节点”键表示的平均余弦为0.070，95%区间0.058–0.083；
- 删除虚拟节点会改变预训练模型的注意力拓扑，属于分布外输入，只能作为依赖性诊断，不能直接作为可靠的新表示空间。

### 架构结论

KPGT 的 contextual bond token 虽然锚定到具体化学键，但强烈依赖全局指纹、分子描述符及虚拟节点拓扑。因此它不承担“无规则库先验的局部碎裂因子发现器”角色。KPGT保留为知识增强参照和敏感性分析。

主发现路线调整为“谱图侧优先”：

1. 从 DreaMS peak token 中学习跨谱图重复的稀疏非线性因子；
2. 将因子落实到实际峰 m/z、峰强和 precursor–fragment 中性丢失；
3. 在因子高激活分子中，统计富集的 bond-centered radius-1/radius-2 局部结构；
4. 使用前体质量、分子式、碰撞能量、仪器和峰数匹配的低激活分子作为对照；
5. 通过峰遮蔽、跨分子骨架确认集和条件稳定性验证因子；
6. 发现完成后再查询现有3,486条规则，标记已知、条件修正或候选新规则。

这里的“无先验发现”严格表述为“不使用现有碎裂规则库作为发现标签”。DreaMS模型、稀疏性约束、质量守恒和局部结构表示仍构成明确的归纳偏置。
