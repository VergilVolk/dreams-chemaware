# Formal ranking-method increment gate

`tasks/evaluate_contrast_atlas_ranking_method_increment.py` asks one narrow
question: on the same closed exact-axis gold queries and the same frozen
reference atlas, does conservative optimal-face transport retrieve responses
more safely than both fixed simple ranking baselines?

It consumes three outcome tables independently generated by
`build_pan_redu_exact_axis_source_outcomes.py` for
`transport_conservative`, `greedy_same_graph`, and `centroid_same_encoder`.
Only the `all` world is compared.  Query objects, axes, biological and
provenance families, candidate-universe IDs/hashes/sizes, truth-registry query
hashes, expected direction, frozen reference atlas, held-out-source status,
evaluation role, and `shared_primary_answerability_mask_sha256` must be exactly
identical across methods.  The last digest is built before method scoring from
sorted target IDs plus raw primary `answerable` and `direction_identified`
flags; it contains neither ranking scores nor truth classes.

The evaluator has no score or threshold input.  It preserves each method's
already-built correct, wrong, or abstained result and uses utility
`correct - 2 * wrong`, with abstention equal to zero.  Different method
outcomes and different counts of direction-aligned positive candidates are
allowed; they are consequences of the fixed builder rule, not an invitation to
change the candidate universe or optimize abstention after truth is opened.

For each of the two fixed baselines, axes are averaged inside held-out query
source, sources inside biological family, and biological families equally.
The component gate requires at least four families, at least eight held-out
query sources, at least three quarters of families strictly positive, every
family nonharmful, every leave-one-family-out mean strictly positive, and a
one-sided query-source sign-flip `p <= 0.05`.  Both complete component gates
must pass as an intersection-union test; no observed-best baseline or alpha
splitting is used.

The sign flip is conditional on the fixed reference atlas.  Its inferential
meaning still requires independent held-out query sources and paired
primary-versus-baseline source-delta sign symmetry under each component null.
Passing this gate establishes a ranking-method increment only.  It does not
validate the biological gold adjudication, prove exact chemical identity,
establish mechanism, or turn development data into external confirmation.
