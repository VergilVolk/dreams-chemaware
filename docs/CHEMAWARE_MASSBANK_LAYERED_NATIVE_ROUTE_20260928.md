# ChemAware MassBank 分层原生 triplet 路线（2026-09-28）

## 当前裁决

本路线不依赖 SIRIUS，不做教师蒸馏，不改变 DreaMS 模型、损失或优化器。化学知识只负责选择错误候选；训练数据最终仍是 DreaMS 原生 `(query, positive reference, negative reference)`。

受保护的 PhaseA `+2.1266 pp` checkpoint 是唯一初始化基线。本轮不会重训 PhaseA，也不会把规则头间、训练集可纠错数或 triplet 数量表述为新的 embedding 性能。

## 独立化学证据

- 数据源：MassBank 官方 `2026.03` 发布包。
- 下载包大小：239,602,156 bytes。
- 发布包 MD5：`51904e29ee8717756153a8d31726789d`。
- 输入记录：139,240 个文本记录。
- 合同：仅正离子 ESI、`[M+H]+`、有 `PK$ANNOTATION` 分子式注释、峰质量误差不超过 0.015 Da。
- 单张谱绝不成为规则。每条规则至少由 3 个不同分子身份支持，并按 fragment/loss formula 与 generic Murcko scaffold 聚合；结构谓词取 80% Morgan-bit 共识。
- 输出：16,272 条候选规则，其中 product-ion 9,396 条、neutral-loss 6,876 条；5,437 条由至少 5 个不同身份和 2 个贡献单位支持。

## 特异性确认

候选评分阶段不读取候选真值，并抑制与 MassBank 来源完全相同的分子身份。两种匹配容量对照分别置乱规则质量位置、置乱分子式与结构谓词的对应关系。

开发公式折 0–2：

- product-ion：2,473 个适用查询；相对两个对照的 Hit@1 差异 CI 下界分别为 `0.0494`、`0.0358`，margin 差异 CI 下界分别为 `0.0353`、`0.0249`。
- neutral-loss：2,473 个适用查询；Hit@1 差异 CI 下界分别为 `0.0281`、`0.0314`，margin 差异 CI 下界分别为 `0.0450`、`0.0370`。

冻结作用域后，仅运行一次公式折 3–4 确认：

- product-ion：1,559 个适用查询；两个 Hit@1 差异 CI 下界为 `0.0241`、`0.0257`，两个 margin 差异 CI 下界为 `0.0364`、`0.0360`。
- neutral-loss：1,559 个适用查询；两个 Hit@1 差异 CI 下界为 `0.0444`、`0.0394`，两个 margin 差异 CI 下界为 `0.0267`、`0.0244`。

四组确认均严格大于零，因此 product-ion 与 neutral-loss 两族均获得候选选择资格。该结论是化学候选关系的特异性证据，不是 embedding 性能结果。

## 为什么旧转换只得到 60 个事件

旧转换器对每个候选关系只取 PhaseA 几何下最高相似的一个正参考谱和一个负参考谱。MassBank 规则覆盖 3,599/4,032 个训练查询，但单一 max-reference 几何只新增 60 个不重复事件；228 个事件与 PhaseA 重复，且大量关系在两个化学视图之间发生候选级冲突。

这说明瓶颈不是规则数量，而是“已确认的身份级化学关系”到“具有梯度的谱图级 triplet”之间的转换过窄。

## 动态参考谱转换

新转换仍先要求真实候选相对错误候选得到已确认化学源支持，并拒绝同置信层化学源的反向冲突。对每个通过的身份关系：

1. 在 PhaseA 冻结 embedding 中枚举真实身份与错误身份的参考谱；
2. 优先保留相似度最高、同时仍存在正 triplet hinge 的真实参考谱；
3. 为该正参考谱保留相似度最高的活跃负参考谱；
4. 保证事件内每一个可能被 DreaMS 原生随机采样到的 `(q,p,n)` 都有正 hinge；
5. 不把化学分数写进 loss，不设置自定义权重。

结果：

- 新增化学事件 1,658 个；
- 覆盖 569 个查询、414 个分子式、847 个候选关系；
- 提供 4,066 个可由原生 dataloader 采样的活跃谱图 triplet；
- 85 个 PhaseA 当前错误查询的最高错误候选位于可纠错覆盖内；这是训练头间，不是预期 pp 的替代指标。

## 正式 12k 训练语料

- 受保护 PhaseA 前缀：5,956 个事件，逐数组保持不变；
- 新增合格化学边界：1,658 个事件；
- 新增未修改 DreaMS 10-ppm replay：4,386 个事件；
- 总数：12,000 个事件。

化学事件与官方 replay 在清单中分层记录；官方 replay 只用于覆盖与抗遗忘，不能计为化学证据。所有事件权重均为 1，验证池不变，身份边审计通过。

## 唯一服务器入口与停止门

本地正式语料目录为：

`data/validation/chemaware_massbank_layered_12k_native_v1_20260928/`

完整证据与 20 个直接/传递代码依赖已冻结在：

`data/validation/chemaware_massbank_layered_release_v3_20260928/`

其 `release_manifest.json` SHA256 为：

`f66b0a75ec90cced8b59857fdd30530c94264aa6e7c90f6c759a6549eba9a146`

服务器准备好冻结语料与本轮代码后，只提交：

```bash
sbatch tasks/run_chemaware_massbank_layered_native.sbatch
```

该脚本只请求一张 GPU，不手动指定内存。它直接从 PhaseA checkpoint 继续训练 1,000 步，在 250/500/750/1000 步形成候选；role 2 只用于相对 PhaseA 选 checkpoint，并要求 formula-cluster CI 下界严格为正。若没有候选通过，立即停止且不打开 role 3；只有通过者才运行一次 role 3 确认并封存。

## 当前不能声称的内容

- 不能声称已达到 3–5 pp；尚未完成服务器训练和 role-2/role-3 评估。
- 不能把 85 个可纠错训练查询直接折算成 Recall@1 增益。
- 不能把 16,272 条规则、4,066 个活跃组合或 12,000 个训练事件当作模型性能。
- 不能把 MassBank 规则称为普适碎裂定律；它们是经过公式不相交确认、仅获准用于候选选择的条件关系。
