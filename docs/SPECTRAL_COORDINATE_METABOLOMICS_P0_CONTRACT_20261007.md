# 固定谱图坐标方法：P0-L 局部可辨识性合同

日期：2026-10-07  
状态：预注册的最小可证伪实验；不是既成方法或生物学成果。

## 1. 本轮只回答一个问题

在前体质量已经把搜索限制到冻结候选邻域后，未知名称的查询谱能否被可靠地映射到代表同一分子的参考谱图坐标，尤其是在所有正确参考谱均来自另一仪器家族时？

若这一步失败，则不得继续宣称可以把不同研究的非靶向特征表投影到共同谱图坐标。若通过，也只允许进入全局字典和真实 feature correspondence 的下一门，不允许直接声称跨队列生物学有效。

## 2. 为什么重写原P0草稿

原草稿有四个不可接受的问题：

1. 文档声称比较 DreaMS 和 Noise，但代码实际只计算 m/z、自写余弦和一个不等同于正式 weighted spectral entropy 的公式；
2. “跨文件”被误写成“跨仪器”；
3. 以已知身份挑选单张“峰数最多”的谱作为坐标，改变了冻结 benchmark 的参考聚合口径；
4. `entropy > cosine` 被当作通过门，但它既不检验坐标可辨识性，也不检验项目算法的增量。

正式P0-L不重新计算任何谱图得分，直接读取已冻结的GNPS Gold/Silver面板和15方法得分包，保持所有方法相同的候选、谱图预处理、分子级最大聚合和并列失败规则。

GNPS两个面板此前已经用于文章算法评价，因此本轮不是Noise的新外部确认，也不得据此选择新的checkpoint或融合权重。它新增的是固定坐标口径和严格跨仪器分层。项目映射器的最终外部主张仍须在未被模型选择消费的MoNA或其他独立来源复现。

## 3. 冻结对象

- 候选邻域：观测前体 m/z 的10 ppm窗口；
- 局部坐标：候选分子；同一候选分子的1至3张参考谱按最大得分聚合；
- 正例：查询与候选具有相同IK14；
- 查询和正确参考至少来自不同源文件；
- `strict_cross_instrument`：正确坐标至少有一张已知仪器家族不同的参考谱，且没有同仪器家族的正确参考谱；
- 仪器家族只分为 `orbitrap_ft`、`qtof` 和 `unknown`；unknown不用于证明跨仪器；
- 名称、IK14和分子式不进入任何方法的得分，只在冻结得分产生后用于评价。

这仍是**质量条件化的局部坐标**，不是全局坐标字典。它是后者的必要条件，而不是充分条件。

## 4. 固定比较

- 主方法：`noise_v1`；
- 基线：`official_dreams`；
- 其余13种方法完整报告，但不得在本轮根据P0结果改选主方法；
- identity-disjoint 和 formula-disjoint 两个面板均报告；
- `all`、`near_structure`、`cross_instrument_available`、`strict_cross_instrument` 四个子集均报告。

指标包括 Recall@1/5/10/20、MRR、同分子式错误合并率、跨分子式错误率、Top1-Top2间隔，以及20%至100%覆盖率下的选择性风险。所有主方法相对官方DreaMS的差异均按分子式簇bootstrap给出95%置信区间。

## 5. 预注册裁决

### 坐标地基通过

必须同时满足：

1. strict-cross-instrument查询不少于1000；
2. `noise_v1` 在该子集 Recall@1 不低于80%；
3. 按Top1-Top2间隔保留60%查询时，错误率不高于2%。

通过只允许进入全局字典和真实跨研究 correspondence 试验。

### 项目映射器增量通过

必须同时满足：

1. strict-cross-instrument Recall@1 相对官方DreaMS的分子式簇bootstrap置信区间下界大于0；
2. near-structure同分子式错误合并率差异的置信区间上界不大于0；
3. formula-disjoint全体Recall@1增益置信区间下界大于0。

若只通过地基、不通过增量，则“固定谱图坐标”仍可继续验证，但不能声称Noise是更好的坐标映射器；后续应比较冻结WSE/P2b或仅把Noise作为普通基线。若地基失败，停止应用方法主线。

即使上述“增量门”通过，也只构成进入独立外部确认的资格，不构成新的独立算法增益证据。

## 6. 明确不回答的内容

P0-L不证明RT/MS1 feature可以跨研究对应，不处理真实no-match比例、离子家族、DDA缺失和基质效应，也不证明未知谱图实体增加疾病分析价值。这些必须由后续P0-G全局字典、P1伪研究恢复和P2 LCNEC跨平台实验分别验证。
