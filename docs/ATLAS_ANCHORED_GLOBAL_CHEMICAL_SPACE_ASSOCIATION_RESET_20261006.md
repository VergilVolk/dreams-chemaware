# 固定谱图化学空间上的全局表型关联：应用方法重置

日期：2026-10-06  
状态：保留为节点层基线与可视化底座；不再单独承担方法学主创新  
工作名：基于固定谱图化学空间的代谢组全局邻域关联分析  
英文工作名：*Atlas-anchored metabolome-wide spectral neighborhood association*

> **2026-10-06 重新定位：**“固定化学空间中的表型效应区域”能改进全局统计，但其生物学对象仍是一片匿名邻域，容易被评价为 Qemistree/FBMN/核平滑的组合。它应保留为节点层基线，用来回答“哪里变化”，不再单独作为主方法。进一步候选主线转向“表型条件化的化学转换程序”，回答“化学组成以什么重复转换方式变化”；见 `docs/PHENOTYPE_CONDITIONED_CHEMICAL_TRANSFORMATION_PROGRAM_20261006.md`。

## 0. 先撤销错误定位

以下流程不构成方法论提升：稳健差异 feature → 公共谱库/邻域搜索 → 类别线索 → 三级证据主张 → 暴露排查 → 少量标准品。它是反向检索和非靶向代谢组学的标准骨架，加上必要的质量控制纪律。

实体层统计、弃权匹配、实体/类别/结构分层、负结果归档和按信息量采购标准品都应保留，但只能进入 SOP、Methods 或质量控制附件，不能承担标题、摘要主创新或“新范式”主张。LCNEC 的 30 个暗模块、5 个类级命中、2 个近前体候选和用药史核查是一次执行记录，不会自动把标准流程变成新方法。

此前提出的扰动响应指纹也不作为近期主线。它有较新的问题结构，但全部价值依赖尚未验证的跨研究实体迁移，且可用扰动原始 MS/MS 资源不足。继续扩写该故事只会增加概念负债。

## 1. 真正需要改变的不是注释环节，而是分析单位

传统非靶向流程把分析单位设为单个 feature：先逐峰统计，再从显著峰中挑选、注释和讲故事。即使后续使用分子网络，统计选择已经在 feature 层完成，大量未注释谱图只作为候选池或背景。

新的候选方向把一个样本的全部合格 MS/MS-linked feature 表示为固定谱图化学空间上的加权分布，并把病例—对照差异表示为该空间上的表型效应场：

> **研究对象不再是“哪个峰叫什么”，而是“疾病使哪些化学空间区域整体富集、耗竭或发生组成重排；这些区域能否在不同色谱平台、离子模式或队列中复现”。**

精确结构不再是进入主分析的条件，未知谱图与已知谱图使用同一坐标。注释只在显著区域形成以后用于解释，而不决定哪些信号有资格参加统计。

## 2. 新对象、新功能和新结果

### 2.1 新对象：谱图化学空间上的样本分布与表型效应场

令 \(z_i\) 为 feature \(i\) 的冻结 MS/MS embedding，\(a_{si}\) 为样本 \(s\) 中经过预注册归一化的 MS1 丰度。样本表示为：

\[
\mu_s=\sum_i a_{si}\,\delta_{z_i}.
\]

这里的 \(\mu_s\) 是样本在“MS/MS 可见化学空间”中的经验分布。它不是一张已注释代谢物表，也不是 MS/MS 谱数。

在固定 atlas landmark \(c_m\) 和尺度 \(h\) 上定义软邻域：

\[
O_{sm}^{(h)}=\sum_i a_{si}K_h(z_i,c_m).
\]

对配对患者 \(p\)，肿瘤—癌旁差异为：

\[
D_{pm}^{(h)}=O_{p,T,m}^{(h)}-O_{p,N,m}^{(h)}.
\]

所有 landmark 和尺度都在不看表型的情况下固定。对患者标签做配对 sign-flip，使用 maxT、层级检验或等价的全局错误控制，得到化学空间上的显著效应区域及方向。

### 2.2 新功能：不依赖逐峰同一性的跨平台区域复现

传统跨平台复现要求两个平台观察到同一个 m/z–RT feature 或已经知道结构。这里在发现平台冻结一个 atlas 区域 \(R\)，验证平台只需把自己的合格谱图投影到同一个固定空间，直接检验区域总效应：

\[
E_{pR}=\sum_i \mathbf 1(z_i\in R)\,\Delta_{pi}
\]

或使用预注册软权重版本。验证时不重新画 UMAP、不重新聚类、不移动区域边界。

因此它能回答一个不同的问题：即使不同平台选择了不同离子、不同类似物或同一家族的不同成员，是否仍然观测到同一片化学空间的疾病重排。

### 2.3 新结果：已知与暗化学空间对疾病信号的分解

每个显著区域按与权威参考谱库的距离和结构证据分为：

- 已知锚定区域；
- 已知化学邻域但精确成员未知；
- 远离参考库的暗区域。

主问题不是“暗区域也显著”，而是：

1. 全空间分析是否比仅使用已知代谢物更稳定地复现病例—对照效应；
2. 暗区域是否提供不能被已知区域解释的跨平台增量；
3. 不同疾病是否具有可重复、可区分的化学空间效应场。

若暗区域没有增量，本方法不能以“释放暗代谢组价值”为主张。

## 3. 为什么这不是再做一个 atlas

DreaMS Atlas 已经把约 2.01 亿张公共 MS/MS 组织为固定的全局邻域，并展示跨研究谱图的局部联系。本项目不复制该资源，不重新抓取全球仓库，也不把“更多节点”作为贡献。

现有 atlas 主要回答“某张谱附近有什么”。本候选方法试图回答：

- 一个病例—对照研究在整个固定空间上形成什么效应场；
- 哪些区域在控制多重比较后关联表型；
- 同一效应区域能否被另一个平台或队列盲法复现；
- 未注释区域是否增加跨平台表型信息。

atlas 是坐标系，疾病研究才是待估计对象。

## 4. 与已有全局方法的边界

| 方法 | 已有能力 | 本方向不能冒领 | 必须证明的新增功能 |
|---|---|---|---|
| FBMN / molecular networking | 将定量 feature 组织为谱图相似家族，并展示家族差异 | “未知物也能进入分子网络” | 在固定外部坐标中做全空间统计和跨平台区域复现 |
| CSCS | 用谱图结构相似性比较样本整体化学组成 | “用化学相似性计算样本距离” | 定位带方向、带错误控制、可外部复现的表型效应区域 |
| Qemistree | 以预测分子指纹构建研究内化学树，用 UniFrac、Songbird 等比较样本 | “把样本看成化学树上的组成” | 不重建研究内树；在固定外部空间中冻结区域并跨平台检验 |
| CANOPUS / ChemRICH | 聚合化学类别后做类别层解释或富集 | “结构未知也能做类别分析” | 不依赖预定义类别，允许发现参考类别之外的暗区域 |
| DreaMS Atlas | 2.01 亿谱图的全局邻域、元数据探索和个例传播 | “构建全球谱图图谱”或“查询邻居” | 从个例探索推进到样本级、配对设计、全空间错误控制与外部区域复现 |
| 参考数据驱动分析 | 将公共来源谱当作伪参考库，提高来源解释覆盖 | “公共谱图元数据可以解释未知物” | 表型效应由研究样本的 MS1 定量产生，公共 atlas 只提供坐标而不提供结果 |

若最终输出只是 UMAP 上色、网络图、UniFrac 分离或显著分子家族列表，应判定为已有方法组合，不构成新应用方法。

## 5. “全局”与“unbiased”的诚实边界

不得无修饰地声称 unbiased。电离效率、色谱覆盖、DDA 选择和 MS/MS 触发都具有系统偏差。本方法最多可以称为：

> **对化学身份和参考谱库覆盖不设进入门槛的全局分析；研究宇宙仍限于表型盲 QC 合格、具有可靠 MS1 定量和代表性 MS/MS 的可观测化学空间。**

具体要求：

- feature 宇宙必须在看肿瘤/癌旁标签前，由 pooled QC、blank 和 dilution 冻结；
- MS/MS 只负责定位，丰度效应必须来自独立 MS1 EIC/feature 定量；
- 同位素、加合物、源内碎片和共洗脱冗余先形成离子家族，避免一个分子重复投票；
- 不以每个样本的 DDA 谱数代表化学丰度；
- atlas 公共数据的物种、仪器和上传偏差不能进入病例—对照显著性计算。

## 6. 统计实现的最低要求

### 6.1 固定坐标，而不是结局驱动的 UMAP

优先直接使用冻结 DreaMS embedding 和不看表型建立的 landmark/prototype。二维 UMAP/TMAP 只作展示，不能作为距离计算和区域选择空间。

### 6.2 多尺度，而不是任意挑一个邻域半径

预先固定从近似实体到化学家族的多个尺度。检验需要控制 landmark 与尺度的联合多重性。只有单一人工阈值结果不允许作为主结论。

### 6.3 患者是推断单位

LCNEC 使用 34 个患者配对 sign-flip 或配对 wild bootstrap。feature 不是独立重复，不能把数百个 feature 当样本扩大显著性。

### 6.4 需要可解释的 witness field

全局两样本距离或分类 AUC 只能证明样本不同，不能定位变化发生在哪里。方法必须同时输出：

- 全局差异检验；
- atlas 上的有符号局部效应；
- 每个区域的患者一致性与不确定性；
- 区域由哪些 feature/谱图贡献；
- 去除已知代谢物后是否仍然存在。

## 7. LCNEC 是现成的最小证伪场，而不是故事素材

### 7.1 已有资产

HSST3n 平台已经完成表型盲技术筛选：85 个文件中包含 68 个研究样本、9 个 pooled QC、2 个 blank 和6个稀释样本；研究样本累计 133,925 张 MS2，QC 累计 17,727 张 MS2。1,138 个 precursor–RT 家族中，263 个同时通过 QC 复现、blank 和 dilution 门。这 263 个家族是第一个合法的全局分析宇宙，不应从现有 81 个差异暗模块起步。

公开资源同时列出 LIPp、LIPn、HILICp、HSST3n 和 HSST3n-2HG 五套 mzML 压缩包，具有相同患者、QC、blank 和 dilution 设计。因此可以在一个平台发现区域、另一个平台冻结验证，而不需要先等待新的疾病队列。

当前本地已经保存 HSST3n 的合格 feature/EIC 工件和少量优先 MS2；其余平台原始包尚未在本地形成同等 feature 宇宙，需在服务器取得和处理。已有 12 个跨平台候选只能作为阳性对照，不能定义区域或阈值。

### 7.2 预注册的最小实验

1. **发现宇宙：** HSST3n 全部 263 个表型盲 QC 合格家族，禁止先筛差异。
2. **定位：** 每个家族使用 pooled-QC 代表谱生成冻结 embedding；使用 MS1 EIC 形成 34 对患者丰度。
3. **全局检验：** 比较肿瘤和癌旁的整体分布，随后用多尺度 witness field 定位区域。
4. **冻结：** 仅依据发现平台冻结区域边界、尺度和方向。
5. **技术外部验证：** 在 LIPn 或另一相容平台独立完成 QC feature 宇宙，再检验固定区域；正、负离子模式分层，不强行跨极性合并。
6. **暗增量：** 比较仅权威谱库匹配、类别可解释、全部谱图三种输入的区域复现和患者区分。
7. **负对照：** QC 对 QC、blank、患者标签 sign-flip、随机旋转 embedding、质量匹配但谱图打乱。

## 8. 必须比较的基线

- 逐 feature 配对检验及 FDR；
- FBMN 分子家族聚合；
- Qemistree + weighted UniFrac / differential ranking；
- CANOPUS 或 ClassyFire 类别聚合；
- 样本平均 DreaMS embedding；
- 仅前体 m/z 邻域；
- 经典余弦、谱熵或官方 DreaMS 建图；
- 项目冻结改进 embedding 所形成的空间。

主结果不是谁的病例分类 AUC 最高，而是谁能在发现平台冻结后，于验证平台复现同一有方向化学区域，同时保留暗 feature 的独立贡献。

## 9. 三类审稿人的否决点

### 计算评审

“这是 Qemistree 加 kernel smoothing。”如果没有固定外部坐标、联合错误控制、冻结区域外部检验和对 Qemistree/FBMN 的直接比较，这项批评成立。

### 代谢组学评审

“DDA 不是全局；embedding 邻近不等于结构邻近；一个分子重复形成多个离子。”必须将主张限制为 MS/MS 可观测空间，并完成离子家族归并、QC/blank/dilution、谱图—结构保真度和多尺度敏感性分析。

### 生物学评审

“一片抽象化学空间有什么生物意义？”必须证明固定区域跨平台复现、展示其已知锚点和暗成员，并说明该区域相对于已知代谢物-only 增加了什么疾病信息。区域复现仍不是因果机制。

## 10. 三级杀死规则

### Gate A：空间本身可信吗

在真实跨条件重复谱和已知结构对上，局部邻域必须同时具有条件稳定性和高于简单余弦的结构一致性。若 DreaMS 距离不能支持从实体到家族的预期尺度，停止。

### Gate B：区域能跨平台冻结复现吗

发现平台定义的显著区域必须在兼容验证平台中方向一致，并优于逐峰匹配、Qemistree 与 FBMN 基线。若只有同平台重采样有效，停止“跨平台化学空间效应场”主张。

### Gate C：暗空间有独立增量吗

在保留已知区域后，暗区域必须提高固定区域复现、患者配对效应解释或外部队列预测，并通过置换。若无增量，降级为已知化学类别的空间化展示。

## 11. 当前判断

这一方向比注释漏斗、证据分层和扰动指纹更值得优先试验，原因不是故事更大，而是：

- 它改变了主分析单位，从单峰改为固定化学空间上的样本分布和效应场；
- 它提供了一个传统流程没有的具体功能：无需精确逐峰对齐的跨平台化学区域复现；
- 它不需要先有结构名称或新的扰动 atlas；
- LCNEC 已有五平台原始数据，可以立即得到正或负结论。

但目前仍不能称为方法创新。只有 Gate A–C 至少前两门通过，并在预注册比较中优于 Qemistree/FBMN/逐峰基线，才允许升级。否则应作为一次全局可视化或负结果归档。
