日期：2026-10-08

## 裁决

MassSpecGym 是 Noise、ChemAware、P2b 及融合开发反复使用的开发集合；GNPS Gold/Silver 也已用于外部开发、方法天梯和融合分析。二者都不得再称为最终独立测试。MassBank 2026.03、项目内 MoNA 面板和 MSnLib 压力测试也已开封，只能承担开发、消融或补充压力测试。

最终主评测首选 **Enveda-180**。截至本裁决，仓库内未发现 `Enveda-180`、DOI `10.5281/zenodo.21346580` 或 ChemRxiv `15004319` 的任何既有引用或结果。该资源在 2026 年公开，包含约 184,944 个标注结构和约 1.16 百万张实验谱，覆盖正负离子及三档碰撞能，足以构造大规模跨条件候选检索。

## Enveda-180 冻结协议

1. 先生成只含记录ID、采集条件、离子模式、碰撞能和结构哈希的 manifest；不计算任何模型分数。
2. 由 `tasks/unified_consumed_sources_v1.json` fail-closed 汇总全部已消费身份与峰表哈希；任何 required source 缺失即停止。排除 InChIKey14 重叠和规范化谱峰哈希重叠。主结果报告身份不重叠集合，另报告 Murcko scaffold 不重叠硬子集。
3. 以一种碰撞能/采集条件的谱作为 query，以不同条件的谱作为候选参考，禁止同一原始扫描或复制谱同时出现在 query 与 reference。
4. 同时冻结两种候选任务：严格同分子式候选；10 ppm 质量候选。真结构必须在候选池内，候选构造不得读取任何算法分数。
5. 主指标为 Recall@1/5/10、MRR、近结构子集 Recall@1、配对 bootstrap 置信区间，以及固定错误风险下的接受覆盖率。所有模块和基线使用完全相同的 query、候选池与聚合规则。
6. 统一模型、权重、阈值、主比较基线和模块清单先在开发数据上冻结并记录哈希；训练进程不得接收 Enveda bundle。外测由独立 evaluator 在读取标签前 exclusive-create opening ledger，成功或失败均不可自动重试。终局结果不得反向改变模型；若需要修改，必须另取新的、未打开外部来源。

本协议只能证明对 registry 中可枚举已消费标注源及可得谱峰哈希完成排除。由于 DreaMS 无监督预训练语料缺乏完整结构命名空间，不能声称对全部预训练数据零曝光。

## 能验证与不能验证的范围

Enveda-180 可以完整检验 Noise、ChemAware、WSE、P2b、Noise 两类重排器及其统一候选模型，并特别检验跨碰撞能与近结构安全性。BioAware B47 需要真实样本内的共现代谢事件；标准谱库没有这一输入，不能伪造。其增量必须在独立、带真值且具有样本上下文的外部面板单独评价，再在真实应用中以条件模块接入。

## 备选

若 Enveda-180 的池化采集或元数据质控无法满足严格身份归属，商业授权允许时使用 NIST26 相对 NIST23 的新增身份作为最高质量替代；否则等待 MassBank 下一正式发布，仅使用冻结日期之后的新记录。不得退回 MassSpecGym 或已打开的 GNPS 面板补作“最终测试”。
