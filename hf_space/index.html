Overview

Results of the Chem-aware DreaMS pipeline on the MTBLS13729 colorectal-cancer metabolomics cohort (smoke run: 14,948 query spectra against a 1,000-spectrum MONA library). This is a static showcase — data is precomputed; see Run annotation for live compute.

Run annotation

This Space is static (free, no Python compute). Live annotation runs on a compute backend selected top-right. The form below matches the DreaMS /predict interface exactly.

Confident matches cos ≥ 0.7 ∧ |Δm/z| ≤ 20 ppm

The 9 spectra whose top-1 hit passes both the cosine cutoff and the precursor m/z hard constraint (4 distinct structures). The m/z constraint removes ~4× raw-cosine over-annotation.

FDR confidence

Confidence is a target-decoy FDR (Elias & Gygi 2007; Scheubert et al. 2017), not a raw similarity.

Self-consistency COSMIC · Hoffmann 2022

The COSMIC structure-space coherence score is a self-consistency signal — not P(correct). Decoded via a frozen concept probe over the retrieval embedding.

Chemical rule matching

Frozen Schymanski chemical rules decoded from the embedding by a concept probe (266/335 rules). This panel is the per-match rule-evidence surface.

Chemical explainability

Every confident match carries a transparent, auditable reason for its assignment. Select a row to read the full evidence chain.

HMDB / biochemical confidence reserved · all NaN

Biochemical pathway / functional confidence (HMDB pathway & disease associations). Interface reserved; not yet populated.

Differential analysis tumor vs normal

Fisher exact test on confident structures across tumor / normal samples (q-value = Benjamini–Hochberg corrected).

Novel findings dark matter

Structures our pipeline recovered that the original author annotation did not report (min_dppm_to_author = distance to the closest author hit — hundreds to thousands of ppm, i.e. genuinely distinct).
